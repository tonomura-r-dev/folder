## 全体設計（案）
1. **役割**：カモンハウス会員だけが参加できる場所（投票・アンケート・共創・会員限定の企画）。レシピ・新商品・大型キャンペーンはグループ公式LINEに任せる。
2. **友だちの増やし方**
   - 主＝サンクスLINE誘導（会員登録・イベント応募・キャンペーン応募・メルマガ登録の完了ページ）
   - 立ち上げ時＝既存会員（約32.7万人）へのメルマガ告知（SIMの初月7,113人はこれが前提）
   - 後で判断＝サイトのポップアップ（離脱防止）、グループ公式LINE・X・IGでの告知
3. **友だち追加後の流れ**：あいさつ → ステップ配信（2週間）→ 週1本の定期配信
4. **定期配信（月4本）の中身**：①参加（投票・アンケート）②結果発表・共創の報告 ③サイトの新着（コラム・企画）④会員限定のキャンペーン・イベント
5. **送り分け**：最初は標準機能（サンクスLINE誘導で引き継ぐ会員登録の情報＋定期配信のクリック）。
   3問アンケートでの出し分け（12枚目⑤）はツールかAPIが要るので、3か月の数字を見て判断（17・18枚目どおり）。
6. **測る数字**：配信ごとにutm。友だち数／追加から2週間のブロック率／開封率／LINE経由のサイト流入（6か月後 月3,795件＝29枚目）／投票・アンケートの回答率。
7. **進め方**：1か月目＝立ち上げと配信時間の検証 → 2〜3か月目＝クリックで送り分け開始 → 4〜6か月目＝ツール・マストバイを判断。

## 初動設計（案）
### 開設前（約1か月＝37枚目のSTEP1〜4）
- アカウント開設＋認証済アカウントの申請（審査に日数がかかるので最初に）
- プロフィール・あいさつメッセージ・リッチメニュー
  - リッチメニュー案＝今参加できる企画／キャンペーン・イベント／新着コラム／会員ページ／よくある質問
- 自動応答：個別チャットはしない（29枚目）ので、届いたメッセージにはFAQとお問い合わせ先を自動で返す
- サンクスLINE誘導の設置（ハウス側のサイトの完了ページに入れてもらう）
- utm・GA4の設定
- メルマガ告知の日を開設日に合わせる

### ステップ配信（2週間・5本）
| 日 | 中身 |
|---|---|
| 0日目 | あいさつ：このLINEでできること＋今参加できる企画 |
| 1日目 | 会員だけの投票・アンケート（1タップで参加） |
| 3日目 | 会員の声で商品になった話（2024年 とんがりコーン・フルーチェの新しい味） |
| 7日目 | 今月の会員限定キャンペーン・イベント |
| 14日目 | サイトの人気コラム・企画 |

### 1か月目
- 定期配信＝上の①〜④を週1本ずつ。配信時間は 昼12時台／夕方16〜17時（献立を決める時間）／夜21時 を試す。
- 月末に決めること＝配信時間／ステップの追加（10本程度の枠の残り）／送り分けの開始。

   SIMの初月7,113人はこれが前提 → 告知できるか・いつかをハウスに確認する。

## ステップ5本・2週間の根拠（2026-10-01 殿村さんに出した内容）
1. **ver2の20枚目：友だち追加から15日を境にアクティブ率が下がる** → まだ反応がある最初の2週間に5本を集める。
   20枚目の文は「追加から20〜30日間のステップ配信」。15日目以降は週1本の定期配信（アンケート・企画）が続くので、
   「ステップ5本＋定期配信」で30日を埋める形にする（20枚目の図の並び＝ステップ配信→アンケート→企画配信 と同じ）。スライドにするときは20枚目の文をこれに合わせる。
2. **送りすぎると開かれなくなる**：インクアートで約600人への配信を5回続けたら、開封率が 42.6→37.1→36.2→33.2→30.1% と毎回下がった（業種が違うので参考）。
   新しい友だちには定期配信も届くので、最初の2週間で1人に約7回（ステップ5＋定期2）。10本だと約12回になる。
3. **1本1役で5つの役が埋まる**：何ができるか／参加してみる（投票）／参加が商品になった話／会員の特典／サイトに戻る理由。6本目からは定期配信と同じ中身になる。
4. **足すのは数字を見てから**：管理画面の「分析→ステップ配信」で1本ごとの開封・クリックが見られる（配信から14日間を集計）。1か月目に落ちている所を見て足す。

## 今あるLINE（グループ公式）を動かす場合（2026-10-01 殿村さん「運用法かなり変わるよね／いきなりコンサルで入れるかも怪しいし」）
「今あるLINE」＝ハウス食品グループの公式LINE（友だち1,000万人超・外部の推計）として答えた。
※カモンハウスの広告用のLINE（ver2の2枚目「広告用のみ」）のことなら、運用していないのでほぼ新しく作るのと同じ進め方になる。

| | 新しく作る（カモンハウス） | 今あるグループ公式 |
|---|---|---|
| 友だち | 0から。会員だけ（濃い） | 1,000万人超。懸賞・ポイント目当ても多い（薄い） |
| 仕事 | 立ち上げ（設計・ステップ・リッチメニュー） | 今の運用の手直し |
| 決める人 | カモンハウスの担当 | グループ本社。すでに回している担当がいる |
| 合わせる物 | 無し | ミニアプリ（HOUSE QUEST WORLD）・LINEで応募・各ブランドのキャンペーン |
| 1回の配信 | 外しても影響が小さい | 全員に送ると影響が大きい → 絞り込みが前提 |
| 見る数字 | サイトへの再訪・ブロック率 | 買われたか・店の棚の前で思い出されるか |

- いきなりコンサルで入るのは難しい（同感）：すでに回している担当と考え方（ゆるやかなCRM）がある／ハウスとの実績がまだ無い／規模が大きいので外からの変更は通りにくい。
- **推し＝順番を分ける。** ①まずカモンハウスの新しいLINE（今回の提案）で数字を作る（グループ公式に触らないので通りやすい）
  ②その数字（再訪・回答率・ブロック率）を持って、グループ公式には一部だけ提案する。入口の候補＝サンクスLINE誘導（キャンペーン応募の完了ページから）／キャンペーン1本分の配信設計／計測（utm・GA4）。
