## 2. この資料の背骨（要旨）

> **「高校生の進路検討は約18ヶ月。それに対して、学校が持っている接点は
> オープンキャンパス当日の数時間だけです」**

支える事実は3つ。

1. **接触が1点しかない** — 資料請求で取る連絡先はメール・電話＝高校生が最も使わない2つ。
   LINEなら**当日中に約8割が開封**（LINEヤフー社公開値）
2. **勝負は年内に終わる** — 総合型＝9/1出願・11/1発表、学校推薦型＝11/1出願・12/1発表
   （文科省『大学入学者選抜実施要項』）。**夏のOCが実質の決戦**
3. **失注は取り返せない** — 募集は年1サイクル。**1人の入学＝4年間で約400万円**

### 言わないこと3つ
① 偏差値・ブランドの話（短期で変えられない）
② 他大学・他校の批判（高校の先生の心証に関わる）
③ 「SNSでバズらせる」提案（広報部の既存業務と衝突する）

## 3. 塾と決定的に違う4点（設計を変えている理由）

| | 教育（塾） | 学校法人 |
|---|---|---|
| 決める人 | 保護者 | **高校生本人**（払うのは保護者＝**二重の説得**） |
| 検討期間 | 26日 | **約18ヶ月** |
| チャンス | 年中いつでも | **年1回＝失注は実質永久失注** |
| 単価 | 4年で約80万円 | **4年で約400万円** |

→ この「二重の説得」がリッチメニュー3面目（**保護者タブ**）の理由。
→ 「年1回」が、中退防止を**第2の提案軸**に置いた理由。

## 4. CV3段と第2軸

- **CV①（軽CV）** ＝ 資料請求／LINE友だち追加＋**30秒 学部学科診断**
- **CV②（主CV）** ＝ オープンキャンパス（体験入学）予約・参加
- **CV③（最終CV）** ＝ 出願・入学手続
- **第2軸** ＝ **入学後活用（中退防止・在学生・保護者・卒業生）**
  - 年間中退率 約2%／4年で約8%／2年次中退＝**残存学費200〜300万円**
  - **「募集で1人増やす＝中退を1人止める」で理事会の稟議に乗せる**

## 6. 実測データ（★この資料の強み。捏造なし）

### Googleトレンド（2026-09-15取得・`_data/trends/学校法人/`）

- **「オープンキャンパス」は5年連続で7月ピーク**（7月値 100/94/80/85/90）。谷は12-1月でピークの約1/20
  → **形が変わらない＝毎年同じ日程で仕込める**
- **週次（2025年）：ピーク7/27週。6/29週で既に半分（51）。動き出しは5/25週**
  → **仕込みの窓は5/25〜6/29の5週間。6月に広報を始めたら遅い**
- **「総合型選抜」は5年で3.3倍**（9月値 30→100・5年連続増）。**指定校推薦は64→57（▲11%）で横ばい**
  → **2023年9月に逆転済み。いまは総合型が1.75倍**
- **総合型の週次ピークは8/31週＝9/1出願解禁を含む週**
  → **OCピーク7月末 → 総合型ピーク8月末。間は1ヶ月しかない**
- **「専門学校」は年中フラット（22〜40）** ＝大学と季節性が違う → **別の配信設計が要る**
- 「共通テスト」は1月中旬の2週だけ（他月は10以下）。**「大学受験」の約17倍スケールなので必ず別グラフ**

### 前後検索（2026-09-15・`_data/journey/学校法人/`）

- **0日前後の密集帯はほぼ全部「大学名＋偏差値」。** 学部でもやりたいことでもない
- **−7日＝MARCH・成成明学 → 0日＝大東亜帝国・地方中小私大**
  ＝ **志望校は「下方修正の過程」で決まる**
- **OC検索が立つのは +1〜+7日** ＝ **OCは入口ではなく、絞り込み後の確認行動**
- 「定員割れの大学一覧」が −2日（滑り止め探し）
- 部活KW（野球部・駅伝部・サッカー部）が多数 ＝ **スポーツ推薦の導線が実在**
- 地域は埼玉西部〜北部（川越・所沢・大宮・春日部・熊谷・坂戸・東松山）＝ **通学圏が主軸**

### 3業界で共通して確認できた1点

**お金（学費・奨学金・就学支援金・教育ローン）の検索は必ず「後」に来る。**
塾（料金確認は+1.6日＝決断の後）／通信制高校（学校名の直後）／大学（絞り込みの後）。
→ **入口の訴求を「安さ・学費」に置かない。** ただし**保護者には先に総額を出す**（リッチメニュー③）。

## 7. SIM（p37）の設計

モデル校＝私立大学・入学定員600名・**現在の入学者480名（充足率80%）**・デジタル募集広報費 年1,000万円

| 指標 | Before | After |
|---|---|---|
| 投下計 | 1,000万円 | 1,360万円（＋LINE運用費360万円） |
| LP流入／LP CVR | 100,000／2.5% | **変えない** |
| CV①合計／CPA | 2,500件／4,000円 | 3,085件／**4,408円** |
| OC参加率 | 70%（525名） | **80%（741名）** |
| 出願率 | 40%（210名） | **43%（319名）★** |
| **入学者（Web経由）** | **120名** | **182名（＋62名）** |
| **入学1名あたり獲得コスト** | 83,333円 | **74,725円（▲10.3%）** |

**必ず添える3点**
1. LP CVRは動かしていない。触るのは「落ちた後」と「予約が入った後」の2箇所だけ
2. 効くのは母数ではなく率（CV①＋23%／入学者＋52%）
3. **CPA単体は悪化して見えるのが正しい。** 見るのは**入学1名あたり**

**限界の注記（省略禁止）**
- Web経由の募集だけを切り出した試算。高校訪問・指定校推薦など他経路と重複するため**純増は試算より小さい**
- **定員という上限がある。** 充足済みの学校では「歩留まり改善によるコスト削減」として読む

**★仮置きは3つだけ**：①友だち化率3% ②友だち→CV①転換率20% ③出願率40→43%
