# プリントアース LINE OA｜タスク1：あいさつメッセージ＆初回オファー

作成日：2026-08-31 ／ 対象：プリントアース（インクアート株式会社）LINE公式アカウント
目的：広告流入ユーザーの**即時CVR最大化**（＝成果報酬モデルのCPA改善）

---

## 0. 先に直すこと（コピーより優先）

**リッチメニューの遷移先URLが `https://https://…` の二重表記になっている。**
これはコピー改善の効果を全部飲み込むので、今日中に直す。

1. LINE Official Account Manager → ホーム → リッチメニュー → 該当メニューを開く
2. 各アクションの「リンク」欄の先頭 `https://` の重複を削除
3. 保存 → 実機（iOS / Android の両方）で全ボタンをタップして着地確認

> 修正のついでに、全リンクへ計測パラメータを付ける（§5参照）。成果報酬型では
> 「どのカードのどのボタンが売上を作ったか」が分からないと単価交渉ができない。

## 1. 現状の何が「摩擦」なのか（3行で）

| # | 現状 | 何が起きているか | 打ち手 |
|---|---|---|---|
| 1 | 広告「1.2円〜／最大50%OFF／1,000Pt進呈」→ LINE初回応答「最大10万円分クーポン」 | 広告で見た数字と違う数字が出る＝**別サイトに来た感覚**。「最大10万円」は条件が想像できず、かえって嘘っぽい | 広告で見た数字を**そのまま**冒頭に出す。オファーは1つに絞る |
| 2 | あいさつ内に「会員登録」「アンケート」の2CTA | 選択肢が2つ以上あると人は選ばずに閉じる（意思決定コスト）。しかもアンケートは**売上に直結しない** | 主CTAは「会員登録＝割引の受け取り」1本。アンケートはあいさつから外し、**注文完了後**に移設 |
| 3 | 「個別メッセージ不可」の注意書きが目立つ | 買う前に「困っても助けてもらえない」と伝えている。BtoBの印刷は**入稿データの不安**が最大の離脱要因なのに、そこを突き放している | 否定形を消し、「**メールで担当者が回答する**」という前向きな事実に言い換えて、カード内の末尾へ小さく置く |

## 2. 【最重要】ポイントとクーポンの構造ミスマッチ

公式のポイント規約上、**ポイントは「次回以降のご注文時」に使えるもの**で、
発行のトリガーは購入。つまり——

> **広告の「1,000Pt進呈」は、初回注文の価格を1円も下げない。**

「すぐ安く買いたい」で来たユーザーに、初回の支払額が変わらないオファーを見せている。
ここが即時CVRを最も削っている可能性が高い。

### 組み替え方（本提案の論理構成）

```
初回の支払いを下げるのは ── 割引クーポン（20% / 50%OFF）  ← ここを主役に
次回の支払いを下げるのは ── 1,000ポイント                 ← 「おまけ」として添える
```

**両方を1画面で見せて「今日も安い、次も安い」の二段で得を積む。**
ポイントを隠すのではなく、役割を正しく置き直すのがポイント。

> ⚠️ **要確認（社内）**：新規登録特典が「1,000pt」か「2,000pt」か、初回20%OFFと
> 最大50%OFFの適用条件（商品・部数・期間）、クーポンとポイントの併用可否。
> 下記コピーの数字は**広告の訴求値に合わせて差し替える前提**で書いている。

## 3. あいさつメッセージ本文（テキスト吹き出し）

### 構成ルール

- 吹き出しは**2つまで**（テキスト1＋Flexカルーセル1）。3つ以上は読まれずスクロールされる
- 本文は**200字前後**。スマホ1画面に収める
- 1行目に相手の名前、2行目に「いくら安くなるか」。**能書きは書かない**
- 絵文字は使っても1〜2個まで。多いと広告色が出て信用が落ちる

---

### 案A：割引即時回収型（**推奨・まずこれで配信**）

```
{ユーザーの表示名}さん、はじめまして。
ネット印刷のプリントアースです。

初回のご注文が20%OFFになるクーポンを、いまお渡ししています。

受け取りは会員登録だけ。30秒で終わります。
登録した時点で、カートの金額に自動で反映されます。
次回から使える1,000円分のポイントも、一緒に入ります。

名刺もチラシも冊子も、最短で当日出荷。
下のボタンから、今日中に発注まで進みます。
```

**なぜ効くか**
- 「20%OFF」を2行目に置き、広告の割引訴求をその場で回収
- 「30秒」「自動で反映」で、**登録＝面倒**という最大の心理障壁を先回りして潰す
- 1,000ptは3番目に小さく置く（主役にしない＝§2の構造整理）
- 最後の「今日中に発注まで進みます」が、**次の行動を1つだけ**明示

---

### 案B：スピード訴求型（納期で刈る／A/B対抗案）

```
{ユーザーの表示名}さん、ありがとうございます。
プリントアースです。

いまご入稿いただければ、最短で本日出荷できます。
（平日◯時までの受付分・商品により異なります）

はじめての方は、初回20%OFFクーポンつき。
会員登録30秒で、カートの金額がそのまま下がります。

1枚のチラシから、5万枚のロットまで。
下のボタンからどうぞ。
```

**使いどころ**：「急ぎ 印刷」「即日 チラシ」系のキーワード広告からの流入。
価格より納期が刺さる層に当てる。

---

### 案C：価格の底・訴求型（広告と完全一致／A/B対抗案）

```
{ユーザーの表示名}さん、はじめまして。
ネット印刷のプリントアースです。

A4チラシ、1枚1.2円から刷れます。
そこからさらに、初回は20%OFF。

会員登録は30秒。登録したその場で、
カートの金額に割引が入ります。

いくらになるかは、下のボタンで30秒で分かります。
（部数を選ぶだけ・送料込みの総額が出ます）
```

**使いどころ**：「印刷 激安」「チラシ 印刷 安い」など**価格比較**中の流入。
※「1.2円」は必ず**実際の最安条件と一致**させること。乖離があると景表法リスク。

---

### ネガティブ注意書きの置き換え（3案共通）

| Before（現状） | After（推奨） |
|---|---|
| 「このアカウントでは個別のお返事ができません」 | 「ご相談は下のメニューから。担当者が**1営業日以内にメールで**お返事します」 |

- 置き場所は**あいさつ本文ではなく、Flexカード3の本文末尾**と**リッチメニューの相談タブ内**
- 「できません」という否定語を使わず、**代替経路と所要時間**を示す＝安心材料に反転する
- これで「困ったら助けてもらえる」に意味が変わり、入稿データ不安による離脱を止められる

## 4. Flexメッセージ（カルーセル）構成案

あいさつテキストの直後に流す。**カード3枚**。4枚以上は3枚目以降の視認率が落ちる。
実装JSON → `_drafts/printearth_flex_greeting_carousel.json`（そのまま貼れる）

### カード1｜今すぐ注文する（**主動線・必ず左端**）

| 要素 | 内容 |
|---|---|
| 画像 | 刷り上がったチラシ／名刺の実物。左上に赤帯で **「初回 20%OFF」**。1040×520px |
| ラベル | 初回かぎり |
| 見出し | **20%OFF ＋ 1,000ポイント** |
| 本文 | 会員登録は30秒。登録した時点で、カートの金額に反映されます。 |
| 主ボタン | **30秒で登録して割引を受け取る**（塗り／目立たせる） |
| 副ボタン | 商品と価格を見る（テキストリンク） |

> ボタン文言は「会員登録はこちら」にしない。**登録は目的ではなく、割引の受け取り手段**。
> 「割引を受け取る」と書くと、同じ行動でもクリック率が上がる。

### カード2｜無料で見積りを出す

| 要素 | 内容 |
|---|---|
| 画像 | 見積り画面のスマホモック。「送料込み」を明示 |
| ラベル | 仕様が決まっていなくても |
| 見出し | **その場で無料見積り** |
| 本文 | サイズと部数を選ぶだけ。1分で総額が出ます。送料も込みの金額です。 |
| 主ボタン | 無料で見積りを出す |
| 副ボタン | 納期を確認する |

> 拾う層：**社内稟議で金額が要る人／相見積り中の人**。ここを取りこぼすと
> 「価格が分からない」だけで競合に流れる。BtoBのCVはここが太い。

### カード3｜データを見てもらう（不安の除去）

| 要素 | 内容 |
|---|---|
| 画像 | 担当者がデータを確認している写真、または「無料データチェック」の図版 |
| ラベル | データに不安がある方へ |
| 見出し | **入稿データ、無料で確認します** |
| 本文 | そのまま印刷できるか、担当者が確認してご連絡します。追加料金はかかりません。 |
| 主ボタン | 無料でデータを見てもらう |
| 注記（小・薄字） | ※お返事はメールでお送りします（1営業日以内） |

> ここが**「個別メッセージ不可」の受け皿**。否定文を消し、代替経路として自然に機能させる。

### 実装手順（JSONの入れ方）

1. LINE Official Account Manager → ホーム → **あいさつメッセージ**
2. 1つ目の吹き出し：§3の案Aを貼る（`{ユーザーの表示名}` は挿入メニューから入れる）
3. 「＋追加」→ **Flexメッセージ** → JSON入力 → `printearth_flex_greeting_carousel.json` を貼る
4. altText（トーク一覧・通知に出る文言）を設定：
   `初回20%OFFクーポンをお受け取りください｜プリントアース`
5. プレビューで崩れがないか確認 → 保存 → **自分の実機で友だち追加してテスト**

> **JSON内の差し替えが必要な箇所**（現状はプレースホルダ）
> - 画像URL `https://www.inkart.jp/line/greeting_card*.jpg` → 実ファイル（1040×520px・HTTPS必須）
> - 遷移先URL（`/regist/` `/estimate/` `/contact/` `/guide/delivery/`）→ **実パスを確認して差し替え**
> - アクセントカラー `#E8380D` → プリントアースのブランドカラーに合わせる
> - 画像は**タスク3の発注指示書**で作成する。それまでは hero を外してテキストのみでも配信可能

## 5. 計測タグ（成果報酬型なので必須）

全リンクに付ける。どのカードが売上を作ったかが分からないと改善が回らない。

```
?utm_source=line
&utm_medium=greeting
&utm_campaign=ad_20off
&utm_content=card1_signup   ← カードごとに変える
```

| 位置 | utm_content |
|---|---|
| あいさつ本文のリンク | `greeting_text` |
| カード1 主ボタン | `card1_signup` |
| カード1 副ボタン | `card1_lineup` |
| カード2 主ボタン | `card2_estimate` |
| カード3 主ボタン | `card3_datacheck` |

**見る指標**：友だち追加 → 会員登録率 → 初回注文率 → 広告CPA。
とくに「**追加から60分以内の注文率**」を基準値として取っておく（タスク4のリマインド効果測定に使う）。

## 6. A/Bテストの回し方

1. **まず案Aを2週間**回して基準値を取る（friends追加数が母数として足りるまで）
2. 案B / 案Cは**広告の入口ごとに出し分ける**のが理想
   （LINE公式単体では出し分け不可 → 広告側のURLパラメータでLPを分けるか、
   MAツール／Lステップ等を使う場合はシナリオ分岐で対応）
3. 変更は**一度に1箇所**。冒頭2行 → ボタン文言 → 画像、の順で効果が大きい
