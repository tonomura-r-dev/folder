作成日：2026-08-31（v2／26年8月ADレポート反映）
対象：プリントアース（インクアート株式会社）LINE公式アカウント
目的：**CVR改善 → CPA低減**。CV＝注文完了／見積もり完了／問い合わせ完了

## 1. 8月ADレポートから読める構造：客が2種類いる

| | 検索広告（Google / Yahoo!） | Meta広告（Instagram / Facebook） |
|---|---|---|
| 誰 | 店舗・販促担当・法人 | 個人・クリエイター・同人 |
| KW / フック | 格安印刷通販、チラシ印刷、チケット印刷、商品タグ印刷 | 推し活グッズ、透明グッズ、ノベルティ、小ロット |
| 動機 | 今すぐ刷りたい／1円でも安く／納期を今すぐ知りたい | 作ってみたい／少量でいけるか／見た目が良いか |
| 刺さる言葉 | 価格・スピード・見積もり | 1個から・簡単・かわいい |

**現状のあいさつは、この2種類のどちらにも当たっていない。**

- 検索層 →「最大10万円分クーポン」を見て「**自分には関係ない（高額発注向けだ）**」と離脱
- Meta層 →「会員登録」「10万円クーポン」の**法人臭**で引いてブロック

つまり問題は文言の巧拙ではなく、**広告で約束したものと違うものを出している**こと。

---

## 2. 【制約】あいさつメッセージは流入元で出し分けできない

LINE公式アカウントの標準機能では、**誰がどこから登録しても同じあいさつが一律送信**される。
流入元別の出し分けには外部ツール（Lステップ／プロラインフリー等）か Messaging API 連携が要る。

### だから今回の設計はこうする

```
あいさつ本文（1通・全員共通）
  └ 誰でも同じだけ得するオファー（1,000円分）＋ 法人臭を抜いた一文
       ↓
カルーセル（横スクロール）
  └ 「何を作るか」で1タップ分岐 ← ここでBtoB / BtoCを吸収する
```

**縦の動線は1本（ポイント受け取り）、横の選択肢は商材別。**
CTAを1つに絞りつつ、2種類の客を取りこぼさない唯一の形。

> **中期の打ち手**：出し分けツールを入れれば、検索流入には価格・納期訴求、Meta流入には
> 推し活訴求のあいさつを出せる。まずは本案で基準値を取り、費用対効果が見えてから提案する。

## 3. あいさつメッセージ本文

### 構成ルール

- 吹き出しは**2つまで**（テキスト1＋カルーセル1）。3つ以上はスクロールされて読まれない
- **150〜200字**。スマホ1画面に収める
- 1行目に名前、その直後に「いくらもらえるか」。**能書きを先に書かない**
- 絵文字は1〜2個まで。多いと広告色が出て信用が落ちる

---

### 案A：ポイント即時回収型（**推奨・まずこれで配信**）

```
{ユーザーの表示名}さん、はじめまして。
印刷通販のプリントアースです。

友だち追加ありがとうございます。
1,000円分のポイントをお渡しするので、受け取ってください。

会員登録だけ、30秒で終わります。
▼こちら
（会員登録URL）

チラシ5万枚も、アクスタ1枚も、同じ工場で刷っています。
下のカードから、作りたいものを選んでください。
```

**なぜこの形か**

| 行 | 狙い |
|---|---|
| 「1,000円分のポイントを**お渡しするので、受け取ってください**」 | 広告文の約束をその場で回収。「進呈します」より当事者化する言い方 |
| 「会員登録だけ、30秒」 | **登録が面倒**という最大の障壁を先回りで潰す |
| **「チラシ5万枚も、アクスタ1枚も、同じ工場で刷っています」** | **この1行が本案の核**。法人臭と「個人お断り感」を同時に消し、BtoB/BtoC両方に「自分の店だ」と思わせる |
| 「下のカードから、作りたいものを選んでください」 | 次の行動を1つだけ指示 |

> ✍️ 「最大10万円分クーポン」は**廃止**。金額が大きすぎて条件が想像できず、
> 検索層に「自分には関係ない」と判断される原因そのもの。

---

### 案B：スピード訴求型（検索層に寄せる／A/B対抗案）

```
{ユーザーの表示名}さん、ありがとうございます。
印刷通販のプリントアースです。

いまご入稿いただければ、最短で本日出荷できます。
（平日◯時までの受付分・商品により異なります）

はじめての方には、1,000円分のポイントを。
会員登録30秒で受け取れます。
▼こちら
（会員登録URL）

チラシ5万枚も、アクスタ1枚も、同じ工場で刷っています。
```

**使いどころ**：「急ぎ 印刷」「即日 チラシ」系の比率が高い時期。納期が価格に勝つ層に。

---

### 案C：BtoC寄せ型（Metaの比率が高いなら／A/B対抗案）

```
{ユーザーの表示名}さん、はじめまして。
印刷通販のプリントアースです。

アクスタも缶バッジも、1種類1枚から刷れます。
個人の方のご注文、大歓迎です。

まず1,000円分のポイントをお渡しします。
会員登録30秒で受け取れます。
▼こちら
（会員登録URL）

下のカードから、作りたいものを選んでください。
```

**使いどころ**：ADレポで Meta 流入が検索を上回る場合。**「個人の方のご注文、大歓迎です」**が
BtoC層のブロック理由を直接潰す。

---

### ネガティブ注意書きの置き換え（3案共通）

| Before（現状） | After |
|---|---|
| 「このアカウントでは個別のお返事ができません」 | 「ご相談は下のカードから。担当者が**1営業日以内にメールで**お返事します」 |

- 置き場所は**あいさつ本文ではなく、カルーセル4枚目の末尾**（小さい薄字）
- 「できません」を使わず、**代替経路と所要時間**を示す＝安心材料に反転
- 印刷通販の最大の離脱要因は「入稿データが正しいか不安」。ここを突き放すと確実に落ちる

## 4. カルーセル（4枚）— 商材別に1タップで分岐

実装JSON → `_drafts/printearth_flex_greeting_carousel.json`（検証済み・そのまま貼れる）

### カード1｜チラシ・フライヤー・ポスター 〈検索層・最大ボリューム〉

| 要素 | 内容 |
|---|---|
| ラベル | 販促・集客に |
| 見出し | **チラシ・ポスターを刷る** |
| 本文 | サイズと部数を選ぶだけ。送料込みの総額が30秒で出ます。最短で当日出荷。 |
| 主ボタン | 30秒で見積もりを出す |
| 副ボタン | 価格表を見る |

### カード2｜推し活・オリジナルグッズ 〈Meta層・BtoC〉

| 要素 | 内容 |
|---|---|
| ラベル | 1種類1枚からOK |
| 見出し | **推し活グッズをつくる** |
| 本文 | アクスタ、缶バッジ、透明グッズ。1種類1枚から刷れます。**個人の方のご注文も大歓迎です。** |
| 主ボタン | グッズの種類と値段を見る |
| 副ボタン | 入稿テンプレートをダウンロード |

> 「個人の方のご注文も大歓迎です」は**削らないこと**。Meta流入のブロック理由を
> 名指しで打ち消す一文で、本カードのCVRを決める。

### カード3｜名刺・ショップカード・冊子 〈迷い層の低摩擦CV〉

| 要素 | 内容 |
|---|---|
| ラベル | 紙で迷ったら |
| 見出し | **紙の見本帳、無料で送ります** |
| 本文 | 実際に印刷された用紙を、手にとって選べます。送料も無料です。 |
| 主ボタン | 無料で見本帳をもらう |
| 副ボタン | 名刺・冊子の価格を見る |

> **このカードが企画上いちばん効率が良い。** 見本帳の請求には会員登録が必要なので、
> 「請求 → 会員登録 → ポイント発生 → 後日注文」が1本の線でつながる。
> しかも**その場で買わない人を捨てずにCV（問い合わせ完了）として拾える**。
> 迷っている層をブロックさせずに在庫化できる、CPA的に最も安い出口。

### カード4｜相談・データチェック 〈不安の除去＋注意書きの受け皿〉

| 要素 | 内容 |
|---|---|
| ラベル | データに不安がある方へ |
| 見出し | **入稿データ、無料で確認します** |
| 本文 | そのまま印刷できるか、担当者が確認してご連絡します。追加料金はかかりません。 |
| 主ボタン | 無料でデータを見てもらう |
| 注記（小・薄字） | ※お返事はメールでお送りします（1営業日以内） |

### カードの並び順

**1枚目に置いたカードのCTRが最も高い。** 8月ADレポの流入比率で決める：

- 検索 > Meta → 上記の順（チラシが1枚目）
- Meta > 検索 → **カード2（推し活）を1枚目に入れ替える**

> 📌 **次に必要なデータ**：8月の検索広告 vs Meta広告の「**友だち追加数の比率**」。
> これが分かればカード順とあいさつ案（A / C）を確定できます。

## 7. 要確認（社内・**配信前に必ず**）

1. **【最重要】1,000ポイントは初回注文から使えるか。**
   公式のポイント規約は「**次回以降のご注文時に使用**」と読める（100円＝1pt、購入で発行）。
   もし登録特典1,000ptも同じ扱いなら、**初回の支払額は1円も下がらない**。
   広告で「すぐ使える」と言っていると、カートで期待が外れて離脱＋景表法リスク。
   - 初回から使える → 案Aの本文に「**そのまま初回のお会計から引けます**」を追加
   - 次回から → 本文に「**次回のお買い物から使えます**」と明記し、初回の割引は
     クーポン（20%OFF等）で別途用意する
2. 新規登録特典は **1,000pt か 2,000pt か**（媒体により記載ゆれあり）
3. 「最大50%OFF」「1枚1.2円〜」の**適用条件**（商品・部数・期間）。
   広告の数字は**実際の最安条件と一致**させること
4. 会員登録ページの実URL
5. 8月の**検索 vs Meta の友だち追加数比率**（§4のカード順を決めるため）
