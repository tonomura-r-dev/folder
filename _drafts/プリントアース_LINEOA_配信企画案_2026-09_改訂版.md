## ★8月の実配信から取った2つのルール

**2026-09-09に8月の実CR4本を受領、2026-09-10に構成のズレを殿村さんから指摘された。**
ズレていたのは文体だけではなく、**月4本の組み方**だった。

### 8月の実配信4本の内訳

| # | 内容 | 種類 |
|---|---|---|
| 1 | ポリうちわ印刷に新サイズが新登場＋～8/31は10%OFF | **新商品紹介** |
| 2 | お盆の休業期間（11〜16日）・8/10の受付確定／電話対応の締切 | **実務のお知らせ** |
| 3 | 最大50%OFF／残り日数わずか！／**3商材まとめ** | キャンペーン |
| 4 | 最大50%OFF／本日終了！／**3商材まとめ**＋入稿の一言 | キャンペーン |

### ルール1：キャンペーンを商材別に割らない

**#3と#4はどちらも「名刺・ショップカード／チラシ・フライヤー／冊子」を1枚に3つまとめて載せ、
回で変えているのは残り日数だけ**（残り日数わずか！→本日終了！）。

→ 旧案の「名刺の回／冊子の回／チラシの回」は**先方の運用と違う**。9月は24・25の2本に集約した。

### ルール2：月4本を販促で埋めない

8月は4本のうち2本が販促以外（新商品紹介・実務のお知らせ）。
過去20本の狙い概要でも**新商品紹介は5回で2番目に多い**分類。

→ 9月は **23（トレカ）を商材紹介の回**に充てた。割引訴求を乗せない。

### 文体ルール

| 要素 | ルール |
|---|---|
| 絵文字 | **使う。**（2026-09-10 殿村さん「淡白すぎない？絵文字くらい入れようよ」）<br>行頭に1つだけ。1本の配信で3〜4個まで。文中には入れない |
| 行数 | **4〜8行**。ブロックごとに空行 |
| 1行目 | **オファーの数字を単独で置く**（「最大50%OFF」「ポリうちわ印刷が10％OFF」） |
| 状況の一言 | 「残り日数わずか！」「本日終了！」「新登場！」を1行で挟む |
| 対象 | 商材を改行で縦に並べる |
| 期限 | **「～8月31日」。「まで」も年号も曜日も付けない** |
| 補足 | 「データのご入稿は**後でも**大丈夫です！」（※「後日でも」ではない） |
| CTA | 「ご注文はこちらから！」「詳細・ご注文はこちら」 |
| 語尾 | 「！」で締める。説明を足さない |

**「まもなく終了！」はこちらの造語だったので使わない。** 8月の実語は「残り日数わずか！」と「本日終了！」。
