## ★8月の実配信から取った2つのルール

**2026-09-09に8月の実CR4本を受領、2026-09-10に構成のズレを殿村さんから指摘された。**
ズレていたのは文体だけではなく、**月4本の組み方**だった。

### 8月の実配信4本の内訳

| # | 内容 | 種類 |
|---|---|---|
| 1 | ポリうちわ印刷に新サイズが新登場＋～8/31は10%OFF | **新商品紹介** |
| 2 | お盆の休業期間（11〜16日）・8/10の受付確定／電話対応の締切 | **実務のお知らせ** |
| 3 | 最大50%OFF／残り日数わずか！／**3商材まとめ** | キャンペーン |
| 4 | 最大50%OFF／本日終了！／**3商材まとめ**＋入稿の一言 | キャンペーン |

### ルール1：キャンペーンの締めくくりは3商材をまとめて出す

**#3と#4はどちらも「名刺・ショップカード／チラシ・フライヤー／冊子」を1枚に3つまとめて載せ、
回で変えているのは残り日数だけ**（残り日数わずか！→本日終了！）。

**※当初これを「商材別に割らない」というルールとして書いたが、範囲が広すぎた。**
8月の#3・#4は**どちらもキャンペーン終盤の回**で、終盤は全部見せるのが自然。
**期間中は1回1商材で掘り下げてよい**（2026-09-10 殿村さん判断）。

→ 9月は **9/15＝名刺／9/23＝冊子／9/28＝チラシ＋残り日数わずか**とし、
　**9/28の下部にだけ他2商材を小さく添える**。

### ルール2：月4本を販促で埋めない

8月は4本のうち2本が販促以外（新商品紹介・実務のお知らせ）。
過去20本の狙い概要でも**新商品紹介は5回で2番目に多い**分類。

→ **9月は例外。** 9/10が会員登録（販促というより関係づくり）で、残り3本は
　サマーキャンペーンが9/30に終わるため販促に充てる。
　**10月は新商品紹介の回を1本入れる**（新着情報にネタが実在する。§末尾参照）。

### 文体ルール

| 要素 | ルール |
|---|---|
| 絵文字 | **使う。**（2026-09-10 殿村さん「淡白すぎない？絵文字くらい入れようよ」）<br>行頭に1つだけ。1本の配信で3〜4個まで。文中には入れない |
| 行数 | **4〜8行**。ブロックごとに空行 |
| 1行目 | **オファーの数字を単独で置く**（「最大50%OFF」「ポリうちわ印刷が10％OFF」） |
| 状況の一言 | 「残り日数わずか！」「本日終了！」「新登場！」を1行で挟む |
| 対象 | 商材を改行で縦に並べる |
| 期限 | **「～8月31日」。「まで」も年号も曜日も付けない** |
| 補足 | 「データのご入稿は**後でも**大丈夫です！」（※「後日でも」ではない） |
| CTA | 「ご注文はこちらから！」「詳細・ご注文はこちら」 |
| 語尾 | 「！」で締める。説明を足さない |

**「まもなく終了！」はこちらの造語だったので使わない。** 8月の実語は「残り日数わずか！」と「本日終了！」。

# No.22 9/10(木)｜新規会員登録キャンペーン

遷移先：`https://www.inkart.jp/cp/202606-12-newmember/`

### 企画案

新規会員登録キャンペーン（最大10万円分クーポン）

### 狙い概要

```
キャンペーン訴求
```

### CRテキスト

```
会員登録がまだの方へ

ご登録で
🎁最大10万円分の
クーポンプレゼント

✨最初のご注文から使えます
📅～12月31日

📱約2分で完了・ご登録は無料

無料で会員登録する（CTA）
```

**★「最初のご注文から使えます」「約2分で完了」はトップページのバナー文言そのまま**
（2026-09-10 スクショで確認）。原文は
**「最初のご注文から使える／最大10万円分クーポン進呈中／約2分で完了 新規会員登録（無料）」**。

**⚠️ これは「最大10万円分クーポン」の話であって、1,000ptとは別物**（2026-09-10 殿村さん指摘）。
8/31からの申し送り「1,000ptが初回注文から使えるか未確認」は**まだ未確認のまま**。
ただし**9月のCRからptの記述を全部外しているので、この企画には影響しない。**

### ★この回だけ8月の型を当てない（2026-09-10 殿村さん指摘）

**「オファーの数字を1行目に単独で置く」は“注文させる回”の型。**
この回は**登録させる回**なので、そのまま当てると**割引の告知に見えて登録の話に見えない**。

変えた3点：

| # | 変更 | 理由 |
|---|---|---|
| 1 | 冒頭に**呼びかけ**を置く（「会員登録がまだの方へ」） | 誰向けの話かが1行目で分かる |
| 2 | **「ご登録で」**を挟む | クーポンが**登録の対価**だと分かる |
| 3 | CTAを**行動**にする（詳細・ご登録はこちら → **無料で会員登録する**） | 押した先が登録だと分かる |

**「会員登録がまだの方へ」が絞り込みの代わりになる。**
誰が会員かはLINE側で分からず全配信しかないが、この1行があれば登録済みの人は自分で読み飛ばせる。

### バナー構成（1040×1040）

| 領域 | 内容 |
|---|---|
| 上 0–140px | 会員登録がまだの方へ |
| **主役 140–520px** | ご登録で ／ **最大10万円分の**（特大）／**クーポンプレゼント** |
| 中 520–800px | 最初のご注文から使えます ／ ～12月31日 ＋ クーポン券を扇状に重ねた俯瞰／名刺・チラシ・冊子を小さく添える |
| 下 800–1040px | 約2分で完了・ご登録は無料 ＋ CTA「無料で会員登録する」 |
