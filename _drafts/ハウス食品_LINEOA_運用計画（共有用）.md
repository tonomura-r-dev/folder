# Come on House LINE公式アカウント 運用計画（案）

2026-10-01 時点／数字はシミュレーションの暫定値

## 方針
- ハウス食品グループの公式LINEとは別に、Come on House（カモンハウス）のLINE公式アカウントを新しく作って運用する
- コンセプト：食と健康でつながるコミュニティに、LINEから毎週参加できる場所
- 友だちの増やし方：会員登録の完了ページからLINEへ誘導（サンクスLINE誘導）＋開設時に既存会員へメルマガで告知

## 目標（暫定）
| 時期 | 友だち | LINEからサイトに来る数 | ブロック率 |
|---|---|---|---|
| 1か月目 | 約7,100 | 月約2,100 | 25% |
| 6か月目 | 約13,000 | 月約3,800 | 27%以下 |

## 1日の目安（2か月目以降）
| 毎日見る数字 | 1日の目安 |
|---|---|
| 会員登録 | 約70人 |
| うちLINEに入った人（会員登録の完了ページから） | 約26人（会員登録の約4割） |
| 新しい友だち（全体） | 約40人 |
| ブロック | 約12人まで |
| LINEからサイトに来た数（配信の日） | 1本で約530→約950（届く人の約10%） |

- 届く人＝ブロックしていない友だち
- サイトに来た数は、配信ごとにURLへ印（utm）を付けてGA4で数える

## 毎日やること
1. 朝5分：前日の数字を記録して、目安と比べる
2. 次の配信を1段進める（投稿案 → FIX → デザイン → 配信設定）。途中でも毎日共有する
3. サイトの新着（コラム・企画・キャンペーン）を見て、配信のネタに貯める
4. 届いたメッセージを見て、よくある質問を自動応答に足す（個別の返信はハウス側）

## 最初の1週間に徹底すること
- 開設告知のメルマガの日と翌日は、友だち追加とブロックを数時間おきに見る
- 毎朝、会員登録の完了ページからLINEに入った人数を見る。会員登録があるのに0なら、完了ページのLINEボタンをすぐ確認する
- 毎朝、ステップ配信が始まった人数が、新しい友だちの数と合っているか見る
- 届いたメッセージは、その日のうちに自動応答に足す
- 2週目からは、朝5分の数字チェックと配信の1段進めに戻す

## 週のリズム（配信は週1本）
例：金曜に配信する場合

| 曜日 | やること |
|---|---|
| 月 | 前週の数字を見て、投稿案 |
| 火 | FIX（ハウスの確認） |
| 水 | デザイン |
| 木 | 配信設定 |
| 金 | 配信 |

- ハウスの確認に日数がかかる場合は、全体を1週前倒しにする
- 配信の曜日は1か月目に試して決める

## 月のリズム
- 固定：定期配信 月4本（①投票・アンケート ②結果発表・共創の報告 ③サイトの新着 ④会員限定のキャンペーン・イベント）
- 変動：臨時のキャンペーン・イベントの告知
- 月末に決めること：配信時間／ステップ配信を足すか／クリックした人で送り分けを始めるか

## 1か月目だけ別
- 開設告知のメルマガで、数日のうちに約6,300人が入る。全員が同じタイミングでステップ配信5本を受け取るため、最初の2週間は定期配信を入れない（2週間で7回届くのを避ける）
- 定期配信は3週目から（3週目＝投票／4週目＝その結果発表）
- 配信時間を試す（昼12時台／夕方16〜17時／夜21時）

## ステップ配信例（2週間・5本・ざっくり）
| 日 | ねらい | 中身 | 飛び先 |
|---|---|---|---|
| 0日目（あいさつ） | 何が届くLINEかを伝える | 週1回、会員だけの投票・結果発表・新着コラムが届くことを伝える＋今参加できる企画を1つ | 今参加できる企画 |
| 1日目 | 1回参加してもらう | 2択の投票（例：シチュー、ごはんにかける派？かけない派？） | サイトの投票ページ |
| 3日目 | 参加が形になると知ってもらう | 会員の投票から商品になった話（とんがりコーン・フルーチェの新しい味）＋共創コミュニティ・ラボの紹介 | 共創コミュニティ・ラボ |
| 7日目 | 会員でいる得を知ってもらう | 今月の会員限定キャンペーン・イベント | キャンペーンのページ |
| 14日目 | サイトに戻る習慣をつける | 人気のコラム・企画を3つ（季節もの） | コラム一覧 |

- 投票はサイトの投票ページで行い、LINEからは1タップで飛ぶだけ。1通につき飛び先は1つ

## 定期配信の企画案（冬・11〜1月の想定）
| 型 | 案 |
|---|---|
| ①投票・アンケート | カレーに必ず入れる具は？／年末年始に作りたい料理は？／冬の献立の困りごと（アンケート → 共創のネタに） |
| ②結果発表・共創の報告 | 投票結果をサイトの記事で発表＋次の投票の予告／共創コミュニティ・ラボの進み具合 |
| ③サイトの新着 | 冬の献立・作り置き・年末年始の料理のコラム／食品ロスを減らす料理（みんなのサステナブルテーブル） |
| ④会員限定 | キャンペーン・プレゼント・イベント（ハウスの予定次第） |

- 食品の健康効果（「代謝が上がる」など）は書かない

## ハウスに確認すること
- 開設日の希望
- ハウスの確認（FIX）にかかる日数
- 既存会員へのメルマガで、開設を告知できるか・いつか
- 今後3か月の企画予定（投票・アンケート・キャンペーン・イベント）
- 会員の年代・性別・家族構成の割合
- 会員登録フォームの項目（LINEに引き継げる情報）

## 社内メモ（先方に出すときは外す）
- 一番遠い目標は「サイトに来る数」（1本で届く人の約10%）。他の運用アカウントの実績は届いた人の約0.5〜3%なので、毎週の配信の勝負はここ。1タップで答えられる投票と、その結果発表を軸にする
