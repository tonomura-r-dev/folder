# STORES 予約 × LINE（LINEミニアプリ連携）構築手順

作成：2026-09-07
元資料：STORES 社の営業パンフレット「LINE連携でお客さまの体験と売上を最大化する方法（STORES 予約 × LINE）」2026.08版・27ページ
（`forms.stores.fun` からDLしたPDF。中身は営業資料で、管理画面の操作手順は載っていない。
　手順部分は STORES 予約の公式FAQ・公式サイトの検索結果から補完した。出典は末尾）

> **先に結論：作業は「①STORES側の契約 → ②LINE側の準備 → ③STORES管理画面から申請 → ④LINE Developersで権限付与 → ⑤審査待ち → ⑥公開後のLINE側導線づくり」の6段階。**
> 自分で手を動かすのは①〜④と⑥。⑤は待つだけ。**申請後のキャンセルは不可**なので、①②を先に固めてから③に進む。

---

## 0. これは何か（パンフレットの要約）

- STORES 予約（予約システム）と店舗の LINE公式アカウントを **LINEミニアプリ** でつなぐ。
- できること（パンフ P4〜P6）
  1. **LINEを閉じずに予約が完了**する（外部ブラウザに飛ばないので離脱が減る）
  2. **予約と同時に友だち追加**される（顧客リストが勝手に育つ）
  3. **予約完了通知・前日リマインドがLINEに自動で届く**（無断キャンセル対策）
  4. 予約履歴を条件にした配信（例：前回来店から3か月経過／体験に来たが未入会／誕生月クーポン）
- 事例（P8〜P11）：こし楽 体ほぐし（3か月でLINE予約が全体の2割超）／mimosa. EyeDesign（顧客の約8割がリピーター）／武州ガス（メール連絡→LINEへ移行）

## 1. 料金（パンフ P7・P21〜P24）

| 項目 | 金額（税込） | 備考 |
|---|---|---|
| LINEミニアプリ連携 | **月額 4,400円** | 初期費用なし。STORES 予約の契約プランに**上乗せ** |
| STORES 予約 パッケージプラン フリー | 月額 0円 | 予約50件/月・オンライン決済手数料 5.2%〜 |
| STORES 予約 パッケージプラン スタンダード | 月額 3,300円（年契約。月契約は3,960円） | 決済端末1台無料・POSレジ連携・広告非表示・メルマガ |
| 拡張プラン スモール | 月額 9,790円（通常12,980円） | 予約200件/月・予約ページ10 |
| 拡張プラン チーム（おすすめ） | 月額 19,690円（通常22,880円） | 予約300件/月・スタッフ3人 |
| 拡張プラン ビジネス | 月額 28,600円（通常31,790円） | 予約2,000件/月・スタッフ20人 |
| 拡張プラン エンタープライズ | 月額 66,000円（通常77,000円） | 予約5,000件/月・スタッフ無制限 |

- 拡張プランの割引価格は**年間契約一括払い**の金額。
- **⚠️ LINEミニアプリ連携は「スモールプラン以上の有料プラン」が条件**（公式FAQ）。
  フリー／スタンダードのパッケージプランだけでは使えない。
  → 最低構成は **スモール 9,790円 ＋ LINE連携 4,400円 ＝ 月額 14,190円**。
- LINE公式アカウント自体の料金（コミュニケーション／ライト／スタンダード）は別途。

## 2. 構築手順

### ① STORES 予約の契約（自分でやる）

1. STORES アカウントを作成 → https://id.stores.jp/signup
2. パッケージプランを選ぶ（フリー or スタンダード）。
   決済端末・POSレジも使うならスタンダード（3,300円）が前提。
3. 予約システムの**拡張プランをスモール以上**で契約する（LINE連携の必須条件）。
4. 予約ページを作る：メニュー／スタッフ／営業時間／予約受付・キャンセル期限／アンケート項目。
   ※ 予約ページタイプは「メニュータイプ」と「レッスン・イベントタイプ」の2種類（P13）。
   サロン系はメニュータイプ、教室・セミナー系はレッスン・イベントタイプ。
5. 予約ページを公開し、**LINE無しの状態で予約→完了メールまで一度通す**（LINE連携の審査中も通常予約は動くので、先にここを固めておく）。

### ② LINE側の準備（自分でやる）

1. 店舗の **LINE公式アカウント**を用意する（無ければ https://manager.line.biz/ で新規作成）。
   ※ 公式FAQは「お持ちでない方はLINEミニアプリご利用開始時に新規作成」としているので、
   既存アカウントがあればそれを使える。
2. **LINE Business ID** でログインできるメールアドレス・パスワードを確認しておく（④で LINE Developers に入るため）。
3. LINE公式アカウントの管理者権限を持っているアカウントで作業すること（権限が無いと④が詰まる）。

### ③ STORES 管理画面から申請（自分でやる）

1. STORES 予約 管理画面ホーム → **［サイト設定］ → ［サイト設定（予約）］ → ［LINEミニアプリ連携］**
2. 説明を読んで **申請フォーム**へ進み、送信。
3. **⚠️ 申請後のキャンセルは不可。** 月額4,400円がここから発生する前提で進める。

### ④ LINE Developers で権限付与（自分でやる・申請後に案内が来る）

審査を進めるため、STORES 側の提携先 **㈱Colife の担当者**に、LINE Developers 上で **2種類の操作権限**を付与する。

1. **プロバイダー**の操作権限付与
2. **LINEミニアプリ**（チャネル）の操作権限付与

- LINE Developers → https://developers.line.biz/console/ に、②で確認した LINE Business ID でログイン。
- 権限付与の相手（メールアドレス等）と具体的な操作は、申請後に STORES から届く案内と公式FAQ
  「LINEミニアプリの利用申請後に必要な権限付与の手順」に従う。
- **⚠️ LINEミニアプリ（チャネル）が未作成だと権限付与ができない。** 案内の順番どおりに進めること。

### ⑤ LINE社の審査を待つ（待つだけ）

- 所要期間は公式情報で表記が揺れている：
  - 「1〜2週間前後。審査状況により延びる場合あり」（FAQ「LINEミニアプリ連携とは」）
  - 「1〜2ヶ月ほど」（別の検索結果の要約）
  → **クライアントには「2週間〜、最長で2ヶ月見ておく」と伝えるのが安全。** 申請時にSTORESに確認する。
- この間に⑥の準備（リッチメニュー画像・あいさつメッセージ文面）を先に作っておく。

### ⑥ 公開後：LINE側の導線づくり（自分でやる・ここがDYMの提案領域）

審査が通ると、LINEミニアプリの予約URLが使えるようになる。置き場所は次の2か所が公式推奨。

1. **リッチメニュー**に「予約する」を置く（一等地＝左上 or 中央大）
2. **あいさつメッセージ**に予約URLを入れる（友だち追加直後に予約まで行かせる）

これで完了する挙動（パンフ P4〜P6）：
- 予約完了通知・前日リマインドが**自動で**LINEに届く（設定不要）
- 予約者が**自動で友だち追加**される
- 予約者はLINE上で予約詳細の確認・変更ができる

その上でやる運用（パンフ P6の例。配信自体はSTORES側の顧客リスト＋LINE公式の配信で組む）：
- 前回来店から3か月以上経過した人への再来店案内
- 体験には来たが未入会の人への入会キャンペーン
- 誕生月クーポン

## 3. 提案時に押さえる注意点

- **プラン条件で見積もりが変わる。** 「月額4,400円で導入できます」だけ言うと、スモール（9,790円）が必要だと後で分かって揉める。最初から「LINE連携 4,400円 ＋ 拡張プラン スモール以上」で出す。
- **審査期間がある。** 「今月中に動かしたい」案件には向かない。最短でも2週間、余裕を見て2ヶ月。
- **申請のキャンセル不可。** 申請ボタンはクライアント合意後に押す。
- LINE公式アカウントのメッセージ配信数は、LINE側のプラン（コミュニケーション200通／ライト5,000通／スタンダード30,000通）に依る。通知・リマインドがどの枠にカウントされるかは要確認。
- パンフのP17「メルマガ・DM配信」は**メールのみ**と明記。LINEでのセグメント配信は、STORESの顧客リストで抽出 → LINE公式の配信、という**手組み**になる想定。ここは要確認。

## 4. 未確認事項（PC側で公式FAQを開いて潰す）

クラウド環境からは `stores.fun` / `reserve-faq.stores.jp` / `faq.coubic.com` が全てegressブロックで開けない。以下はPC側で確認すること。

1. 審査期間の正（1〜2週間 か 1〜2ヶ月 か）
2. ④の権限付与の具体的な操作画面（付与先のアカウント名・ロール名）
3. LINE公式アカウントは**認証済みアカウント**が必要か（未認証でも可か）
4. 予約完了通知・リマインドがLINE公式アカウントの配信通数にカウントされるか
5. 予約履歴を条件にしたLINE配信（P6）が、STORES管理画面から直接できるのか、手組みなのか
6. 既存のLINE公式アカウントに、既に外部ツール（Lステップ等）が繋がっている場合の共存可否
