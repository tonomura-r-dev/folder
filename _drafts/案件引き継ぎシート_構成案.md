# 案件引き継ぎシート 構成案（Web広告＋LINEOA統合版）

## 前提
- 現行スプレッドシート（Google Sheets）の実物は、本セッションの環境からアクセスできず未閲覧。
- 依頼文中の「現状の主な項目（参考）」リストと、以下3要件をもとにゼロから構成を設計した。
  1. 構造の最適化（共通/Web広告/LINEOAの分離）
  2. LINEOA特有項目の追加
  3. 入力しやすさ（プルダウン/チェックボックス化、必須/任意の可視化）
- 実物のシートの列見出しが分かれば、この案をベースに微調整できる。

## 設計方針
- **1案件1行の「共通マスタ」**と、**媒体ごとの「明細シート」**に分割する（Web広告用・LINEOA用）。
- 3シートを「案件ID」で紐付け、クライアント名などの重複入力をなくす。
- 入力はできる限り**プルダウン／チェックボックス化**し、フリーテキストを最小限にする。
- 必須項目は色分け＋「必須/任意」列で、誰が見ても一発でわかるようにする。

## シート構成（4シート）

| シート名 | 役割 |
|---|---|
| ①INDEX（案件マスタ） | 全案件共通の基本情報。1案件1行。 |
| ②Web広告_引き継ぎ | Web広告運用がある案件のみ、案件IDに紐づけて詳細記入 |
| ③LINEOA_引き継ぎ | LINEOA運用がある案件のみ、案件IDに紐づけて詳細記入 |
| ④入力ルール・凡例 | プルダウンの選択肢マスタ、記入例、必須/任意の凡例 |

## 使い勝手向上の実装Tips（Google Sheets側の設定）

- **必須項目の可視化**：必須列は条件付き書式で「空欄なら赤枠」、ヘッダー背景色を必須＝赤系／任意＝グレー系に固定する。
- **引き継ぎ漏れ防止**：①INDEXシートに「②③記入チェック」列を追加し、運用媒体区分にチェックが入っているのに②か③に対応する案件IDの行がない場合、`COUNTIF`＋条件付き書式で自動的に赤字警告を出す。
- **プルダウンの一元管理**：①②③の全プルダウンは④シートの選択肢マスタをデータの入力規則（リスト）で参照する。選択肢の追加・変更は④シートだけ直せばよい。
- **有無系の項目は必ずチェックボックス化**：あいさつメッセージ有無、ステップ配信有無、有人チャット有無、連携ツール有無など「あり/なし」をテキストで書かせない。
- **消化率アラート**：メッセージ消化率は数式で自動計算し、80%超で警告色にする（枠消化超過による配信停止を未然に防ぐ）。
- **案件ID列とヘッダー行は固定（ウィンドウ枠の固定）**し、横スクロールしても迷子にならないようにする。
