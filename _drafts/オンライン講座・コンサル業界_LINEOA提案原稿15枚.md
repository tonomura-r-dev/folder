# オンライン講座・コンサル業界 LINE公式アカウント提案原稿（15枚・モードA）

作成：2026-10-30（殿村さん依頼「すなおコンサルみたいな情報商材を扱っている業界の汎用資料」）
対象：無料セミナー・説明会・無料特典を入口に、オンライン講座・オンラインサロン・個別コンサルを販売する事業者（広告で集客するところ）
業界の呼び方：資料では「オンライン講座・コンサル業界」（「情報商材」は使わない。殿村さん決定）

数字のラベルは3種類だけ使う。
- 調査データ：出典つき（最下部に一覧）
- 弊社の目安：DYMのSIMで使っている係数
- 仮に：根拠を置いて仮に置いた数字（3つまで）

---

## 置いた前提（差し替え可）

1. **CV3段**：①無料特典の受け取り・無料セミナーの申込み（軽いCV）→ ②セミナー・説明会への参加、個別相談（主なCV）→ ③本講座・サロンへの入会（最終CV）→ 継続・上位講座・紹介（LTV）
2. **入口の型は2つ**：A＝フォーム申込型（LPのフォームで申込み。すなおと同じ）／B＝LINE登録型（LINE追加で特典→セミナー案内）。資料はAを主に書き、Bは同じ流れの前倒しとして扱う
3. **主役の施策**：この業界は「申込み→当日参加→入会」の歩留まりで売上が決まるので、離脱防止より**申込み後のナーチャリング（参加率・入会率）**を主役に置く
4. **仮に置いた数字（3つ）**：LPの申込率 3%／セミナー参加者の入会率 10%／本講座の単価 30万円

■ スライド5：エンドユーザー行動心理：申込む前も後も「本当に大丈夫か」を確かめている
【目的・意図】：この業界ならではの不安（怪しくないか・高額を売られないか・自分にできるか）を言葉にする
【レイアウトイメージ】：左＝お客様の心の声4つ／右＝それぞれにLINEで返すこと
【メインキャッチコピー】：不安を消すのは、広告ではなく申込み後の中身
【スライド本文・データ】：
お客様の心の声 → LINEで返すこと
①「無料と言って、最後に高い講座を売られるのでは」→ 費用と申込みの流れを先に見せる
②「本当に成果が出るのか。自分にもできるのか」→ 自分に近い受講生の声・実例を見せる
③「平日の夜に、時間を取って参加できるか」→ 日時の確認と前日・当日のご案内
④「講師はどんな人か。評判はどうか」→ 講師の考え方・実績を事前に伝える
背景（調査データ）：副業・投資などのノウハウとして売られる「情報商材」は、国民生活センターの相談の分類の1つとして扱われ、消費者庁も注意喚起をしている。お客様は「怪しくないか」を確かめてから動く
【LINE・図表モックアップ内容】：4行の対応表（心の声｜LINEで返すこと）
【コンサルタントプレゼン原稿】：
この業界のお客様は、ほかの業界よりも慎重です。ニュースや行政の注意喚起で「無料セミナーから高額な講座を売られた」という話を見ているからです。だから、申込みをしても当日来ない、参加しても入会を決めきれない、ということが起きます。逆に言えば、この4つの不安に先回りして答えられれば、参加も入会も上がります。その答えを置く場所として、LINEが一番向いています。

■ スライド7：解決策コンセプト：売り込みではなく、納得して選んでいただく流れへ
【目的・意図】：施策の考え方を1枚で言い切る
【レイアウトイメージ】：左右比較（今の流れ／LINEを入れた流れ）
【メインキャッチコピー】：申込みの後も、LINEで話を続ける
【スライド本文・データ】：
今の流れ：広告 → LP → 申込み → メールで当日URL → セミナー → その場で入会の判断
LINEを入れた流れ：広告 → LP → 申込み → LINEでつながる → 当日までに講師・実例・費用を知る → セミナー → 入会しなかった方にも、次の案内を続ける
変わること
・当日のURLやご案内がLINEに届くので、見落としが減る
・入会の判断を「その場の1回」にしない
・入会しなかった方を、次回のセミナー・別の講座の見込み客として残せる
【LINE・図表モックアップ内容】：左右の流れ図。右の「LINEでつながる」だけ緑
【コンサルタントプレゼン原稿】：
今の流れは、申込みの後はメールでURLが届くだけ、入会の判断はセミナー当日の1回きり、という形が多いと思います。これを、申込みの後もLINEで話を続ける形に変えます。当日までに講師のことや実例、費用を知っていただく。その場で決めなかった方にも、次の機会をLINEで案内し続ける。売り込むのではなく、納得して選んでいただく流れです。

【目的・意図】：同業がLINEをどう使っているかを、確かめられた事実だけで見せる
【レイアウトイメージ】：上＝4つの型の表／下＝確認できた実例の表
【メインキャッチコピー】：多くは「特典を渡して終わり」。その後の流れが差になる
【スライド本文・データ】：
運用の型
・特典型：友だち追加で動画・PDFなどの特典を渡す
・診断・アンケート型：追加直後に質問し、答えで配信を出し分ける

確認できた実例（公式サイト・プレスリリースで確認）
