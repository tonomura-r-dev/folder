# インクアート（プリントアース）LINE公式アカウント運用 案件まとめ

2026年10月8日時点。はじめてこの案件に関わる人向けのまとめです。

## 1. どんな案件か

インクアート株式会社が運営するネット印刷通販「プリントアース」のLINE公式アカウントを、DYMが運用しています。名刺やチラシ、年賀状、カレンダーなどの印刷物をネットで注文できるサービスです。

DYMの仕事は、毎月の配信の企画、配信する文章、画像の指示書（備考）、配信の設定、数字の振り返りです。目的は、LINEから会員登録や注文を増やすことです。先方の窓口は丸山さんで、配信の前に内容を確認してもらいます。

## 2. 最初に覚える言葉

| 言葉 | 意味 |
|---|---|
| 友だち | LINE公式アカウントを登録している人。配信が届く相手 |
| 配信 | 友だちに送るメッセージ。インクアートは「テキスト」と「バナー画像」の2つを続けて送る |
| リッチメニュー | トーク画面の下にずっと出ているメニュー。商品一覧や会員登録のボタンが並んでいる |
| アイテム名 | バナー画像に付ける一文。トーク一覧に表示される |
| 開封率 | 配信を開いた人の割合 |
| ブロック | 友だちが配信を受け取らない設定にすること。増えると配信が届く人が減る |
| 絞り込み配信（セグメント） | 全員ではなく、条件で選んだ人にだけ送ること |
| オーディエンス | 「この配信を開いた人」のように、絞り込み配信に使う人のまとまり |
| CPF | 友だちを増やすための広告（友だち追加広告）。友だち1人ごとに費用がかかる |
| utm | ページのURLの後ろに付ける印。GA4（サイトの分析ツール）で、この配信から来た人の数や注文を数えられる |
| LP・飛び先のページ | 配信のリンクを押したときに開く商品のページ |

## 3. 友だちはどんな人か

メッセージが届く人は約1,600人です。ただし大半は、4〜8月にCPFで集めた人です。いま実際に反応があるのは、そのうち約700人です。CPFを止めてからは、新しい友だちは月に10人ほどしか増えていません。

LINEの管理画面で見ると、女性が約6割、55〜64歳が約7割、50歳以上が85%で、35歳未満は0%です。会社の総務や事務で、名刺やチラシ、年末のご挨拶の品を手配している方を思い浮かべると近いです。推し活や同人誌など若い人向けの商品は、この友だちにはほとんど届きません。

## 4. 毎月の配信の組み方

配信は月4本です。先方の8月の配信は、新商品の紹介が1本、お知らせ（受付の締切時刻など）が1本、キャンペーンが2本でした。最近は、先方ができるだけ新商品を紹介したい意向なので、新商品の紹介が増えています。

キャンペーンは、始まりと締切の2回に分けて知らせます。割引は最初に知らせます（定価で注文した直後に割引が出ると、先に買った人が損をするため）。

配信先は、ふだんは反応のある約700人に絞ります。全員に送ると開く人よりブロックする人の割合が大きく増えるからです（9月に全員へ送った回は3日でブロックが25人増え、絞り込みの回は5〜9人でした）。年賀状のように誰にでも関係がある話題のときだけ、全員に送ります。

曜日と時間は、広告で実際に注文が入ったデータに合わせています。月曜がいちばん注文が多く、時間は18時台の注文率が高いので、いまは18:05の配信が中心です。

## 5. 文章とバナーの決まりごと

- 飛び先のページに書いてあることだけを書きます。検索で見つけた情報は入れません
- 割引は必ず「最大」を付けます（例：最大25%OFF）。画像の中の文字も同じです
- 期限は「～10月31日」のように書きます
- 絵文字は行の頭に1つだけ、1本の配信で3〜4個までにします
- スマホでは1行に入る文字数が少ないので、1行は11文字くらいで改行します。テキストは1つの吹き出しで500文字までです
- テキストとバナーで、同じ物は同じ言葉で呼びます（例：バナーが「3タイプ」なら本文も「3タイプ」）
- アイテム名に使える絵文字は✨です。🎍は管理画面ではじかれました
- 配信管理シートの「企画案」には、アイテム名と同じ文を入れます
- 新商品のバナーは、サイトの商品写真を使います。画像生成で描いた商品の絵は、先方から何度も差し戻されています

「備考」はデザイナーへの指示書です。サイズ、上・主役・中・下に置く文字、ビジュアルを5〜6行で書きます。理由や配信先などの運用の話は書きません。主役の文字は「120px以上」と書きます（年齢が高めの友だちでも読める大きさ）。

## 6. 数字の見方

9月に約700人へ送った3本は、開封率が36%、33%、30%と下がりました。同じ人に続けて送ると、だんだん開かれなくなります。全員に送った回の開封率は14〜17%です。LINE全体の平均は、開封率が約55%、ブロック率が約36%です。インクアートのブロック率は38%ほどで平均並みですが、開封率は平均より低めです。

テキストを読んでいるのは、開いた人の15%以下です。ほとんどの人はバナーしか見ていないので、大事なこと（割引率や期限）はバナーに入れます。

リンクを押した人が20人未満だと、LINEの画面には数字が出ません。インクアートは毎回20人未満なので、注文の数はGA4で見ます。そのため、配信のリンクには必ずutmを付けます。

| 場所 | 付ける印 |
|---|---|
| 配信のリンク | `utm_source=LINEOA&utm_medium=crm&utm_campaign=日付_英単語`（例：`20261005_NewYearCard_EarlyBird`） |
| リッチメニュー | `utm_source=LINE&utm_medium=social&utm_campaign=richmenu` |

9月の申し込みは、会員登録4件・購入4件で、すべてリッチメニューからでした。リッチメニューが見られるのは、9割近くが配信の当日と翌日です。配信でトークを開いてもらい、リッチメニューで申し込んでもらう、という流れになっています。

## 7. 10月の配信

10月は、年賀状印刷の超早割（最大25%OFF・10月31日受付分まで）で注文を取る月です。リッチメニューのいちばん大きな枠も、10月中は超早割にしています。

| 配信日 | 内容 | 配信先 |
|---|---|---|
| 10/6(火) | 年賀状 超早割のスタート（配信済み） | 全員（1,602人） |
| 10/13(火) | 中綴じカレンダー（壁掛けタイプ） | 約700人 |
| 10/19(月) | 新商品の紙製ランチョンマット | 約700人 |
| 10/26(月) | 年賀状 超早割の締切のお知らせ | 約700人＋10/6に開いた人 |

10/6は約17%が開きました。同じく全員に送った9/29（シール）の15.6%を上回り、年賀状はふだん開かない人にも届く話題でした。10/26の配信先に使うので、10/6を開いた人のオーディエンスを作っておく必要があります。

## 8. 仕事の流れ

1. 投稿案：企画案、文章、備考を作る
2. FIX：社内と先方（丸山さん）の確認を通す
3. デザイン：備考をもとにバナーを作る
4. 配信設定：管理画面で配信先・日時・アイテム名・リンクを入れて予約する

先方への確認では、割引のない新商品を「キャンペーン」と呼ばないようにします（先方から直されたことがあります）。先方から修正の依頼が来たときは、言われた所だけを直します。

## 9. 気をつけること

- プリントアースのサイト（inkart.jp）は、クラウド環境のClaudeからは開けません。ページの本文は、PCのブラウザでコピーして渡します
- 管理画面のプレビューは、長い文章の下が切れて見えたり、古い画面のままだったりします。最後は文章そのものと照らし合わせます
- 配信の予定を共有するときは、配信管理シートの12列（配信月／配信日／曜日／配信予定時間／関連要素／企画案／セグメント／企画内容／URL／source／medium／campaign）の順で出します

## 10. これから

配信だけでは、会員登録・購入はそれぞれ月に数件にとどまる見込みです。一方で、広告経由の購入は毎月450〜850件あります。そこで、購入した方をLINEの友だちにする「サンクスLINE誘導」と、サイトから離れそうな方にLINEを案内する「離脱防止」をセットで提案する予定で、提案資料はできています（初期11.5万円・月6万円〜）。11月からの開始を目指しています。
