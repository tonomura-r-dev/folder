## 0. この文書の読み方（Claude側の評価）

**結論は「関係ある」。** 当初の見立てどおりだった。

**ただし出典の扱いに注意が3点。**

1. **厚労省資料に「LINE公式アカウントのリッチメッセージ」を名指しした記載は無い**
   （調査側が明記している）。以下は**メルマガ・医療機関アプリ・SNS広告の一次資料を
   LINEに当てはめた法的評価**であって、LINEを直接名指しした通知ではない。
2. **条文番号・要件の骨格は信頼してよい**（医療法第6条の5、施行規則第1条の9の2、
   薬機法第66条・第68条・第85条）。一方、**改正日・Q&Aの版数・ネットパトロールの件数は未検証。**
   資料名で引用するときは原典に当たること。
3. **これは法的助言ではない。** 自由診療・未承認薬を含む配信は、
   **所轄都道府県の医療広告担当と薬務担当に事前相談**するのが正しい手順
   （調査側も同じ結論）。クライアント側に既存の運用ルールがあれば、それが最優先。

## 1. 5行の要約

- 友だち限定のLINE配信も、**受診を促し医療機関を特定できれば「医療広告」に該当**する。
- 自ら友だち追加した人への配信は**限定解除の対象になり得る**が、
  虚偽・誇大・No.1・体験談などは**禁止のまま**。
- 自由診療を案内する場合、**治療内容・費用・期間／回数・主なリスク**を、
  **リンク先だけでなく同一配信内に**明示する必要がある。
- 未承認薬は追加情報の開示が必要で、商品名や効果を強調すると
  **薬機法第66条・第68条**にも抵触する危険がある。
- 休診・診療時間・予約方法などの事実情報は基本的に配信可能。
  **キャンペーンや割引の過度な強調は避ける。**

## 2. ★ここが設計を変える：同一配信内に書く必要がある

**「詳しくはこちら」で遷移先に費用・リスクを書く方法は不十分。**
厚労省の事例解説書が、必要事項をリンク先だけに記載した例を
**限定解除要件を満たさない事例**として示している。
複数のSNSやサイトに情報を分散させ、どの媒体にも全情報が無い方法も不十分。

同一配信内に、**読める文字サイズで一体的に**表示するもの：

1. 治療内容
2. 標準的費用（または費用の幅・上限下限）
3. 標準的な期間・回数
4. 主なリスク・副作用
5. 問い合わせ先

### → 1040×1040の画像1枚では成立しない

情報量と文字サイズが両立しないため、調査側の推奨構成は：

```
吹き出し1：リッチメッセージ（画像）＝ 中立的な見出しにとどめる
吹き出し2：テキスト ＝ 必須事項5点をまとめる
（本文と画像を一体の配信として容易に確認できるようにする）
```

**⚠️ つまり自由診療の訴求回は 2吹き出しが前提。通数が倍になる。**
プリントアースで「1配信＝1吹き出し」に統一したのと逆方向。
**ノーストの月の通数上限を確認しないと本数が決められない。**

## 3. 広告該当性と限定解除

### 3-1. 医療法上の「広告」

医療法第6条の5第1項は媒体を限定せず、「文書その他いかなる方法によるを問わず、
広告その他の医療を受ける者を誘引するための手段としての表示」を規制対象とする。

判断要素：①**誘引性**（受診を誘引する意図）②**特定性**（医療機関を特定できる）
③医療に関する情報であること。

LINE公式アカウントはアカウント名・アイコンで通常は医療機関を特定できる。
そこに診療メニュー・治療効果・予約・キャンペーンを配信すれば誘引性も認められる。
**「友だち限定だから広告ではない」は成立しない。**

### 3-2. 2018年改正の意味

改正前、医療機関のウェブサイトは「患者が自ら検索して閲覧する」ため原則として
広告に当たらない運用だった。美容医療等の不適切表示が問題となり、
**改正後はウェブサイトその他の誘引的表示も広告規制の対象**に。
同時に、患者が自ら求める媒体について**限定解除**が設けられた。

### 3-3. Q&Aでの言及（LINEに近い先例）

| Q | 対象 | 扱い |
|---|---|---|
| Q1-9 | 患者がダウンロードした医療機関アプリ | 広告に該当するが**限定解除の対象になり得る** |
| Q1-10 | 会員制・限定サイト | 同上 |
| Q1-11 | **患者が希望して受信するメールマガジン**・パンフレット | 同上 |

→ **友だち追加は「患者等が自ら求めて入手」に当たる可能性が高い**（Q1-11に最も近い）。

### 3-4. ただし限定解除が使えない場合

- 本人の明確な意思なく名簿から一斉配信する
- **景品を条件に形式的に追加させる**
- 広告ネットワーク上で不特定多数に配信する
- **LINE広告から直接、不特定多数に治療広告を表示する**
  → 一般向けLINE広告は「自ら求めた」とは言いにくく、限定解除の第1要件を満たさない可能性が高い

**※CPF（友だち追加広告）で集めた友だちへの配信の扱いは、この4点目に近い論点。要確認。**

### 3-5. 限定解除の要件

**すべての場合に必要**
1. 患者等が自ら求めて入手する情報であること
2. **問い合わせ先を明示**（電話番号・メールアドレス等）

**自由診療で追加**
3. 通常必要となる**治療内容・費用**（標準額または上限下限）**・治療期間・回数**
4. **主なリスク・副作用**

**限定解除は「何でも書ける制度」ではない。**
虚偽・比較優良・誇大・体験談・誤認を招くビフォーアフターは解除後も禁止。

## 4. 薬機法が効く場面

| 条文 | 内容 |
|---|---|
| 第66条第1項 | **何人も**、医薬品等の名称・製造方法・効能・効果について虚偽誇大な広告をしてはならない |
| 第66条第2項 | 医師等が効能効果を**保証したと誤解されるおそれのある記事**も第1項違反とみなす |
| 第68条 | **未承認**の医薬品・医療機器等の名称・効能・効果の広告を禁止 |
| 第85条 | 第66条第1項・第68条違反は**2年以下の拘禁刑または200万円以下の罰金**（併科あり） |

薬機法上の広告該当性（平成10年9月29日医薬監第148号）：
①顧客誘引の意図が明確 ②特定の商品名が明らか ③一般人が認知できる状態。

**→ 友だち限定でも、特定の未承認医薬品名と効能を示して処方を促せば広告と評価され得る。**

### 医薬品名の出し方

| 表現 | 可否 |
|---|---|
| 「ジェネリック医薬品を採用しています」 | 特定商品を指さない ＝ 可 |
| 「AGA治療薬を取り扱っています」 | 治療の種類として表示できる余地 |
| 「○○錠を処方します」 | **特定の商品名＝原則として広告可能事項ではない** |

処方薬は**医薬品等適正広告基準**で一般消費者向け広告を行わないことが求められる。
→ **ブランド名を前面に出さず、診療内容を中心に構成する。**

### 未承認薬・適応外使用を伴う自由診療

限定解除の通常要件に**加えて**、未承認である旨／入手経路／国内承認品の有無と流通状況／
海外での承認状況／主なリスク／安全性情報が不十分ならその旨／
**医薬品副作用被害救済制度の対象外になる可能性**、の開示が要る。

**医療法上の限定解除は、薬機法第68条の適用を免除しない。**

## 5. NG・高リスクな表現（LINE配信で使わない）

※「要回避」には、直ちに刑罰対象と断定できないが厚労省が「厳に慎むべき」とする類型を含む。

| 表現例 | なぜ駄目か | 根拠 |
|---|---|---|
| 「絶対安全です」 | 虚偽広告の典型 | 医療法6条の5第1項 |
| 「必ず成功」「100%治ります」 | 結果保証＝虚偽・誇大 | 同第2項第2号 |
| 「日本一」「地域No.1」「最高の技術」 | **客観的事実でも比較優良広告は禁止** | 同第2項第1号 |
| 「芸能人○○さんも推薦」 | 著名人利用で優良と誤認させる | 同第2項第1号 |
| 「患者様の声：1回で人生が変わりました」 | **体験談は禁止** | 同第2項第4号／施行規則1条の9第1号 |
| **口コミを画像化して再配信** | 元が自主投稿でも広告転用すれば体験談広告 | 同上 |
| ビフォーアフター写真＋「劇的変化」 | 治療内容・費用・リスクが近接表示されない | 同第2項第4号／施行規則1条の9第2号 |
| 加工した／照明・角度を変えた比較写真 | 虚偽・誇大 | 同第1項・第2項第2号 |
| 「1回で完了」（実際は通院要） | 期間・回数の虚偽誇大 | 同第1項・第2項第2号 |
| 「満足度99%」だけ掲載 | 調査対象・方法・回答数が無く根拠不明 | 同第1項・第2項第2号 |
| 「副作用はほとんどありません」 | リスクの過小表示。限定解除要件も欠く | 同第2項第2号・第3項 |
| 「最新の治療なので高い効果」 | 根拠なき優良性の誇張 | 同第1項・第2項第2号 |
| **「今だけ50%OFF」「通常10万円→本日5万円」を大きく表示** | **費用の過度な強調＝厳に慎むべき類型。**通常価格が実在しなければ虚偽広告。二重価格は景表法第5条も | ガイドライン「広告の品位」／景表法5条 |
| **「残り3名」「あと24時間」の反復** | 虚偽の希少性・期限なら虚偽誇大。事実でも過度な受診誘引は要回避 | 医療法6条の5第1項・第2項第2号 |
| 「無料相談で美容グッズをプレゼント」 | 医療と無関係な利益による誘引＝品位を損ねる | ガイドライン |
| 「月額○円で受け放題」だけ強調 | 費用の過度な強調＋条件・総額・期間の欠落 | ガイドライン／同第2項第2号 |
| 「○○治療 9,800円〜」で回数・総額・リスクはリンク先だけ | **限定解除要件を満たさない** | 同第3項／施行規則1条の9の2／事例解説書 |
| 「未承認の○○注射で確実に若返る」 | 未承認薬の商品広告＋効果保証 | 薬機法66条・68条／医療法6条の5 |
| 「当院では○○錠を処方」と商品名を大きく | 広告可能事項でなく、処方薬の一般向け広告にもなる | 医療法6条の5第3項／薬機法66条 |
| 「厚生労働省認定クリニック」「国が効果を保証」 | 実在しない認定・保証は虚偽 | 医療法6条の5第1項／薬機法66条第2項 |

## 6. 安全に配信できる内容

| 内容 | 表現例 |
|---|---|
| 休診案内 | 「9月10日は院内研修のため休診します」 |
| 診療時間変更 | 「10月から土曜日の診療時間を9:00〜13:00に変更します」 |
| 臨時休診・災害対応 | 「台風接近のため、本日の午後診療を休止します」 |
| 予約方法 | 「予約はLINE予約画面または電話から受け付けています」 |
| 予約システム停止 | 「メンテナンス中は電話でご予約ください」 |
| 所在地・電話番号・アクセス | 広告可能事項 |
| 標榜診療科 | 法令上認められた診療科名のみ |
| 担当医・診療体制 | 「金曜日は○○医師が担当します」 |
| 標準的な料金案内 | 「初診料○円」（条件を明示し、安さを強調しない） |
| 一般的な啓発情報 | 「熱中症予防のため、こまめに水分を」 |
| 公的機関の情報案内 | 厚労省・自治体の情報へ案内（出典明示・診療効果と結び付けない） |

**⚠️ 啓発情報でも「この症状なら当院の○○治療で解決」「今すぐ予約」を付けると、
全体として広告になる。** 付けた瞬間に通常の規制がかかる。

## 7. 違反したとき

### 医療法
1. 都道府県・保健所設置市・厚労省の**ネットパトロール**が把握
2. 事実確認・行政指導・修正削除依頼
3. 報告徴収／立入検査（第6条の8第1項）
4. **広告の中止・内容訂正命令**（同第2項）
5. 命令違反・虚偽広告等 → **6月以下の拘禁刑または30万円以下の罰金**（第87条）
   報告拒否・虚偽報告・検査拒否 → 20万円以下の罰金（第89条）／法人に両罰規定（第90条）

**虚偽広告は第6条の5第1項に直接違反。** 限定解除要件を欠く広告は、
行政指導→報告徴収→中止訂正命令を経て、命令違反が処罰対象になるのが基本。

### 薬機法
第66条第1項・第68条違反 → **2年以下の拘禁刑または200万円以下の罰金**（第85条）。
第66条第1項の虚偽誇大広告には課徴金制度もある（第75条の5の2）。

### ネットパトロールの実績（※件数は未検証）
2025年度資料・2026年2月28日時点：審査2,092件／違反確認1,842件／通知1,819件／
改善・広告中止1,238件／改善されず自治体へ情報提供377件。
※監視対象として抽出されたサイトの実績であり、全医療機関の違反率ではない。

## 8. ノーストのLINE運用ルール（この調査からの実装）

1. **休診・診療時間・予約方法は、正確な事実のみで配信する**（限定解除不要）
2. **自由診療を案内するときは画像だけで完結させない。**
   同一配信内に費用・回数・期間・リスク・問い合わせ先を表示（＝2吹き出し）
3. **「詳細はウェブへ」だけで必須事項を省略しない**
4. **体験談・口コミ転載・ランキング・No.1・絶対表現を使わない**
5. **ビフォーアフターは原則使わない。** 使うなら近接した詳細表示を徹底
6. **割引は事実でも前面に出さない。** 架空の通常価格や反復する期間限定表示は行わない
7. **未承認薬・適応外使用・医薬品ブランド名を含む配信は、通常の投稿とは別に事前審査**
8. 未承認薬については**所轄都道府県の医療広告担当と薬務担当の双方に事前相談**
