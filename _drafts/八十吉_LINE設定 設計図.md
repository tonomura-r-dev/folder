## 4. 応答メッセージ（リッチメニューに紐づく6本）

**場所：ホーム → 応答メッセージ**
各マスの送信テキストをキーワードに設定し、下記を返す。
**応答メッセージは通数にカウントされない。**

### 4.1 ご予約

キーワード：`ご予約` `予約` `よやく`

```
ご予約ありがとうございます。

下記をコピーして、埋めたうえでお送りください。

－－－－－－－－－－
ご希望日：　　月　　日（　）
お時間　：　　時　　分ごろ
人数　　：　　名
ご指名　：
ご要望　：
－－－－－－－－－－

内容を確認のうえ、担当者よりお返事いたします。

※お席の空き状況を確認いたしますので、
　この時点ではご予約は確定しておりません。
```

**最後の2行は必ず残す。**リクエスト制であることをここで明示しておかないと、
「予約したつもりだった」という行き違いが起きる。

### 4.2 今から行く

キーワード：`今から行く` `今から`

```
本日の空席をご案内いたします。

「今から〇名」とメッセージをお送りください。
確認してすぐにお返事いたします。
```

```

★店舗様よりご提供いただき次第、差し替えます。
```

### 4.4 はじめての方へ

## 6. 権限

### 6.1 方針

| 項目 | 値 |
|---|---|
| 付与できる人数 | 権限の種類を問わず**100名まで**（追加費用なし） |
| 付与の方法 | 招待。**IDやパスワードは共有しない**（各自が自分のLINEアカウントでログイン） |
| 招待URLの有効期限 | **発行から24時間** |
| 付与する相手 | パフォーマー（エイトビート所属）、店長 |
| 付与のタイミング | **先方の了承後**（提案資料S22でチェックをもらってから） |

### 6.2 権限の種類

**★未確認：「チャットは可・配信は不可」の権限が選べるか。**
選べるなら、パフォーマーにはその権限を付与する。誤って156名へ一斉配信する事故を構造的に防げる。
選べない場合は、運用マニュアルで注意喚起する。

**実機で 設定 → 権限管理 → メンバーを追加 を開いて、選択肢を確認すること。**

### 6.3 記録

付与したら `八十吉_権限管理台帳.xlsx` に1行追加する。
辞めたら権限を削除し、台帳に削除日を入れる。月に一度、権限管理画面と台帳を突き合わせる。

### 6.4 担当者の割り当て

**チャットルームごとに担当者を設定できる**（2023年提供開始）。
ご予約のトークに、指名されたパフォーマーを担当として割り当てる運用にする。

## 7. タグ

**LINE公式標準では手動付与のみ。**チャットでやり取りした方にしか付かず、
既存156名には遡って付けられない。これから接点を持つ方から順次溜まる。

| タグ | 付ける相手 | 用途 |
|---|---|---|
| ご予約あり | ご予約のご希望を送ってこられた方 | 見込み度の高い層 |
| ご指名あり | 出演者を指名された方 | エイトビートのコア顧客候補 |
| エイトビート興味あり | 会話で新店舗・系列店に興味を示された方 | 開店告知の優先リスト |

**出演者別タグ（「指名：Aさん」）は保留。**リピート施策に該当し、
「行わない」という方針とぶつかるため。やるなら先方への方針確認が要る。

4. **リッチメニューを作成**（2章）※画像アップロード → 6マスにテキストアクションを設定

## 9. 公開の判断
