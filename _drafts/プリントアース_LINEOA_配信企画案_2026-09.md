作成日：2026-08-31
前提：26年8月ADレポート（Gemini分析）／実画面スクショ／過去CR素材／現行リッチメニュー
目的：**CVR改善 → CPA低減**。CV＝注文完了／見積もり完了／問い合わせ完了

## 1. 実画面診断：いま起きていること

### 1-1. あいさつメッセージに **明確なバグ** がある

現行は3吹き出し構成。1つ目テキストの最後が——

> 👇 **アンケートはこちら**

そのすぐ下に置かれているバナーは **「新規会員登録はこちら」**。

**矢印が指している先と、バナーの中身が違う。**
ユーザーは「アンケート」と言われて「会員登録」を押すことになる。押した瞬間に
「話が違う」と感じる導線で、ここで確実に一定数が落ちています。**最優先で修正。**

### 1-2. 3つの吹き出しの中身が、それぞれ逆効果

| 吹き出し | 現状 | 問題 |
|---|---|---|
| ① テキスト | 「このアカウントでは下記のような情報を配信中🔍 ✅新商品の情報 ✅季節のキャンペーン情報」から始まる | **自社都合の配信予告が先頭**。広告で「1.2円〜」「1,000Pt」を見て来た人の関心はそこにない |
| ① 続き | 「【最大10万円分クーポン】をゲットできるキャンペーン実施中」 | 検索層が「**自分には関係ない（高額発注用だ）**」と判断して離脱。ADレポの指摘どおり |
| ② バナー | 「2分で完了！新規会員登録で最大10万円分」＋「LINEスタンプカードとの併用で…」 | **1枚に情報を詰めすぎ**。10万円＋スタンプカード＋会員登録の3要素で、何をすればいいか消える |
| ③ テキスト | 「※この公式LINEでは個別メッセージは対応しておりません」**だけの独立した吹き出し** | **最後に残る印象が「対応してもらえない」**。独立吹き出しは最も目立つ置き方で、最悪の位置 |

### 1-3. リッチメニュー：一等地がCVから最も遠い

```
現行（2×3）
┌──────────┬──────────────┬──────────────┐
│ テンプレDL │ 納期カレンダー │ 購入はこちらから │ ←赤
├──────────┼──────────────┼──────────────┤
│ サンプル請求│ お見積もり・   │ ショップカード   │ ←橙
│            │ お問い合わせ   │                │
└──────────┴──────────────┴──────────────┘
```

| 問題 | 中身 |
|---|---|
| 一等地の浪費 | 視線は左上から入る。そこに**CVから最も遠い「テンプレDL」**が置かれている |
| **推し活・グッズの入口がゼロ** | Meta広告で推し活グッズに惹かれて来た人が、**自分の目的をメニューに見つけられない**。ブロック要因 |
| 「購入はこちらから」が汎用 | 商材分岐がなく、押しても総合トップ。BtoCもBtoBも迷子になる |
| ショップカードが1/6を占有 | LINEのポイント機能。CVには直結しない |

> ✅ 良い点：緑ベースでCTAだけ赤・橙にする色設計、アイコンの統一感は**そのまま活かせる**。
> 作り直すのは**配置と項目**であって、デザインシステムではない。

## 2. あいさつメッセージ 改修版（確定案）

### 吹き出し①（テキスト）

```
{ユーザーの表示名}さん、はじめまして。
印刷通販のプリントアースです。

友だち追加ありがとうございます。
1,000円分のポイントをお渡しするので、受け取ってください。

会員登録だけ、30秒で終わります。
▼こちら
https://www.inkart.jp/entry/regist/?utm_source=LINEOA&utm_medium=crm&utm_campaign=20260901_greeting_signup

チラシ5万枚も、アクスタ1枚も、同じ工場で刷っています。
下のカードから、作りたいものを選んでください。
```

**変更点**

| Before | After | 理由 |
|---|---|---|
| 配信内容の予告から始まる | **1,000円分のオファーから始まる** | 広告で見た約束をその場で回収 |
| 最大10万円分クーポン | **1,000円分のポイント** | 「自分には関係ない」を消す |
| 👇アンケートはこちら（バナーと不一致） | **▼こちら＋会員登録URL**（バナーと一致） | 導線バグの修正。アンケートはあいさつから外し、**注文完了後**に移設 |
| （なし） | **「チラシ5万枚も、アクスタ1枚も、同じ工場で刷っています」** | 法人臭と「個人お断り感」を同時に消す。Meta層のブロック理由を潰す |

### 吹き出し②（バナー1枚）

```
┌────────────────────────────┐
│  ロゴ                            │
│  ┌──────────────────┐  │
│  │ 30秒で完了          │ ←黄吹き出し
│  └──────────────────┘  │
│                                  │
│   新規会員登録で                  │
│   1,000円分のポイント             │ ←緑・特大
│                                  │
│  ┌──────────────────┐  │
│  │  ポイントを受け取る  →  │ ←赤CTA帯
│  └──────────────────┘  │
└────────────────────────────┘
```

- **「LINEスタンプカードとの併用で…」は載せない。** 1枚1メッセージ。
- 数字は「1,000円分」を最大サイズ。「10万円」は使わない。

### 吹き出し③（カルーセル4枚）

独立した注意書きの吹き出しは**廃止**。カルーセル4枚目の末尾に薄字で入れる。

| # | カード | ボタン | CV |
|---|---|---|---|
| 1 | チラシ・ポスターを刷る | 30秒で見積もりを出す | 見積もり完了 |
| 2 | 推し活グッズをつくる（1種類1枚から／**個人の方のご注文も大歓迎です**） | グッズの種類と値段を見る | 注文完了 |
| 3 | 紙の見本帳、無料で送ります | 無料で見本帳をもらう | 問い合わせ完了 |
| 4 | 入稿データ、無料で確認します<br>※お返事はメールでお送りします（1営業日以内） | 無料でデータを見てもらう | 問い合わせ完了 |

実装JSON → `_drafts/printearth_flex_greeting_carousel.json`

> **カード3が企画上いちばん効率が良い。** 見本帳の請求には会員登録が必要なので、
> 「請求 → 会員登録 → ポイント発生 → 後日注文」が1本の線になる。
> その場で買わない人を**ブロックさせずにCVで拾える**、CPA的に最も安い出口。

## 3. リッチメニュー 改修版

```
改修後（2×3）
┌──────────────┬──────────────┬──────────────┐
│ チラシ・ポスター │ 推し活・グッズ  │ 注文する       │ ←赤
│ を刷る         │ をつくる       │              │
├──────────────┼──────────────┼──────────────┤
│ 名刺・冊子     │ 無料見本帳・   │ 見積もり・     │ ←橙
│               │ テンプレDL     │ お問い合わせ   │
└──────────────┴──────────────┴──────────────┘
```

| 変更 | 理由 |
|---|---|
| 左上を「チラシ・ポスター」に | 一等地に**最大ボリュームの商材**を置く |
| **「推し活・グッズをつくる」を新設** | Meta流入層の受け皿。**現状ゼロの穴を埋める**のが今回最大の追加 |
| テンプレDLを「無料見本帳」と統合 | 単独で一等地を取る価値はない。見本帳（CV）に主役を譲る |
| ショップカードを撤去 | CV直結しない。必要ならカルーセルや配信で告知 |
| 納期カレンダーを撤去 | 「見積もり・お問い合わせ」内に納期表示を寄せる |

- **URLの `https://` 二重を全ボタンで修正**し、全リンクにutmを付与
- 色・アイコン・角の三角アクセントは**現行デザインを踏襲**（作り直しは配置のみ）

## 5. セグメント配信の導入（今回の構造的な提案）

現状は**全配信が「全員」**。BtoBに推し活を、BtoCに名刺を送っている状態で、
これが**ブロック率と配信コストの両方**を押し上げています。

### 【重要】いま作られているオーディエンスは全部「インプレッション」

管理画面の実データ（2026/08/31時点）：

| オーディエンス | 種類 | サイズ |
|---|---|---|
| サマーキャンペーン／ポリうちわ／お盆／紙うちわ／会員登録 | **インプレッション** | 263〜340 |
| 同人誌印刷（8/21作成） | インプレッション | **「準備中」のまま** |
| 友だち追加経路（20260402〜） | 友だち追加経路 | 1,471 |
| RMImp_Day45 | リッチメニューインプレッション | 502 |
| 関係者／新規・個人 | チャットタグ | 6／51 |

**クリックオーディエンスが1つもありません。**

- **インプレッション＝「見ただけ」**。配信が届けばほぼ全員入るので、絞り込みの精度がほぼゼロ
- **クリック＝「押した」＝意図がある**。BtoB/BtoCを分けられるのはこちらだけ
- 同人誌が10日以上「準備中」なのは、**対象者が少なすぎてサイズが確定していない**可能性が高い。
  今回の企画から同人誌を外したのはこのため

### やること：次の配信から「クリック」でオーディエンスを作る

**管理画面の設定だけ。制作物ゼロ、工数ゼロ。**

| オーディエンス | 作り方 | 使い道 |
|---|---|---|
| **BtoC・推し活層** | 推し活／トレカ／うちわ のURLを**クリックした人** | No.27、グッズ系の配信 |
| **BtoB・販促層** | チラシ／名刺／冊子／カレンダー のURLを**クリックした人** | No.21、No.23、No.25 |
| **未登録者** | 会員登録URLを**クリックしていない**人（除外指定） | No.22 |

- **配信のたびにオーディエンスが育つ。** 3ヶ月続ければ精度の高い2分割ができる
- あいさつメッセージ自体の出し分けは標準機能では不可（Lステップ等が必要）。
  まずはこの方法で分け、効果が出てからツール導入を提案する

## 6. 配信前に確定すること

1. **【最重要】1,000ポイントは初回注文から使えるか。**
   公式のポイント規約は「次回以降のご注文時に使用」と読める。もし登録特典も同じなら
   **初回の支払額は下がらない**。広告で「すぐ使える」と言っているとカートで期待が外れ、
   離脱＋景表法リスク。→ No.22・あいさつの文言が変わる（両パターン用意済み）
2. 「最大50%OFF」「1枚1.2円〜」の**適用条件**（商品・部数・期間）
3. 名刺カテゴリ・カレンダー早割の**実URLと価格**（`◯◯◯円`のプレースホルダを埋める）
4. 期初に間に合う**入稿締切日**（No.21で使用）
5. 8月の**検索 vs Meta の友だち追加数比率**（カルーセルの並び順を確定するため）

## 7. 効果測定

| 指標 | いま測る理由 |
|---|---|
| 友だち追加 → 会員登録率 | あいさつ改修の効果。**改修前の数値を先に控えておく** |
| 追加 → 60分以内のCV率 | 即時CVRの基準値。次のリマインド施策の土台 |
| 配信別CTR / CVR | どの商材が刺さるか。10月以降の企画の根拠になる |
| **ブロック率（配信別）** | セグメント配信の効果検証。全員配信との差を見る |
| 媒体別CPA（検索 / Meta） | 最終評価 |
