# 単品通販版｜FMTに戻すために「いるべき情報」

作成日：2026-09-02
`_templates/DYM_LINEOA_FMT.pptx`（原本36枚）の中身を抽出し、
`単品通販業界_LINEOA施策提案.pptx` に**載っていないもの**を機械チェックで洗い出した。

> **結論：スキル §6.5 の13項目は満たしているが、FMT自身の"型"を8つ落としている。**
> §6.5は「何を調べて載せるか」のチェックリスト。FMTの型は「どう見せるか・どう論を運ぶか」。
> 別物なので、§6.5をクリアしてもFMTに揃ったことにはならない。

---

## 1. FMTの背骨（全業界共通で載るべき情報）

FMT原本から抽出した、業界に依存しない構造。**これが「DYMのLINEOA提案の型」。**

### ★① カスタマージャーニー ①〜⑦の動線番号（FMT S03/S04/S23〜S27）

FMT全体がこの7段階の番号で貫かれている。**改善モデルも具体施策も、全部この番号を参照している。**

| # | 段階 |
|---|---|
| ① | 接触（認知・流入） |
| ② | サイト離脱（対策） |
| ③ | 育成（興味喚起） |
| ④ | リード獲得（web / LINE） |
| ⑤ | リード有効化 |
| ⑥ | 商談・接客 |
| ⑦ | マネタイズ（成約・購入） |

**この番号があるから「この施策は②に効く」と言える。** 番号が無いと施策とKPIの対応が曖昧になる。

### ★② 15日の壁（FMT S22）

> **LINE友だち追加〜15日を境に大きくアクティブ率が下がる（ブロック率が上がる）。
> 為、追加から20〜30日間のステップ配信構築とユーザビリティの改善が必要。**

**FMTで唯一「なぜステップ配信が要るのか」を説明している主張。** これが無いと配信設計が根拠レスになる。

### ★③ アカウント効果を最大化する3本柱（FMT S17）

「アカウント効果を最大化するためには・・・？」に対する3つの答え。

1. **既存友だちのメッセージ配信を拡大＆検証し、課金対効果を向上する**
2. **新規友だちの追加動線を拡大＆整備し、見込みの高いユーザーのリードを獲得する**
3. **WEBサイト上情報と連携させ、配信効果を数値化する**

### ★④ 対策領域の2軸マップ（FMT S19）

- `<対新規ユーザー領域>` … HP / LP からの流入をどう捕まえるか
- `<対既存ユーザー（顧客）領域>` … 既に持っている顧客をどう動かすか

### ★⑤ 改善モデル①〜④（FMT S24〜S27）

**赤チップ「施策内容」＋1行の宣言＋①〜⑦動線のどこに効くかの図**、を4枚で積み上げる型。

| | FMTの宣言文 |
|---|---|
| 改善モデル① | LINE施策を通じて貴社に送ることが出来る個人情報を最大化する |
| 改善モデル② | 獲得されたリードを【接触・商談】などの裏リーチができる状態に引き上げる |
| 改善モデル③ | 成約、購入等、企業としての売上・利益につなげる |
| 改善モデル④ | リピート率、クロスセル率、客単価を改善し、LTVを最大化する |

### ★⑥ 具体施策のパターンA／パターンB型（FMT S29〜S32）

**1枚に「想定：〜」＋パターンA／パターンBの2案**を並べる型。4枚ある。

| 枚 | 想定 | パターンA | パターンB |
|---|---|---|---|
| S29 | 低ハードルのCV地点を設定してリード情報を大量獲得 | 入口設計 | 特典訴求 |
| S30 | 過去の保有リストに対して再度CVを促す動線（未アクションユーザーの再アクション） | タイミング設計 | 再接触設計 |
| S31 | リピート、クロスセルを計画的に実施 | リピート施策 | クロスセル施策 |
| S32 | チャットやり取りを簡略化・自動化し、利便性を下げず営業トスアップ・CVに繋げる | 自動化施策 | トスアップ施策 |

### ★⑦ 短期／長期／診断の3点セット（FMT S33〜S35）

| 枚 | 型 |
|---|---|
| S33 | **友だち追加〜短期**：直近利用・契約可能性が高い層に、**不安の払拭と条件面の精査を15〜30日**でタッチポイント化 |
| S34 | **友だち追加〜長期**：検索ボリューム推移からスケジューリング。「◯◯の日」「検討が活発化する期間」「CVRが高い期間」を抽出して企画化 |
| S35 | **診断**：心理ハードルの低い「性格診断」「経験談アンケート」（**4問・各5択**）で追客の強弱を決定 |

### ⑧ 検討背景のファネル（FMT S02）

「ファン化・自社アプリ登録に対して"ハードルが高く感じる"ユーザーが増えている」
→ リード獲得層 → 検討層 → 既存ユーザー → リピート・ファン化 のファネルと、DYM施策の対応表。

## 3. 単品通販版では、中身をこう置き換える

FMTの型はそのまま、業界の中身だけ差し替える。**型を捨てない。**

| FMTの型 | 単品通販での中身 |
|---|---|
| ①接触 | 広告・記事LPからの流入 |
| ②サイト離脱 | **（単品通販では薄い。LPで直接買うため）** |
| ③育成 | **使用フォロー**（効果実感まで伴走） |
| ④リード獲得 | **同梱物QRでの友だち化**（★購入後に取るのが特徴） |
| ⑤リード有効化 | **F2オファー**（消費サイクル連動） |
| ⑥商談・接客 | **定期引上・プラン変更の相談** |
| ⑦マネタイズ | **定期の継続**（＝解約の手前で受け止める） |
| 15日の壁 | そのまま使える。**購入後の初動15日が勝負**という形で言い換える |
| 3本柱 | ①既存友だちへの配信＝解約予防／②新規追加動線＝同梱物QR／③WEB連携＝**LINE ID連携（S20）** |
| 対新規／対既存 | **対新規＝初回購入者の友だち化／対既存＝定期継続者の解約予防**。単品通販は**対既存が主戦場** |
| 改善モデル① | 個人情報の最大化 → **初回購入者を友だち化して連絡先を持つ** |
| 改善モデル② | 裏リーチ可能な状態へ → **使用フォローで効果実感まで伴走** |
| 改善モデル③ | 売上・利益につなげる → **F2転換率を上げる** |
| 改善モデル④ | LTV最大化 → **月次解約率を下げる（3%と7%で寿命が33ヶ月/14ヶ月）** |
| パターンA／B（S29相当） | A=同梱物QRの入口設計／B=初回特典訴求 |
| パターンA／B（S30相当） | A=休眠掘り起こしのタイミング設計／B=解約者への再開提案 |
| パターンA／B（S31相当） | A=定期引上／B=クロスセル（別商品の提案） |
| パターンA／B（S32相当） | A=解約・スキップ受付の自動化／B=問い合わせのセルフ化 |
| S33 短期 | **購入後15〜30日**：使い方の不安払拭とF2オファー |
| S34 長期 | 年間の企画投稿カレンダー（**S10のGoogleトレンド確定後**） |
| S35 診断 | **初期アンケート4問**（お悩み／使用量／使用歴／使う時間帯）。★FMTと同じ「4問」の型 |
