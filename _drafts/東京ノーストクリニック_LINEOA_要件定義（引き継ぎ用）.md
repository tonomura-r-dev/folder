## 2. 2026-09-01 にやったこと（★これが資産。ゼロからではない）

### 2-1. CRレビューで確定したコピーの型

- 主コピー **「彼女は、言わないだけ。」**
- 受け **「気にしているのが自分だけでも、相談していい。」**
- → **対構造**（突き放す一言 → 受け止める一言）で作る。これが決まった型。
- **「医師もスタッフも全員男性」が最大の障壁を潰す1行。** 必ず入れる。

**この商材の本質は「恥ずかしくて誰にも言えない」。**
煽らず、受け止める側に立つ。これを外すと全部おかしくなる。

### 2-2. ★医療広告ガイドラインで実際に引っかかった2点

**「関係あるか？」の答えはこれ。9/1に具体的にNGを出している。**

| # | 表現 | 何に当たるか | 対応 |
|---|---|---|---|
| 1 | 「今なら／10万円分無料」 | **費用の強調** | LP側で**限定解除の要件**（自由診療である旨・標準費用・治療期間と回数・リスクと副作用）を満たす必要がある |
| 2 | 「夜生活が楽しみに」 | **効果効能の暗示** | 使わない |

→ **プリントアースの「最大50%OFF」のような値引き訴求の型は、そのまま持ち込めない。**
景表法（有利誤認）だけの世界とは前提が違う。

**2026-09-04に裏取り完了 → `_drafts/東京ノーストクリニック_医療広告ガイドライン調査.md`。**
結論は「関係ある」で、9/1の指摘は正しかった。**さらに設計を変える発見が1つ出た（§2-5）。**

### 2-3. ★LINE観点の指摘（まだ実装されていない）

**CTAが「予約」一本道で、「電話も対面もしたくない」層の受け皿がない。**

検討期間が長い商材なのに、いきなり予約しか道がない。
→ **「まずはチャットで相談する」を副CTAに置くべき。**

**LINEはこの商材と相性が良い。** 恥ずかしくて電話できない人が、
文字でなら聞ける。ここが提案の背骨になる。

### 2-4. 画像生成プロンプトの学び

- **ロゴの十字は「入れるな」と禁止を明示しないと勝手に足される**
- **「微笑まず」と書くと冷たい顔になり、受け止め系のコピーと逆を向く**
  → 表情の指定は「微笑まず」ではなく「静かに正面を見ている」等、
    否定形ではなく肯定形で書く

### 2-5. ★調査で出た、設計を変える発見（2026-09-04）

**「詳しくはこちら」でLPに費用・リスクを飛ばす方法は不十分。**
厚労省の事例解説書が、必要事項をリンク先だけに書いた例を
**限定解除要件を満たさない事例**として挙げている。

自由診療を案内するなら、**同一配信内に**これを読める文字サイズで載せる：
治療内容／標準的費用（または上限下限）／期間・回数／主なリスク・副作用／問い合わせ先。

**→ 1040×1040の画像1枚では成立しない。**

```
吹き出し1：リッチメッセージ（画像）＝ 中立的な見出しにとどめる
吹き出し2：テキスト ＝ 必須事項5点
```

**⚠️ 自由診療の回は2吹き出しが前提。通数が倍になる。**
プリントアースで「1配信＝1吹き出し」に統一したのと**逆方向**なので、
**月の通数上限を先に確認しないと本数が決められない**（§3-③）。

### 2-6. 配信の3類型（これで組む）

| 類型 | 中身 | 限定解除 | 吹き出し |
|---|---|---|---|
| **A. 広告可能事項のみ** | 休診・診療時間・予約方法・担当医・アクセス | 不要 | 1 |
| **B. 自由診療の案内** | 診療メニューの訴求 | **必要**（§2-5の5点を同一配信内に） | **2** |
| **C. 一般啓発** | 季節の健康情報など | 誘引を付けなければ広告に当たらない余地 | 1 |

**⚠️ Cに「今すぐ予約」「この症状なら当院の○○治療で」を足した瞬間に広告になる。**
足すならBの要件を満たすこと。

**プリントアースで使った「まもなく終了！」「最大50%OFF」は、ノーストではB類型でも使えない。**
費用の過度な強調・期限の煽りは、厚労省が「厳に慎むべき」とする類型に当たる。

### 2-7. ⚠️ CPFで集めた友だちの扱い（未解決）

限定解除の第1要件は「患者等が自ら求めて入手する情報であること」。
調査では、**LINE広告から不特定多数に治療広告を出す形は第1要件を満たさない可能性が高い**
とされている。

**CPF（友だち追加広告）経由で追加された友だちへの配信が「自ら求めた」に当たるかは、
今回の調査では詰め切れていない。** ノーストの流入がCPF中心なら、ここは論点になる。
→ OAMの友だち追加経路を見てから、必要なら所轄自治体に事前相談する。

## 3. 止まっている理由 ＝ 送ってもらうもの

**現在のLINE運用状況（友だち数・配信頻度・過去投稿）が未取得。**
これが無いと配信対象も本数も決められないので、企画が組めない。

### ① OAMのエクスポート（最優先）

LINE Official Account Manager から5点。**プリントアースで効いたのはこの組み合わせ。**

| # | 場所 | 何が分かるか |
|---|---|---|
| 1 | 分析 → メッセージ配信 | 配信ごとの配信数・開封・クリック |
| 2 | 分析 → 友だち | 友だち／ターゲットリーチ／ブロックの推移。**一番効く** |
| 3 | 分析 → リッチメニュー | 枠ごとのクリック |
| 4 | 分析 → 友だち追加経路 | 流入元ごとのブロック率 |
| 5 | ホーム → メッセージ配信（一覧） | 過去配信の**吹き出し数**と消費通数 |

期間はできるだけ長く（1年あれば十分）。

### ② 過去の配信文とCR画像
文体・型・NGにしている言い回しを合わせるため。プリントアースでもこれが一番効いた。

### ③ 確認事項

| 項目 | なぜ要るか |
|---|---|
| **★プランと月の通数上限** | プリントアースはライト5,000通で、これが本数と配信対象を全部縛った。**ノーストは自由診療回が2吹き出しになるため通数が倍で効く（§2-5）。最優先で確認** |
| **月に何本配信しているか** | タスク上は各月4本の想定 |
| **予約導線**（Web／電話／LINE内） | §2-3の副CTAが置けるかに直結 |
| **診療時間・休診日** | 配信時間 |
| **社内でNGにしている表現** | 医療広告の運用ルールが既にあるはず。**それが最優先** |

## 4. プリントアースから流用できるもの／できないもの

| | 流用可否 |
|---|---|
| **シートの20列形式** | ✅ そのまま |
| **UTM設計**（campaign共通・utm_contentで区別） | ✅ そのまま。計測が死んでいる案件が多いので最初に見る |
| **1040×1040** | ✅ リッチメッセージなら共通 |
| **狙い概要の分類** | ⚠️ ノースト側の過去実績を見て決める |
| **「全配信は月1本まで」** | ⚠️ **持ち込まない。** プリントアース固有の数字（ブロック+19〜37）が根拠 |
| **1配信＝1吹き出し** | ❌ **逆になる。** 自由診療の回は限定解除の必須表示があるため**2吹き出し必須**（§2-5） |
| **配信の曜日・時間** | ❌ **絶対に流用しない。** プリントアースはADレポの実データで決めた |
| **割引・キャンペーン訴求の型** | ❌ **使えない。** 費用の過度な強調・期限の煽りは「厳に慎むべき」類型（§2-6） |
