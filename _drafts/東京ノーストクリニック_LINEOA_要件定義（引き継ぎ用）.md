## 2. ⚠️ プリントアースとの最大の違い：医療広告ガイドライン

**印刷通販は景表法だけ見ればよかったが、医療機関は医療法（医療広告ガイドライン）が乗る。**
LINEの配信も広告に該当しうるため、**文面の作り方が根本的に変わる。**

書き始める前に必ず確認すること（順番に効く）：

1. **体験談は使えない。** 患者の感想を訴求に使うのは禁止。
2. **ビフォーアフター写真は原則不可。** 治療内容・費用・リスク・副作用の
   詳細な説明を併記しない限り使えない。
3. **比較優良広告・誇大広告が禁止。**「日本一」「最高」「絶対安全」の類。
4. **自由診療は「限定解除」の要件**（費用・治療内容・リスク副作用の明示など）を
   満たさないと内容を広告できない。
5. **クライアント側に既存の運用ルールがあるはず。** それが最優先。

→ **CRテキストを書く前に、上記の解釈をクライアントと合わせる。**
プリントアースの「最大◯%OFF」のような割引訴求の型は、そのまま持ち込めない可能性が高い。

## 3. プリントアースから流用できるもの／できないもの

| | 流用可否 |
|---|---|
| **シートの20列形式** | ✅ そのまま |
| **狙い概要の5分類** | ⚠️ クライアントのシート次第。ノースト側の過去実績を見て決める |
| **UTM設計**（campaign共通・utm_contentで配信を区別） | ✅ そのまま。計測が死んでいる案件が多いので最初に見る |
| **「全配信は月1本まで」** | ⚠️ **持ち込まない。** プリントアース固有の数字（ブロック+19〜37）が根拠。ノーストのOAMを見てから判断する |
| **1配信＝1吹き出し** | ⚠️ 同上。通数の上限を確認してから |
| **1040×1040** | ✅ リッチメッセージなら共通 |
| **配信の曜日・時間** | ❌ **絶対に流用しない。** プリントアースはADレポの実データで決めた。ノーストはノーストのデータで決める |
| **割引・キャンペーン訴求の型** | ❌ 医療広告ガイドラインがあるため作り直し |

## 4. 進め方（プリントアースと同じ順番）

1. OAMを分析 → `_drafts/東京ノーストクリニック_OAM分析_YYYY-MM.md`
2. リストの状態（リーチ推移・ブロック率・開封率）から**配信対象の方針**を決める
3. 過去配信の文体に合わせて**CRテキスト**を書く
4. **20列のシート行**に落とす
5. 画像生成プロンプト（1040×1040）

**プリントアースで一番効いたのは1と2。** 訴求を考える前に、
「そもそも誰に送れるのか／送りすぎていないか」を先に潰したのが良かった。
