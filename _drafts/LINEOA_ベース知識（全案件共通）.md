## 1. LINEOAのポジ／ネガ（課題提起パートの素材）

### ポジ
- ネイティブアプリのDLは減っており、**LINE／LINEミニアプリでの管理の重要性が上がっている**
- 広告CVRは高くても2〜3%。高騰中のCPCを払って流入させても**95%以上が離脱**する。**ここの再育成でプロモーション効果が改善できる**
- CRM機能に強く、フェーズに応じた訴求で **CPA・CPO・LTV** が改善できる
- **開封率・開封までの時間**で、電話・メルマガに対して強い
- 1対1のコミュニケーションツールとして使える
- **ブロックされない限り半永久的にアプローチできる**

### ネガ（先に言う。隠さない）
- 従量課金・ツール課金でコストがかかるリスク
- **運用知見のある代理店・個人が少ない**（高CVRにつながるユーザー層・訴求への理解が乏しい）
- 開発にコストがかかる
- APIツールの切り替え時、**ツールによってはデータを引き継げない**

## 2. DYMの方針（自社の強みパート）

- 最適なツール選択に伴走できる
- **成果報酬型での取り組みが可能。最低固定金額 ¥30,000/月**（広告CPAに合わせる）
- CVRの高い層・LTVの高い層に対し、**広告知見をもとにした戦略立て**ができる
- **400アカウント・100社以上**のアカウント商流から横展開できる実績・知見

## 3. ユーザー動線＝8フェーズ

①接触(認知・流入) ②サイト離脱 ③興味喚起・育成 ④リード獲得 ⑤リード有効化
⑥有効リードの再育成 ⑦マネタイズ ⑧リピートによるLTV最大化 （⑨拡散）

※フェーズの意味は当てはめる前に元資料（FMT）の定義を確認する。
※④リード獲得と⑤リード有効化の間には迷う期間がある。その間の追い配信は⑤に入れる。

## 6. ★特殊機能の想定数値（SIMの係数。これが一番使う）

### 通知メッセージ
- ユーザーのアクションに対応するパターン
- **ユーザーリスト（TEL番号）を一括アップロード**して対応するパターン

### LINEログイン（Profile+）

### サンクスLINE誘導
月間のCV数、もしくは成果地点（診断完了）に設置するため、**各母数の集計が重要**。

```
CV経由   ＝ 表示回数 × 遷移率 80%  × 追加率 40〜50%
診断経由 ＝ 表示回数 × 遷移率 75%  × 追加率 35〜40%
```

### 離脱防止ポップアップ（SiteLead）
**コスト 5,000円 ／ 請求 10,000円（月）** で計算する。
表示対象ページ・階層を決めたうえで、

```
表示回数（率により変動） × クリック率 12.5% × 実追加率 12.5%
```

### LINE広告 CPF
- **1ユーザーあたり 200円** で獲得
- **初動ブロック率 50%** 想定

### サイト内CTA（LINE追加）
掲載テキストをユーザーライクにすることで、

```
表示回数 × 0.02〜0.05%
```

## 使うときの注意

- **CVRは 0.3〜1.0% 前後**（2026-09-24 の指定）。ここから大きく外さない。上の係数は「友だち追加率」であってCVRではないので混同しない
- SIMのFMTは10月のLINEプラン改定で変わる。**旧FMTを新規SIMのベースにしない**
- CPF単価は、古河林業では150円で置いたが**出典未確定**。ここでは200円。案件ごとにどちらを使ったか明記する
