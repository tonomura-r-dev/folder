## 1. なぜ「ぬいぐるみ」がノーストに合うのか

**ノーストが取れない手7つのうち、3つがこの表現で最初から関係なくなる。**

| ノーストの制約 | ぬいぐるみだとどうなるか |
|---|---|
| **症例写真が出せない**（§4） | **人を出さないので最初から関係ない** |
| **体験談が出せない**（§4） | 同上。物語を人に語らせない |
| **「人に知られたくない」が最大の不安** | **生々しさが消える。** 部位も身体も一切映さない |
| 友だちの**50歳以上が90.8%** | ぬいぐるみは年齢を選ばない。嫌味がない |
| 競合5社は**全部イラストの静止画** | **動画×ぬいぐるみは誰もやっていない** |

**★競合の実機トーク画面16枚に動画は1本もない。** 上野が体験談カルーセル、
メンズライフが診断、ATOMが価格。**動く画は誰も出していない。**

## 2. 絶対に描かせないこと

| 禁止 | 理由 |
|---|---|
| **ぬいぐるみが治療を受ける／施術される描写** | **症例と効果効能の暗示に読める。** 2026-09-01に「夜生活が楽しみに」で実際に引っかかったのと同じ経路 |
| **身体の部位・患部の暗示** | 同上 |
| **医療器具・処置台** | 同上 |
| **文字・ロゴ・数字** | **AIに日本語を描かせると崩れる。** 編集で後乗せする |
| **人間** | 世界観が壊れる。実写の医師は静止画のバナーで使う |
| **★困り顔・うつむき・暗い部屋** | **鬱に見える。** 不安を煽る絵は §6（誘引的な表示）に近づく。**表情は必ず中立** |

**描くのは「一人で抱えていた → 出かけた → 迎えられた」という行動だけ。**

#### ★9:16のトリミングは使えない。1:1にする

**9:16に切るとクマの顔のアップになり、窓も部屋も消える。**
「一人でいる」が絵から伝わらなくなる。

**1:1（中央 720×720）なら窓・カーテン・観葉植物・ベッドが残り、クマも大きい。**
**バナー（1040×1040）とも揃うので、9月3本と並べたときに統一感が出る。**

```
crop=720:720:280:0
```

**引きのほうが「1体だけでいる」が伝わるので、このまま採用。**
→ **カット2・3も"引き"で揃える。** 寄り引きが混ざると落ち着かない。

## 6. 作り方の手順

**★3つのプロンプトを一度に送らない。** Veoは1回で8秒1本。まとめて投げると詰め込もうとして破綻する。

**★「クマの設定画」を別に作る必要もない。カット1の絵がそのまま設定画になる。**

```
カット1の絵を画像で作る → 動画にする
　↓ その画像を添付
カット2の絵を画像で作る → 動画にする
　↓ 同じ画像を添付
カット3の絵を画像で作る → 動画にする
```

**画像を1コマ目にして動画を作るので、絵は画像の段階で粘る。**
動画は生成に時間がかかるため、ここで詰めたほうが早い。

### ① カット1の画像を作る

```
小さなクマのぬいぐるみが1体、夕方の部屋のベッドに座っている。
背筋は伸びていて、両手で持ったスマートフォンを普通に見ている。うつむいていない。
日本のワンルーム。カーテンは開いていて、大きな窓から夕方のやわらかいオレンジの光が
部屋いっぱいに差し込んでいる。壁も寝具も明るいベージュ。観葉植物。清潔で気持ちのよい部屋。
正面やや上からのミディアムショット。クマを画面の中央に大きめに配置する。
クマの表情は中立。困り顔にしない。眉を下げない。
クマの色はやわらかいベージュ。毛足は短め。目は小さな黒いボタン。
少しへたった綿の質感で、縫い目が見える。
写実的な実写風。あたたかく、穏やか。
文字・ロゴ・数字は描かない。人間を出さない。
縦長 9:16。
```

**気に入る1枚が出るまで作り直す。このクマが3カット通しての主人公になる。**

### ② その画像から動画にする

画像を添付して送る。

```
この画像を1コマ目にして、8秒の動画にしてください。

クマはほとんど動きません。カーテンがわずかに揺れます。
カメラは三脚固定で、ごくゆっくり前に寄ります。
あたたかく、穏やか。
音声はなし。文字・ロゴ・数字は描かないでください。
```

### ③ カット2・3も同じやり方

**①で作った画像を毎回添付**し、「このクマで」と指定しながら §3 のカット2・カット3の内容で
画像を作る → 動画にする、を繰り返す。
**カット3の白衣の大きいクマは新キャラ**なので、主人公のクマだけ揃っていればよい。

### ④ 仕上げ

1. **1カットにつき3〜5本出して選ぶ。** ぬいぐるみは表情と毛の質感で当たり外れが大きい。
2. **Canva等で3カットをつなぎ、文字を後乗せ**（§4）。
3. **実機のLINEで確認。** 無音・小さい画面で文字が読めるかを見る。
