## 2. 絶対に描かせないこと

| 禁止 | 理由 |
|---|---|
| **ぬいぐるみが治療を受ける／施術される描写** | **症例と効果効能の暗示に読める。** 2026-09-01に「夜生活が楽しみに」で実際に引っかかったのと同じ経路 |
| **身体の部位・患部の暗示** | 同上 |
| **医療器具・処置台** | 同上 |
| **文字・ロゴ・数字** | **AIに日本語を描かせると崩れる。** 編集で後乗せする |
| **人間** | 世界観が壊れる。実写の医師は静止画のバナーで使う |

**描くのは「一人で抱えていた → 出かけた → 迎えられた」という行動だけ。**

## 6. 作り方の手順

**★3つのプロンプトを一度に送らない。** Veoは1回で8秒1本。まとめて投げると詰め込もうとして破綻する。

**★「クマの設定画」を別に作る必要もない。カット1の絵がそのまま設定画になる。**

```
カット1の絵を画像で作る → 動画にする
　↓ その画像を添付
カット2の絵を画像で作る → 動画にする
　↓ 同じ画像を添付
カット3の絵を画像で作る → 動画にする
```

**画像を1コマ目にして動画を作るので、絵は画像の段階で粘る。**
動画は生成に時間がかかるため、ここで詰めたほうが早い。

### ① カット1の画像を作る

```
小さなクマのぬいぐるみが1体だけ、暗い部屋のベッドの端に座っている。
うつむいて、膝の上に置いたスマートフォンをじっと見ている。
夜の日本のワンルーム。カーテンは閉じている。片付いているが少し寂しい。
光源はスマートフォンの画面だけ。青白い光がクマの顔を下から照らす。周囲は暗い。
正面やや上からのミディアムショット。
クマの色はやわらかいベージュ。毛足は短め。目は小さな黒いボタン。
少しへたった綿の質感で、縫い目が見える。
写実的な実写風。文字・ロゴ・数字は描かない。人間を出さない。
縦長 9:16。
```

**気に入る1枚が出るまで作り直す。このクマが3カット通しての主人公になる。**

### ② その画像から動画にする

画像を添付して送る。

```
この画像を1コマ目にして、8秒の動画にしてください。

クマはほとんど動きません。スマートフォンの画面の光だけがゆっくり明滅します。
カメラは三脚固定で、ごくゆっくり前に寄ります。
静かで、孤独。ただし悲壮にはしないでください。
音声はなし。文字・ロゴ・数字は描かないでください。
```

### ③ カット2・3も同じやり方

**①で作った画像を毎回添付**し、「このクマで」と指定しながら §3 のカット2・カット3の内容で
画像を作る → 動画にする、を繰り返す。
**カット3の白衣の大きいクマは新キャラ**なので、主人公のクマだけ揃っていればよい。

### ④ 仕上げ

1. **1カットにつき3〜5本出して選ぶ。** ぬいぐるみは表情と毛の質感で当たり外れが大きい。
2. **Canva等で3カットをつなぎ、文字を後乗せ**（§4）。
3. **実機のLINEで確認。** 無音・小さい画面で文字が読めるかを見る。
