## 5. 時期訴求の根拠（毎回これしか使わない）

```
当院は12/30〜1/4が休診です。
```

**この事実1つから逆算するだけ。** 「予約が埋まる」「今だけ」は使わない。

| 回 | 言い方 |
|---|---|
| 9/11 | 年内にとお考えの方は、そろそろご予約のタイミングです |
| 10/30 | 年内にとお考えでしたら、10月中のご予約をおすすめします |
| 11/6 | 12月のご予約は今からお取りいただけます |
| 11/27 | 年内の受付は12/29までです ⚠️**先方確認が必要** |

⚠️ **12/29までは休診日（12/30〜12/31・1/1〜1/4）からの推測。** 年末の受付締切は先方に確認する。

## 6. 月をまたいで効くこと

### オーディエンスが育つ

**現状のオーディエンスは全部インプレッション（見ただけ）で、クリックが1件もない。**
9月の3本でクリック者が初めて取れる。

```
9月  全配信7,347 → 開封 約1,750 → クリック 約175（初めて取れる数字）
10月 クリック者175 に厚く打てる（月末の回）
11月 2ヶ月ぶんのクリック者に打てる
```

**制作物ゼロ・管理画面の設定だけで精度が上がる。**

### 10・11月の配信時間は9月の結果で決める

9月で **21時・11時・18時** の3点を取る（曜日は金曜固定）。
**一番開いた時間に10月の3本を寄せる。** 推測で決めない。

### 測るもの

| 指標 | 基準 |
|---|---|
| 開封率 | **23.8%を超えるか**（2025/12/12 金11:15の実績） |
| クリック率 | 9月が初回。以降の基準になる |
| 予約件数 | **月3件が目標**（7,347人の0.04%） |

逆算：全配信7,347 → 開封23.8%＝1,750 → クリック10%＝175 → 予約2%＝**3.5件**。
**月3件は月初の全配信1本だけで届く。** 2・3本目は上積み。
