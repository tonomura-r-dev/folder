### ★ CPF（友だち追加広告）が経路に出ていない

プリントアースは**流入の97%がCPF**だったが、**ノーストは広告で友だちを集めていない。**
主力は友だち追加URL・QR（LP・院内・アンケート導線）と検索。

→ **限定解除の第1要件「患者等が自ら求めて入手する情報」の懸念が薄い。**
LINE広告から不特定多数に配信する形ではないため、要件を満たしやすい側にいる。
（`_drafts/東京ノーストクリニック_医療広告ガイドライン調査.md` §3-4 の論点は、
現状ではひとまずクリアできそう。**ただし過去に11,396人をどう集めたかは別問題**）

### 「その他」が追加0・ブロック183

**この3ヶ月で「その他」経由の新規追加はゼロなのに、183人がブロックしている。**
過去に「その他」に分類された層が今まとめて離脱している。
経路ごとのURL/QRを発行していないと「その他」に入るため、**いつ・どこから来た人か分からない。**

→ **経路ごとに友だち追加URLを発行し直す**のが、次から効く打ち手。

## 3. 配信：2吹き出し＝1回16,926通

### 2025/12/12 11:15 の配信

| | |
|---|---|
| 配信 | **8,463** |
| 開封 | 2,013（**23.8%**） |
| クリックユーザー | **71** |
| 吹き出し1：テキスト「＼LINE限定お得情報🔍／…」 | imp **337** |
| 吹き出し2：リッチメッセージ「増大施術10万円分無料_251212」 | imp **2,478** |
| リンククリック（`norst.jp/s/form_lin…`） | クリック85／**クリック率3.4%**／クリックUU71 |

- クリックUU / 開封 ＝ **3.5%**
- クリックUU / 配信 ＝ **0.84%**（8,463人に送って71人）
- 開封は初日でほぼ決まり、2週間かけて微増（グラフ）

### ★ 通数：8,463 × 2吹き出し ＝ 16,926通／回

**月4本なら約67,700通。** プリントアース（ライトプラン5,000通）とは桁が2つ違う。

→ **プランと従量課金の状況が最優先の確認事項。**
社内に `20260826_LINE料金改定に伴う運用最適化・特別プランのご案内.pptx` があるので、
**通数を絞る提案がそのままコスト削減の話になる。** 施策より先に金額で効く。

→ セグメント配信の根拠が、プリントアース（リストの保護）と違って
**ノーストでは「通数コスト」**になる。話の組み立てを変える。

### ⚠️ テキスト吹き出しのimpが337しかない（要検証）

リッチメッセージ2,478に対して**テキストは337（13.6%）**。
配信画面で「もっと表示」と畳まれている長文なので、
**開いた人しかカウントされていない可能性が高い。**（※LINEのimp定義は未確認。推測）

**これが本当なら、医療広告の必須表示をテキスト吹き出しに入れても読まれない。**
限定解除は「容易に一覧・閲覧できる状態」を求めるので、畳まれた長文は危うい。

→ 対策は2つ。**①必須表示を画像の中に読めるサイズで入れる**
**②テキストを畳まれない長さに収める**（何字で畳まれるかは実機確認）。
**どちらにするかは、実機で「もっと表示」の閾値を見てから決める。**

## 4. ★あいさつメッセージが最大のリスク

**友だち追加した全員に必ず届く1枚。** 配信より露出が多い。
9/1のCRレビューで指摘した「今なら／10万円分無料」は、まさにこれ。

### 現状の記載と論点

| # | 記載 | 論点 |
|---|---|---|
| 1 | **「通常10万円 → 3万円」「7万円お得！」** | **二重価格。**費用の過度な強調（ガイドライン「品位」）。通常価格が実在しなければ虚偽広告、かつ景表法第5条 |
| 2 | **「増大施術 10万円分無料」** | 費用の過度な強調。9/1に指摘済み |
| 3 | **「たったの3万円でできる！」** | 安さの強調 |
| 4 | **「そして今なら！」** | 期間限定の煽り。**しかも期限が書かれていない** |
| 5 | **リスク・副作用の記載がゼロ** | 自由診療の限定解除要件を満たさない |
| 6 | **治療期間・回数・総額の条件がない** | 同上。「基本切除」の適用条件も不明 |
| 7 | 「まずはクーポンだけでもGETしておきませんか？」 | 施術を決めていない人を金銭的誘因で引く。品位の論点 |
| 8 | 「36年の経験と実績」「日本全国36院を展開」 | **事実なら広告可能事項の範囲内の可能性が高い**（開設年・院数）。根拠を持っておく |
| 9 | 「男性専門の美容外科クリニック」 | 標榜診療科との整合を確認 |

**1〜6は直す前提で考えたほうがいい。**
特に**5と6は「無い」ので、限定解除が成立していない。**

### ⚠️ ただし判断は先方と合わせること

- クライアント側に既存の運用ルール・法務確認がある可能性がある。**それが最優先。**
- 自由診療・費用表示の具体的な線引きは、**所轄自治体への事前相談**が正しい手順。
- ここに書いたのは「論点の洗い出し」であって、法的助言ではない。
