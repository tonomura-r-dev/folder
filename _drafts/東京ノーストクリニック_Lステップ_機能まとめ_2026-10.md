## 1. いちばん大事な3点（10/20の案に効く所）

| 聞きたかったこと | 答え | 根拠 |
|---|---|---|
| 導入前からの友だちは、いつLステップに入るか | **自動では入らない。友だちが「何か動く」と入る。** 動く＝トークに文を送る／Lステップで設定したボタン・リッチメニューを押す／回答フォームに答える。**URLを開くだけのリンクを押しても入らない**（解説記事に「URLリンクだと反映されません」と明記） | 公式ブログ「友だちをLステップに認識させる方法3選」＋解説記事2本 |
| 自動応答で、返事と同時にタグを付けられるか | **付けられる。** キーワード（完全一致／部分一致）に反応して、メッセージ送信・タグ付けなどのアクションを自動で実行。フリープランから使える | 公式の全機能一覧 |
| Lステップから配信するときの絞り込み | **タグ・友だち情報（回答フォームで取った値）・シナリオなどで絞れる。** 「流入経路」「対応マーク」「登録日」で絞れるかは検索では確かめられなかった（要確認＝一斉配信→新規配信→絞り込みの画面を見る） | 公式ブログ「セグメント配信とは」＋解説記事 |

→ **10/20の3本目の案（画像のタップ＝「テキスト」アクションで一言を送らせる → Lステップが認識 → 自動応答で予約URL＋タグ）は、この仕様どおり。**
  リンクを開くだけの形だと入らないので、「一言を送らせる」形で正しい。公式ブログも「カードタイプメッセージのボタンでテキストを送らせて認識させる」を方法の1つに挙げている。
  直す所は1つ＝自動応答で返す予約URLは、Lステップの「URLクリック測定」でくるむ（認識済みの人なので動く。押した人にタグ「予約フォームを開いた」が付く）。GAの印（utm）はその中のURLに付けたまま。

## 2. 機能の一覧（プランごと）

| 機能 | 何ができるか | 使えるプラン |
|---|---|---|
| 一斉配信（セグメント配信） | タグ・友だち情報などで絞って送る。1人でも絞れる（OAMの属性フィルターは推定属性・3日前のデータ・人数の下限あり） | スタート以上（記事による） |
| 自動応答 | キーワードに反応して返事・タグ付け・シナリオ開始などを自動実行 | フリー以上 |
| シナリオ配信（ステップ配信） | 友だち追加や条件を起点に、決めた間隔で順番に送る | プロ以上 |
| リマインダ配信 | 予約日などを起点に、前日・当日に送る | スタンダード以上（要確認） |
| URLクリック測定 | 短縮URLで、誰が押したかを測る・押した人にタグを付ける。**Lステップ経由の配信でしか測れない**（OAMから送った配信のリンクは測れない） | スタンダード以上 |
| 回答フォーム（アンケート） | 質問に答えてもらい、答えを友だち情報に保存（都道府県のプルダウンあり）。**2026年5月の新フォームはLINEログインが必須** | スタート以上（要確認） |
| リッチメニュー／セグメントリッチメニュー | タップ時の動作＝URLを開く／ユーザーメッセージ送信（友だちが文を送る）／テキスト送信（こちらが返す）／テンプレート送信／タグ付け／シナリオ開始／電話／QRリーダー。タグや回答で出し分け（セグメント）は スタンダード以上 | リッチメニュー＝スタート以上／出し分け＝スタンダード以上 |
| 流入経路分析 | 友だち追加した場所（どのLP・どのQR）を特定。**設定前からの友だちの経路は遡れない** | プロ |
| アクション管理（スケジュール） | 条件を満たした人にまとめて動作。スケジュール・定期実行はプロ | プロ |
| タグ／友だち情報／対応マーク／1:1チャット | 友だちごとの印・情報・対応状況の管理 | 全プラン |
| 予約管理（カレンダー予約） | LINE内で予約を取る。**未認識の友だちは予約画面に遷移しないことがある**（公式ブログ） | プロ（要確認） |
| CV計測・クロス分析・ファネル分析 | 配信→クリック→CVの分析 | プロ（要確認） |

## 3. 10/15〜20の疑問への答え

- **(1) Lステップで全員向けに設定したリッチメニューは、まだLステップに入っていない人にも表示されるか** → **表示される**と読める（出し分けの説明に「条件を満たす前の人にはデフォルトのメニューが表示される」。導入前の友だちを入れる方法として「リッチメニュー＋自動応答」が公式ブログに挙がっている）。要確認＝実機。
- **(2) URLを開くだけの枠を押した人も入るか** → **入らない。** 入るのは「ユーザーメッセージ送信」（友だちが文を送る）か、Lステップのアクション（タグ付け・自動応答）を付けた枠。今のOAMのA枠（LINEで相談＝文を送る）は入る。B〜F（URLだけ）は入らない。
- **エリア（都道府県）で送り分ける** → Lステップには LINE の推定属性（性別・年代・居住地）は無い。エリアで分けるには、①回答フォームで都道府県を答えてもらう（LINEログイン必須）か、②院ごとのLPを流入経路にする（新しい友だちだけ）。**今の約6,800人をエリアで分けられるのはOAMの属性フィルター（推定・3日前のデータ）だけ。**

## 4. ノーストでの使い方（10/20時点の整理）
- 配信はOAMから（Lステップに入っているのは有効90人・10/15）。**毎回の配信に「一言を送らせる」仕掛けを入れて、反応した人からLステップに入れていく。**
- Lステップに入った人＝予約に近い人。以後はLステップから、タグ（予約フォーム希望／予約済／来院済）で送り分ける・外す。
- アドアフィの計測（流入経路→予約LP→tagone）は別の仕組み。混ぜない（10/15）。
