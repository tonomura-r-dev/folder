## 0. 過去のCRから読み取った型（この依頼の前提）

### キャンペーン告知の定型
```
最大50%OFF

〔緊急性〕

〔キャンペーン名〕

名刺・ショップカード
チラシ・フライヤー
冊子

ご注文はこちらから！（CTA）
```

- **緊急性の段階**：「残り日数わずか！」→「まもなく終了！」→「本日終了！」
- **キャンペーン名は季節で変わる**：年度末応援 → 新春 → 新緑 → サマー
- **対象商材は3つ固定**：名刺・ショップカード／チラシ・フライヤー／冊子
  （年度末応援のみパンフレットが入っていた）

### 既に使われている強い一言
> **「データのご入稿は後でも大丈夫です！」**

「本日終了！」の回で使用されている。**注文だけ先に取る**導線。
入稿データが障壁になっていることをクライアント自身が認識している証拠であり、
前後検索（`canva` `イラストレーター`）・ADレポ（`カード 印刷 オーダー` がCV0で4.7万円）
の分析結果とも一致する。**③④で必ず使う。**

### 休業告知の定型（お盆の実例）
```
お盆期間中の印刷対応に関して

完全休業期間
　11日～16日

※8/10に関して
　受付確定の締切：16時　電話対応の締切：17時
　16時以降のご入稿→8月17日のデータチェック/受付確定

お早めのご入稿をオススメしております。
ご注文はこちら（CTA）
```
→ **9月の連休（9/21・9/23）も同じ告知が要る。** これが③の下敷き。

- `（LINE側でCTAを入れるのでスペースを空けておく）`
- `（CTA）`

## 2. 全カット共通の指示

### ⚠️ 絶対に守ること（法務）

> **「50%OFF」を単独で書かない。必ず「最大」とセットにする。**

商材ごとに割引率が異なるため、全商品が半額と受け取られると
**有利誤認（景品表示法）**にあたる。**画像内の文字も本文と同じ扱いで厳密に。**
過去のCRも全て「最大50%OFF」表記になっているので、これを踏襲する。

### 表示サイズの前提
LINEのトーク画面ではリッチメッセージは**かなり小さく表示される**。

- **いちばん上の1行だけ遠目で読めれば成立する。** 以下は読めなくてよい。
- 横長バナーを正方形にトリミングせず、**正方形用に組み直す**こと。
- **外周40pxには文字を置かない**（トーク画面で見切れる）。

## 3. カット別の入稿テキスト

### ② 9/8配信｜名刺の見直し

```
その名刺、最新ですか？

部署名・役職・住所・QRコード
気づかないうちに古くなっていることがあります

最大50%OFF
サマーキャンペーン

名刺・ショップカード
チラシ・フライヤー
冊子

～9月30日(水)まで

ご注文はこちらから！（CTA）
```

**ビジュアル：** 白い名刺の束。オフィスで配るビジネス名刺に見えること。

**⚠️「異動」「転勤」「内定式」は入れないこと。**
発注の動機は異動とは限らず（年末の挨拶まわりの可能性もある）、データでも確定していない。
「最新ですか？」ならどちらの人にも当たる。

### ③ 9/17配信｜連休中の印刷対応（休業告知）

```
9月の連休中の印刷対応に関して

休業日
　9月19日(土)・20日(日)・21日(月・祝)
　9月23日(水・祝)

※9月18日(金)に関して
　受付確定の締切：◯時　電話対応の締切：◯時
　◯時以降のご入稿→9月24日(木)のデータチェック/受付確定

お早めのご入稿をオススメしております。

最大50%OFF のサマーキャンペーンも9月30日(水)まで！

ご注文はこちらから！（CTA）
```

**ビジュアル：** カレンダーまたは砂時計＋印刷物。急かしすぎず、明るく。

**⚠️ 締切時刻（◯時）は社内確認後に確定。** お盆告知では「受付確定の締切：16時／
電話対応の締切：17時」だったので、同じ運用ならその値を入れる。
**確定するまでデザイナーに投げない**（時刻の誤記は事故になる）。

### ④ 9/30配信｜本日終了

```
最大50%OFF

本日終了！

サマーキャンペーン

名刺・ショップカード
チラシ・フライヤー
冊子

データのご入稿は後でも大丈夫です！

ご注文はこちらから！（CTA）
```

**ビジュアル：** 印刷物＋締切感。威圧的にはしない。

**※これは過去の「本日終了！」CRとほぼ同じ構成。** 実績のある型なので変えない。
「データのご入稿は後でも大丈夫です！」は必ず残す（注文の心理的ハードルを下げる一言）。

**⚠️「23:59まで」など具体的な時刻は入れない**（締め時刻が未確認のため）。
