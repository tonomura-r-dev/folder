## 2. 全カット共通の指示

### ⚠️ 絶対に守ること（法務）

> **「50%OFF」を単独で書かない。必ず「MAX」または「最大」とセットにする。**

全商品が半額だと受け取られると**有利誤認（景品表示法）**にあたる。
実際は商材ごとに割引率が異なるため、**画像内の文字も本文と同じ扱い**で厳密に。
むしろ画像のほうが目立つので、ここが最重要。

### 表示サイズの前提

LINEのトーク画面ではリッチメッセージは**かなり小さく表示される**。

- **「主役文字」だけが遠目で読めれば成立する。** 補助文字は読めなくてよい。
- 横長バナーを正方形にトリミングすると全要素が中途半端になるため、
  **必ずパーツを置き直して正方形用に組む**こと。
- **外周40pxには文字を置かない**（トーク画面で見切れる）。

### 版面の基本

| 領域 | y座標 | 役割 |
|---|---|---|
| 上 | 0–120px | 見出し・期限リボン |
| **主役** | **120–480px** | **主役文字（画面幅いっぱいまで大きく）** |
| 中 | 480–800px | 商材ビジュアル |
| 下 | 800–1040px | 補助文字・CTA |

### トンマナ
- 既存の9月キャンペーンバナー（SUMMER CAMPAIGN／ひまわり＋水色）を基調にする
- 文字色は黄色＋緑フチ（既存踏襲）
- 明るく、清潔感のある販促トーン。くすんだパステル調にはしない

## 3. カット別の指示

### ② 9/8配信｜名刺の見直し

| | |
|---|---|
| **主役文字** | **その名刺、最新ですか？** |
| 補助文字（下） | 名刺・ショップカード 最大50%OFF ／ 9/30(水)まで |
| ビジュアル | 白い名刺の束。オフィスで配るビジネス名刺に見えること |
| 狙い | 「部署名・役職・住所が古いままかも」と気づかせる |

**注意：** 「異動」「転勤」といった**動機を特定する文言は入れない**。
動機は異動とは限らず（年末の挨拶まわりの可能性もある）、データでも確定していない。
「最新ですか？」なら、どちらの人にも当たる。
