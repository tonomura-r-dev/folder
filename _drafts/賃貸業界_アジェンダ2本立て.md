## 0. 2本に分ける理由

| | **Ver.A｜入居者集客版** | **Ver.B｜オーナー開拓版** |
|---|---|---|
| 対象事業 | 賃貸仲介（お部屋探し）／仲介＋管理の地場賃貸会社 | 賃貸住宅の建築請負・土地活用／賃貸管理の受託 |
| **集める相手** | **入居希望者（B2C）** | **土地・アパートオーナー（B2B）** |
| 検討期間 | **2〜4週間**（極端に短い） | **1〜3年**（極端に長い） |
| 単価 | 仲介手数料＝家賃1ヶ月＋更新・住み替えでLTV | **1棟1〜2億円**／管理は月次フィーで長期LTV |
| 決裁者 | 本人（＋同居予定者） | **オーナー本人＋子世代の2世代** |
| 山 | **1〜3月に年間の約4割**が集中 | 季節ではなく**相続・確定申告・税制改正・修繕周期** |
| 主CV | 来店・内見予約 | 個別相談・セミナー予約 |

**同じ「賃貸」でも、ストーリーも施策も数値も共通点がほとんどない。**
だから1本にまとめず、2本に分ける。

## Ver.A｜入居者集客版（賃貸仲介・お部屋探し）

### この資料の背骨（1文）

> **賃貸は全社が同じ物件を扱っている。物件情報では差がつかない。
> 差がつくのは「返信の速さ」と「追いかけてこないこと」だけ。それを作れるのがLINE。**

### 注文住宅版との決定的な違い

| # | 違い | 資料への影響 |
|---|---|---|
| 1 | **商品が共通**（レインズ・ATBB経由で物件情報は全社同じ） | 差別化の論点が「物件」ではなく**接客体験**になる。ここが提案の核 |
| 2 | **検討2〜4週間** | ステップ配信は14日ではなく**7日間の短期集中**。14日では決まり終わっている |
| 3 | **反響の初動が命** | 「**5分以内に返信できるか**」で来店率が変わる。ここに1枚使う |
| 4 | **電話が繋がらない** | ポータル反響に架電しても出ない。LINEが唯一届く接点 |
| 5 | **繁忙期の山が巨大** | 1〜3月に約4割。閑散期は「次の繁忙期の仕込み」に使う |

### CV3段

| 段 | CV地点 | 位置づけ |
|---|---|---|
| ① 軽CV | LINE友だち追加＋**希望条件アンケート** | 電話番号を出さずに物件情報がもらえる |
| ② 主CV | **来店予約／オンライン相談・内見予約** | ここが主戦場 |
| ③ 最終CV／LTV | 申込・契約 → 更新・住み替え・ご紹介 | 退去時に他社へ流れるのを止める |

## Ver.B｜オーナー開拓版（土地活用・管理受託）

### この資料の背骨（1文）

> **オーナーは営業されたくないが、情報は欲しい。
> 訪問でも電話でもDMでもない接点が要る。しかも検討は1〜3年。伴走できるのはLINEだけ。**

### 注文住宅版との決定的な違い

| # | 違い | 資料への影響 |
|---|---|---|
| 1 | **決裁者が2世代**（オーナー本人＋子世代） | 「**子世代に転送されるコンテンツ**」が設計の核になる |
| 2 | **検討1〜3年** | ステップは短期集中では足りない。**年次のモーメント配信**が主役 |
| 3 | **季節性ではなくイベント駆動** | シーズナリティの代わりに**相続・確定申告・税制改正・大規模修繕の周期**を置く |
| 4 | **サブリース不信が業界的にある** | 「不利を先に言う」が注文住宅以上に効く。誠実さが唯一の差別化 |
| 5 | **単価が極大**（1棟1〜2億） | 歩留まり1ポイントのインパクトが桁違い。SIMの説得力が最も強い |
| 6 | 相談相手が銀行・税理士に分散 | 「誰に聞けばいいか分からない」を受け止める窓口になる |

### CV3段

| 段 | CV地点 | 位置づけ |
|---|---|---|
| ① 軽CV | **土地活用診断／空室・家賃査定**（住所だけで概算収支） | 訪問も電話もされずに数字がもらえる |
| ② 主CV | **個別相談・セミナー予約**（オンライン可） | ここが主戦場 |
| ③ 最終CV／LTV | 建築請負契約／管理受託 → 追加棟・修繕・売却 | 契約後もLINEが残る |

## 共通の枠（注文住宅版から引き継ぐ）

- **章立ては8章で共通。**FMT（36枚）から作れる形を維持する
- **広告の話は第1章の「スコープ宣言」1枚に集約する**（この資料はLINEOA運用の話）
  ※ LINE広告CPFは友だち追加動線なので第4章に残す
- 第7章に**成果SIM・費用プラン・運用スケジュール・サポート体制**を必ず入れる
  （注文住宅版の初回で抜けていた4枚）
- 鉄則・デザイン仕様は注文住宅版と同一（出典ラベル／推測禁止／9906000×6858000 EMU／メイリオ／3色）

## この段階での要確認

1. **Ver.A と Ver.B、どちらから作るか**（両方同時でも可）
2. Ver.A の対象は「仲介専業」か「仲介＋管理の地場」か
   → 仲介＋管理なら、**第8章に「オーナー向けの第2提案軸」を1枚足す**構成にできる
3. Ver.B の対象は「建築請負（土地活用）」中心か「管理受託」中心か
   → 主CVは同じだが、第4章の診断（土地活用診断／空室査定）の比重が変わる
4. 競合の選定（両版とも、確定したら友だち数の実測に入る）
   - Ver.A候補：エイブル／アパマンショップ／ミニミニ／ハウスコム／いい部屋ネット（大東建託パートナーズ）／ピタットハウス
   - Ver.B候補：大東建託／積水ハウス不動産／大和ハウス／東建コーポレーション／生和コーポレーション／シノケン
