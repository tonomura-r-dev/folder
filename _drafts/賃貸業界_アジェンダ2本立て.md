## 0. 2本に分ける理由

| | **Ver.A｜入居者集客版** | **Ver.B｜オーナー開拓版** |
|---|---|---|
| 対象事業 | 賃貸仲介（お部屋探し）／仲介＋管理の地場賃貸会社 | 賃貸住宅の建築請負・土地活用／賃貸管理の受託 |
| **集める相手** | **入居希望者（B2C）** | **土地・アパートオーナー（B2B）** |
| 検討期間 | **2〜4週間** | **1〜3年** |
| 単価 | 仲介手数料＝家賃1ヶ月＋更新・住み替えでLTV | **1棟1〜2億円**／管理は月次フィーで長期LTV |
| 決裁者 | 本人（＋同居予定者） | オーナー本人（＋子世代が関与することがある） |
| 山 | **1〜3月に年間の約4割** | 季節ではなく**相続・確定申告・税制改正・修繕周期** |
| 主CV | 来店・内見予約 | 個別相談・セミナー予約 |
| **最終ゴール指標** | **CPO（成約1件あたりの獲得コスト）** | **CPO（1棟受注／管理1件あたりの獲得コスト）** |

**両版とも着地は CPO。**「LINEを入れましょう」ではなく
「**リードを資産化すると、成約1件あたりのコストが下がる**」で締める。

### CPOの定義（業界汎用版はこれで固定）

```
CPO ＝ 投下コスト ÷ 成約件数
      （投下コスト＝既存の販促費 ＋ LINE運用費）

  Ver.A の「成約」＝ 賃貸借契約の成立（申込 → 契約）
  Ver.B の「成約」＝ 建築請負契約の成立／管理受託契約の成立
```

> **粗利ベースで見るか、成約件数ベースで見るかは会社によって違う。**
> 業界汎用版は**成約1件あたりのコスト**で統一し、
> 個別提案に落とすときにクライアントの定義へ合わせる（＝上司確認②で実績値をもらう）。

# Ver.A｜入居者集客版（賃貸仲介・お部屋探し）

## この資料の背骨（1文）

> **ポータル反響は、いま「使い捨て」になっている。
> Webマーケでできるのは、反響を資産に変えて CPO を下げること。
> 接客の質ではなく、反響の再利用率で勝つ。**

## ★ Webマーケで「できること／できないこと」を先に線引きする

ここが本提案の誠実さであり、説得力の源。**S06で1枚使って明示する。**

### できないこと（正直に書く）

- 担当者の接客トークの質そのもの
- 物件の仕入れ力・管理戸数
- ポータルの掲載単価（言い値。値切れない）

### できること（＝本提案の範囲）

| # | できること | 効くKPI |
|---|---|---|
| 1 | **反響の初動を自動化する**（5分以内の自動返信） | 反響→来店率 |
| 2 | **反響を友だち化してリスト資産にする**（ポータル反響は1回きりで捨てられている） | 翌期のCPO |
| 3 | **条件タグで物件レコメンドを自動配信する**（人力メールの置き換え） | 反響→来店率・工数 |
| 4 | **来店予約のリマインドでドタキャンを減らす** | 来店→成約率 |
| 5 | **決めなかった人・更新期が近い人を再アプローチする**（休眠再活性） | 追加成約・CPO |
| 6 | **ポータルを通さない自社反響をつくる**（友だちからの直接問い合わせ） | ポータル依存度 |

> **「接客体験を良くしましょう」ではなく、上の6つを自動化して CPO を下げましょう、が提案。**

## 3つの壁（Webマーケ側で語る）

| 壁 | 中身 | Webマーケで触れるか |
|---|---|---|
| ① ポータル依存 | 反響単価はポータルの言い値。下げられない | **触れない** |
| ② 取りこぼし | 初動が遅い／電話が繋がらない | **触れる**（自動化） |
| ③ 使い捨て | 決めなかった人・更新期の人が資産化されていない | **触れる**（リスト化） |

→ ②③を潰すと、**同じ反響数・同じ出稿費のまま CPO が下がる**。

## ステップ配信は14日。ただし山の置き方が注文住宅と逆

賃貸は検討2〜4週間なので、**Day10〜14が「他社で決まる直前」**にあたる。
＝ **14日目付近の最後の一押しが、最も刈り取れる**。

| 段 | 日 | 役割 |
|---|---|---|
| ① 初動 | Day0 | **5分以内の自動返信**＋希望条件アンケート |
| ② 提案 | Day1・Day3 | 条件タグに合う物件を配信。**来店を急がせない** |
| ③ 誘導 | Day5・Day7 | 内見・来店オファー①（オンライン内見の逃げ道つき） |
| ④ **クロージング** | **Day10・Day14** | **最後の一押し。**「まだお決まりでないですか」「今週末の空き枠」「申込前に確認すべき5つ」 |

> 注文住宅はDay6とDay14の2回オファーだったが、賃貸は**④に重心**。
> 検討が終わる直前に、最後にもう一度出てくる会社が獲る。

## CPOの語り方（S30の型）

**CPO ＝（ポータル出稿費 ＋ LINE運用費）÷ 成約件数**（成約＝賃貸借契約の成立）

```
Before（ポータルのみ）
  ポータル出稿費 ÷ 成約数 = CPO

After（ポータル × LINE）── 出稿費も反響数も据え置き
  ① 取りこぼし解消 → 来店率が上がる → 成約数が増える → CPOが下がる
  ② 翌期以降、友だちリストからの成約が上乗せ（追加出稿費ゼロ）
     → CPOがもう一段下がる

★ここが肝：ポータル反響は使い捨てなのでCPOは毎期リセットされる。
  友だち化すると資産として積み上がるので、CPOは期を追うごとに下がる。
```

**表の作り方**：Before / After（1年目）/ After（2年目）の**3列**にする。
2年目の列で「追加出稿費ゼロの成約」が乗り、CPOが二段で下がるのが一目で分かる。

# Ver.B｜オーナー開拓版（土地活用・管理受託）

## この資料の背骨（1文）

> **オーナーは営業されたくないが、情報は欲しい。しかも検討は1〜3年。
> 訪問・電話・DMは「その瞬間に検討中の人」しか拾えない。
> リードを寝かせて資産にできれば、1棟あたりの獲得コスト（CPO）は劇的に下がる。**

## ★ この版の主役は「ステップ配信」ではなく「モーメント配信」

検討1〜3年に対して、追加直後の短期ステップだけでは持たない。
**主役は年次のイベント駆動配信（企画投稿）**、ステップは初動30日だけの補助にする。

| | 役割 | 比重 |
|---|---|---|
| **モーメント配信（年次）** | 相続／確定申告／税制改正／大規模修繕の周期に合わせて出す | **主役** |
| **企画投稿（月次）** | 事例・利回り・エリア相場・法改正の解説 | **主役** |
| ステップ配信（初動30日） | 診断結果 → 事例 → 収支の考え方 → 相談オファー | 補助 |

| 通知メッセージ | 既存オーナーへの空室アラート・修繕提案 | LTV側 |
