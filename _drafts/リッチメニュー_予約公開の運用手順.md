# リッチメニュー 予約・公開の運用手順（LINE Official Account Manager）

作成: 2026-09-01 / 場所: ホーム → トークルーム管理 → リッチメニュー
※ 実画面（manager.line.biz）で確認済みのボタン名で記載

## 前提（ここを外すと必ず詰まる）

- タブは2つ。**「予約・公開」**＝公開中＋予約済み、**「待機中」**＝下書き・期間切れの置き場。
- **同時に公開できるリッチメニューは1つだけ。**
- **表示期間が重複していると保存できずエラーになる。**
  → 必ず「先に今のを止める」→「後から新しいのを予約」の順。逆にすると保存できない。
- 反映はLINEアプリ側のキャッシュで数分ラグあり。確認は実機のトーク画面で。

## ボタンの対応（重要）

編集画面の最下部に2つ並んでいる。押し間違えると事故る。

| ボタン | 行き先 | 使いどころ |
|---|---|---|
| **下書き保存**（白） | **「待機中」タブ** | 公開を止めたいとき／CR待ちで寝かせるとき |
| **保存**（緑） | **「予約・公開」タブ** | 公開・予約を確定するとき |

## A. 今出ているものを「待機中」に移す ← 2026/09/01 はこの方針を採用

1. 「予約・公開」タブを開き、**どれが「公開中」か先に確認**する
   （ステータス表記は「公開中」／「予約」。開始日時が未来のものは「予約」）
2. 対象のリッチメニューを開く
   → 詳細ページには「削除」と「編集」しかないので、**右上の緑の「編集」** から入る
3. 編集画面をいちばん下までスクロール → **「下書き保存」**（白いボタン。緑の「保存」ではない）
4. 「待機中」タブに移っていればOK
5. **「予約・公開」タブに残りがあれば全部同じ手順で移す**
   （1つでも表示期間が残っていると、新メニューと重複して保存できない）

⚠️ 待機中に移した瞬間からユーザーにメニューが出なくなる（メニューバーごと消える）。
空白を作りたくないなら、待機中に移さず **終了日時＝切替時刻（今夜）に変更するだけ** でもよい。
そうすれば切替時刻まで今のメニューが出続け、そのまま新しいものへ引き継げる。

※ 待機中に移しても表示期間の設定値は残る。CR完成後に開始日時だけ今夜に直せばよい。

## B. CR完成後、夜に予約公開する

1. 「待機中」タブから対象を開く（新規なら「作成」）
2. **表示期間** を設定
   - 開始日時 ＝ 公開したい今夜の時刻（例 21:00）
   - 終了日時 ＝ 未定なら長めに取る
   - ※ 開始が1分でも未来なら「予約」となり、その時刻まで表示されない
3. 画像アップロード＋アクション（リンク先）設定
4. 最下部の **「保存」（緑）** を押す ←「下書き保存」だと待機中に戻ってしまい公開されない
5. 「予約・公開」タブに入る。開始時刻までは **予約**、時刻になると自動で **公開中** に切り替わる

## チェックリスト

- [ ] 「予約・公開」タブが空になった（＝旧メニューを全部「下書き保存」で待機中へ移した）
- [ ] 新メニューの開始日時＝今夜の時刻になっている
- [ ] 最後に押したのは緑の **「保存」**（白い「下書き保存」ではない）
- [ ] 一覧のステータスが「予約」になっている
- [ ] 切替時刻後、実機のトーク画面で表示を確認した

## 実運用ログ：プリントアース（inkart.jp）2026-09-01

現状（2026/09/01 時点）
- 「予約・公開」：`20260629_Ver.1.0.0` 表示期間 **2026/09/01 00:00 - 2026/09/07 23:59**（つなぎで公開中）
- 「待機中」：`20260820_Ver.2.0.0`（表示期間 2026/08/20 13:10 - 2029/12/31 23:59 のまま温存）
- 新CRはデザイナーが作成中。**今日中に完成予定**。

⚠️ **今夜の切り替えでハマるポイント**
つなぎの Ver.1.0.0 が **9/07 まで** 入っている。このまま新CRを今夜開始で保存しようとすると
**表示期間が重複して保存できない**。必ずこの順で：

1. `20260629_Ver.1.0.0` を開く → 編集 → **終了日時を今夜の切替時刻の1分前**（例 2026/09/01 20:59）に変更 → 緑の「保存」
2. 新CRのリッチメニューを作成 → **開始日時＝今夜の切替時刻**（例 2026/09/01 21:00）→ 緑の「保存」
3. 「予約・公開」タブでステータスが **予約** になっていることを確認
4. 切替時刻を過ぎたら実機のトーク画面で表示確認

※ 終了と開始を同じ時刻にすると重複扱いになる可能性があるので、**1分空ける**のが安全。
