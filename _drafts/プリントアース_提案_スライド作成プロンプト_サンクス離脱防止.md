### 5. 作り方

1. **BUFFFのテンプレートは作業ブランチ `claude/printearth-inkart-verification-tey119` にしか無い（masterには無い）。最初に取ってくる：**
   `git fetch origin claude/printearth-inkart-verification-tey119`
   `git checkout origin/claude/printearth-inkart-verification-tey119 -- _templates/DYM_LINEOA_BUFFF_62p.pptx`
2. 依存が無ければ入れる：`pip install python-pptx` ／ `apt-get update && apt-get install -y libreoffice-impress`（QA用）
3. スクリプトは `_build/build_inkart_thanks_proposal.py`。書き方は `_build/build_special_plan.py`（`clear_slide` `add_text` `add_box` `chip` `put_text`）と `_build/build_generic_lineoa.py`（`drop_slides`、shape_idで文字を差し替える方法）に合わせる。
4. BUFFFをコピー → 残すのは 1・6〜13・27・31・62 の12枚 → 並びを「1, 6, 7, 8, 9, 10, 11, 31, 27, 12, 13, 62」にする → 他は削除。
   - 6〜13の8枚は中身を作り直す枚。`clear_slide()` してから描く（S2〜S7、S10、S11に使う）。
   - **スライドの新規追加はしない**（python-pptxで壊れる）。削除と並べ替えだけ。
5. 料金は先頭の変数にまとめる（例：`PRICE = {"thanks_init": "〔 〕", "thanks_month": "〔 〕", "exit_init": "〔 〕", "exit_month": "〔 〕"}`）。S8・S9・S11はこの変数から入れる。
6. 出力：ルート直下に `YYYYMMDD_インクアート様_LINE公式アカウント_10月以降のご提案.pptx`（YYYYMMDDは作った日）
7. QA：`python _build/qa_render.py <出力.pptx> _qa` で全ページを画像にして目視。はみ出し・重なり・ページ番号とコピーライトが出ているかを確認して直す。
   - このクラウド環境にはメイリオが無いので、画像は代わりのフォントで出る。**最後の文字あふれ確認はPCのPowerPointで。**
8. pptxとスクリプトをcommitしてpushする。**`_memory/INDEX.md` と `CLAUDE.md` は触らない**（記録は元のセッションで行う）。

### 6. 報告

1. 出力ファイル名と枚数
2. 〔 〕のまま残した箇所（料金）
3. QA画像で直した所・直せなかった所
4. PCのPowerPointで確認してほしい所
