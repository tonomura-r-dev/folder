# A｜社内に依頼するもの（4件）

## A-1. DYMの賃貸業界の支援実績 ★最優先

**なぜ要るか：** これが入ると、S04・S29（Ver.A）／S04・S30（Ver.B）が
「業界水準の推計」から「**弊社実績**」に変わる。説得力が段違いになる。

**ほしい形：**

```
【Ver.A 用】賃貸仲介・管理のクライアント支援実績
  - 反響 → LINE友だち化率（%）
  - 友だち → 来店予約のCVR（%）
  - 来店 → 成約率の改善幅（Before → After）
  - 反響の初動返信を自動化した前後での来店率の変化
  - LINE経由の成約が全成約に占める割合（%）

【Ver.B 用】不動産・オーナー向けのクライアント支援実績
  - 友だち → 相談・セミナー予約のCVR（%）
  - 相談予約のCPA（円）
  - 予約 → 実施率（ドタキャン率）
  - 診断コンテンツの完了率（%）
```

**無い場合：** 「賃貸業界の実績なし」と正直に回答してください。
近接業界（不動産売買・住宅）の実績があれば、**業界を明記した上で**代替に使います。

## A-2. 出典未確定数値の扱い（★注文住宅版と同じ問題が必ず起きる）

**なぜ要るか：** ベースにするFMT（`_templates/DYM_LINEOA_FMT.pptx`）には、
**出典が資料内に書かれていない数値が4枚**ある。注文住宅版ではこれが赤4枚になり、
**対外提出不可**の状態で止まっている。**賃貸版でも同じ4枚で必ず引っかかる。**

| 枚 | 数値 |
|---|---|
| S18相当 | 「業態平均で最大3%」「3% / 1.5% / 2.5% / 2%」 |
| S24相当 | 「CVR 2%前後 → 5〜10%に引上げ」 |
| S25相当 | 「商談化70%改善事例も」「再CV率3〜8%」 |
| S29相当 | 「友だち追加率を0.8〜1.0%前後に改善」 |

**ほしい回答：** 次のどちらか。
1. **出典を確定する**（社内実績なら「弊社支援実績（◯年◯月時点）」等のラベルを付ける）
2. **削除してよいと決める**

> **根本解決はFMT側を直すこと。**個別資料で毎回対処するのは非効率。
