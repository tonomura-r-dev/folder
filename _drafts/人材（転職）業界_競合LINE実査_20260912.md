## 2. 追加直後の設計（★これが本体）

### 型は3つに分かれた

| 型 | 会社 | 追加直後にやらせること | CVまでの距離 |
|---|---|---|---|
| **① LINE内完結型** | **UZUZ／マイナビ保育士** | **その場で選択式の質問に答える** | ボタン1つ |
| **② 外部登録型** | リクルートエージェント／type転職エージェント | アカウント連携・会員登録フォームへ | **LINEを出る** |
| **③ 分岐提示型** | doda | カウンセリング前／済みで2択 | あいさつ1行のみ |

### 各社の実物

**リクルートエージェント（146万人）**
- あいさつ：「まずアカウント連携してみましょう！／連携が完了すると、新着のおすすめ求人が届きます！」
- 直後に大きなカード「**ご利用にはアカウント連携が必要です！**」＋「いますぐ連携」ボタン
- リッチメニュー **3枠のみ**：アカウント連携／求人一覧／マイページ
- → **146万人集めて、最初にやらせるのが連携。連携しない人はここで止まる**

**doda（134万人）**
- あいさつ：**1行だけ**「dodaエージェントサービスのLINEアカウントです。」
- リッチメニュー **2枠**：「カウンセリング実施前 → カウンセリング申し込み」「実施済み → dodaとリンク」
- → 状態で分けるのは上手いが、**あいさつで何も起こしていない**

**type[転職]（29万人）**
- あいさつ：「あなたの希望や行動にあった求人情報を配信します」→ 直後にカルーセル（人気求人ランキング／フルリモート特集）
- リッチメニュー：LINEで転職活動をもっと簡単に（連携）／必見求人／希望から見つける／公式アプリを使う
- → 情報配信型

**type転職エージェント（6.8万人）**
- あいさつ2通目が「**まずは以下リンクをタップし、登録を完了させてください**」で外部フォームへ
- リッチメニュー 6枠：マイページトップ／面談・面接カレンダー／登録情報の更新／提案・選考中の求人一覧／選考後アンケート／弊社までのアクセス
- → **登録済みの人が使う道具**になっている

**UZUZ（2.6万人）★面談予約率55%（LINEヤフー公式）**
- あいさつ：名前差し込み →「UZUZのLINEでは、・無料面談のご調整 ・ここでしか聞けない『就活の限定情報』の配信 などを行なっています！」
- →「まずは、数点だけ質問させてください」＋**黄色ボタン「サクッと質問に答える」**
- → 併せて**橙ボタン「無料面談を申し込む」**（今すぐ勢の逃げ道）
- リッチメニューに**吹き出し「まずは30秒アンケートに答えてから！」**
- 背景画像に「ブラック企業徹底排除／半年後定着率93%超／他社の10倍を誇るサポート時間」
- **アンケートは選択式のみ**。最後の設問＝「今の職場で困っていること」4択
  （給与が低く、将来が不安／残業が多く、プライベートがない／人間関係や社風が合わない／スキルアップできる環境にいたい）
- 回答後：「これであなたのことが少しだけわかりましたので、これからあなたに合った情報をお届けしていきます／LINE限定の特典も配布中」＋**再び「無料面談を申し込む」ボタン**
- → **職務経歴を一切書かせずに属性を取り、その場で面談へ**

**マイナビ保育士 ★UZUZと同型でさらに作り込み**
- あいさつ直後に**大きな画像ボタン2つ**：「非公開求人を見たい人はこちら」「**簡単3問ですぐわかる！おすすめ求人診断はこちら**」
- リッチメニュー **2タブ×6枠**（転職サポート／転職お役立ち情報）
- **診断が3種類**：保育士の適正年収診断／おすすめ求人診断チャート／求人マッチング診断
- 「ご友人・ご家族紹介キャンペーン **¥3,000円分進呈**」
- → **同じマイナビでも、保育士（職種特化）は診断ドリブン、転職（総合）は情報配信型**

## 3. ★この実査で変わったこと

**①アジェンダの仮説「診断ドリブン型が空いている」は、正確には違った。**

> **空いているのではない。総合大手がやっていないだけ。
> 特化型（UZUZ＝第二新卒、マイナビ保育士＝職種特化）は既にやっていて、成果も出ている。**

| | 総合大手 | 特化型 |
|---|---|---|
| 例 | リクルート・doda・type・マイナビ転職 | **UZUZ・マイナビ保育士** |
| 追加直後 | 連携・登録フォームへ | **LINE内で診断・アンケート** |
| 狙い | 会員基盤に載せる | **属性を取って出し分ける** |
| 成果 | — | **UZUZ 面談予約率55%**（LY公式） |

提案先（中小〜中堅のエージェント）にとってはむしろ good news。
**「大手と同じことをやっても勝てない。特化型が取っている型は、成果が出ている」**と言える。
