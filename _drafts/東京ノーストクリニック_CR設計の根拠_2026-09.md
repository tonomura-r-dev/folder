## 4. だからこのCRになる

| CRの要素 | 決めた理由 |
|---|---|
| **緑（#00806B）×オレンジ（#EE7800）** | 5社が全部紺・青。**HPのトンマナがそのまま差別化になる** |
| **極太ゴシック。明朝を使わない** | 上野が明朝＋青。HPに合わせると自動的に上野と分かれる |
| **人物を出さない** | 症例写真NG。競合はイラスト。**実写の医師は支給品を使う前提**なので参考版では空ける |
| **数字3つを白い円で** | **価格で戦えないので事実で戦う。** HPのファーストビューの円をそのまま流用 |
| **「男性スタッフのみ」を円の中央に置く** | 5社の誰も言っていない唯一の差だから、真ん中に置く |
| **「年内に」をオレンジで最大** | 煽れない（§6）ので、**12/30〜1/4休診という事実**から時期の理由を作る |
| **CTA「まずは相談してみる」** | 予約を求めない。**全社が「答えるだけ」から始めている**のと同じ発想 |
| **※当院は自由診療です。** | HPに準拠。ガイドライン対応 |
| **ロゴと医師写真は支給品** | AIに描かせると別人・別ロゴになる |

### 文面側の設計

| 要素 | 理由 |
|---|---|
| **冒頭に「※すでにご来院・ご相談いただいた方はご放念ください」** | **友だちに治療済みの人が混ざっている**（チャット画面の表示名「米山☀️5/31名古屋治療済」）。L-STEPがないので除外できず、文面で回避するしかない。**メンズライフが実際に同じことをやっている** |
| **「日程・治療等についてもご相談ください」** | 空き状況を約束しない。チャットの対応体制に負荷をかけない |
| **治療内容・費用を出さない** | 殿村さん判断。**結果として類型Bを外れ、必須表示5点が不要になった**＝待ちゼロで打てる。§2のインフォームド・コンセントの姿勢とも一致 |

## 5. このCRで何をするか

### 目的：月3件のCV。7,347人の 0.04%

**説得の問題ではなく、取りこぼしの問題。**

### 役割は3つ

1. **9ヶ月の沈黙を切る。**
   同じ9ヶ月で上野は18〜36本、アトムは45〜135本送っている。**ノーストは0本。**
   「なぜ他社ではなくうちか」の答えは、まず**思い出してもらえること**。
2. **今動きかけている人を取りこぼさない。**
   7,347人の中に「そろそろやるか」と思っている人は必ずいる。
   9ヶ月何も来ていないので、その人たちは何もアクションできていない。
3. **クリック者オーディエンスを作る。**
   現状のオーディエンスは全部インプレッション（見ただけ）で、**クリックが1件もない。**
   1本目のクリック者が2・3本目の母数になる。

### 逆算

```
全配信         7,347人
　↓ 開封 23.8%（2025/12/12の実績）
開封          1,750人
　↓ クリック 10%
クリック         175人
　↓ 予約 2%
予約            3.5件
```

**クリック10%はリッチメニューの実績（相談8.4%／FAQ6.8%）から妥当な線。**
月3件は1本目だけで届く。2・3本目は175人に打てるので上積み。

### 測るもの

| 指標 | 基準 |
|---|---|
| 開封率 | **23.8%を超えるか**（2025/12/12 金11:15の実績） |
| クリック率 | **初めて取る数字**。以降の基準になる |
| チャット・予約の流入件数 | 手動対応の負荷も同時に見る |

**9/11(金)21:00に打てば、過去の金11:15と曜日を揃えた時間比較になる。**

## 6. やらないと決めたこと

後から蒸し返さないための記録。

| やらないこと | 理由 |
|---|---|
| 価格を出す | §7の宣言と競合の二重価格。定価で戦う |
| 体験談・症例写真 | §4の宣言 |
| 期限の煽り（「まもなく終了」「予約が埋まる」） | §6の宣言＋§7の客観的根拠 |
| 診断・アンケート | L-STEPがないと中途半端になる。**3枠のうち1本を潰してCVを捨てることになる** |
| エロ訴求 | 50歳以上が90.8% |
| 空き状況のお知らせ | 約束するとチャットの手が回らない |
| 実年齢の裏取り | **目的はCV。データ取りを目的にしない** |
