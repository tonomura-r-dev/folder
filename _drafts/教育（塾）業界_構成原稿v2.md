## 共通ルール

- **提案先**：大手・中堅の塾（個人塾は対象外）
- **ターゲット**：保護者（特に母親）。子ども向けの視点は入れない
- **成果**：CV①資料請求 → CV②体験予約 → 入会（契約）。入会は教室で行うため、LINEでは計測しない
- **範囲**：入会まで。退会防止・在籍生向け・入会後の話は入れない
- **流れ**：市場の課題 → 広告の課題 → 検索データ → 各社LINEの今 → 考え方 → 施策 → 運用・費用
- **8フェーズの帯**：検索データのページから入れる。各社LINEのページには入れない。表紙・アジェンダ・市場・広告のページにも入れない
  - 帯の表記：`①接触 → ②離脱 → ③育成 → ④リード獲得 → ⑤リード有効化 → ⑥再育成 → ⑦入会（契約） → ⑧紹介`
  - そのページで話しているフェーズだけを紺で塗り、他は薄いグレー。⑧は今回は塗らない
- **施策ページの型**：左から「データ（事実）」→「すべきこと」→「LINE施策＋導線」の3段
- **使わない言葉**：スコープ／実来校／退会・退塾・解約／爆発的に／26日（仕込み開始日）／口コミは最後に立つ／この5つを外すと効かない

## 5. 考え方（8フェーズの帯あり）

### P10 LINEでできること（旧P5を図に）
- 帯：全フェーズを薄く塗る（全体の話）
- 見出し：**LINEでできること**（「スコープ」は使わない）
- 図：スマホの画面を中央に置き、周りに4つの丸。それぞれアイコン＋一言＋どのフェーズに効くか
  1. **タイプ別の診断**：「うちの子に合うのはどれ？」に、申し込む前に答える（④リード獲得）
  2. **LINEで資料請求**：電話も来店もなしで、コースと料金の資料が届く（④リード獲得＝CV①）
  3. **14日間の配信**：迷っている間に、役立つ情報を届けて体験へ（③育成／⑤リード有効化）
  4. **体験前のリマインド**：日時・持ち物・変更方法を前日に届けて、来てもらう（⑤リード有効化→⑦入会）
- 右下に小さく：LINEではできないこと（授業の質・合格実績はつくれない）
- 入会後の「お友達紹介の仕掛け」は入れない（入会前の「友だちと一緒に体験」はP16で扱う）

### P11 全体設計：8フェーズとCVの位置（旧P12）
- 帯：全フェーズ
- リード：軽い申し込み（資料請求）で先につながり、体験予約、入会へ進んでもらう。
- 図：8フェーズを横に並べ、下にCVを置く
  - ①接触：広告・チラシ・口コミ
  - ②離脱：サイトから帰る保護者を、離脱防止でLINEへ
  - ③育成：比べている間、LINEで情報を届ける
  - ④リード獲得：**CV① 資料請求**（友だち追加＋診断から）
  - ⑤リード有効化：**CV② 体験予約**
  - ⑥再育成：体験予約しなかった人へ、時期を変えて再案内
  - ⑦入会（契約）：教室で入会。LINEでは計測しない
  - ⑧紹介：今回は扱わない（グレー）
- 消すこと：「入会後もLTVのために設計する」

### P12 導線（旧P6）
- 帯：②離脱／④リード獲得／⑤リード有効化／⑦入会
- リード：電話や資料請求フォームに「ハードルが高い」と感じる保護者がいる。LINEなら、名前も電話番号も入れずに始められる。
- 図：**離脱防止 → 友だち追加 → 診断 → 資料請求（CV①） → 体験予約（CV②） → 入会（契約）**
- 「実来校」は使わない

## 6. 施策（8フェーズの帯あり・全ページ「データ → すべきこと → LINE施策＋導線」）

### P13 施策全体像（旧P13・旧P14をまとめる）
- 帯：全フェーズ
- リード：初めの1〜2ヶ月でつくるのは3つ。診断・リッチメニュー・14日間の配信。
- 左：初めにつくるもの
  - LINE公式アカウントの設定（未開設の場合）
  - 30秒診断（4問）
  - LINEで資料請求の仕組み
  - リッチメニュー（2タブ）
  - あいさつメッセージ
  - 14日間の配信（未入会の保護者向け）
  - キーワード自動応答（料金・体験・持ち物）
  - サイトの離脱防止ポップアップ
- 右：毎月まわすもの
  - 企画配信（月1〜2本）
  - 診断結果に合わせた出し分け配信
  - 体験予約者への前日リマインド（自動）
  - 月次レポート
- 消すこと：「LINEの後半戦は辞めさせない」／月次学習レポート／離脱予兆検知

### P14 構築① 友だち追加の入口（旧P15）
- 帯：①接触／②離脱／④リード獲得
- データ：サイトに来た保護者の多くは、名前を残さず帰る（P4）。一番の悩みは「合うか分からない」63.5%（P5）
- すべきこと：決断を迫らず、「資料と診断を受け取るだけ」でつながる入口をつくる
- LINE施策＋導線
  - 入口は3つ：サイトの離脱防止ポップアップ／チラシ・教室掲示のQR／**友だちからの紹介（入会前）**
  - ボタンの文言は「今すぐ体験」ではなく「受け取る」
- 実文（離脱防止ポップアップ）
  ```
  まだ、塾を決めなくて大丈夫です。
  30秒の診断で、お子さまに合う学び方（集団／個別／映像）と、
  コース・料金の資料をLINEでお届けします。
  ［ LINEで資料と診断を受け取る ］
  ※お名前・お電話番号は不要です
  ```
- 旧版の「在籍生への紹介案内」は消す

### P15 構築① つづき：友だちと一緒に通うメリット（新規）
- 帯：①接触／④リード獲得／⑤リード有効化
- データ：塾を知ったきっかけの1位は「知人・友人の口コミ」47.0%（POPER「Comiru」2022年・保護者300人）
- すべきこと：「友だちと一緒なら行ってみたい」を、体験予約のきっかけにする
- LINE施策＋導線
  - 友だちと一緒に体験できる枠をLINEで予約できるようにする
  - 一緒に体験したら、2人とも特典（例：体験後の学習相談、教材プレゼント）※特典の中身は塾ごとに決める
  - LINEのトークを友だちの保護者に転送するだけで、紹介できるようにする
  - 伝えるメリット：一緒に通う友だちがいると、通う習慣がつきやすい／励まし合える／送り迎えを分担できる
- 注記：旧版の「紹介経由の入会率70〜80%」は出典不明の業界推計なので載せない

### P16 構築② あいさつメッセージ（旧P16）
- 帯：④リード獲得
- データ：友だち追加の直後は、一番メッセージが読まれるタイミング
- すべきこと：最初の1通で、保護者が安心できることを先に伝え、診断へ進んでもらう
- LINE施策：あいさつメッセージの組み立て（「5つの法則」「この5つを外すと効かない」は使わない）
  1. 教室長の名前を出す（人の顔が見える安心感）
  2. 返信できる時間を書く（例：平日14〜21時）
  3. 届く頻度を書く（例：週1回）
  4. 営業のお電話はしないと書く
  5. 30秒診断へのボタン
- 実文
  ```
  はじめまして、◯◯塾 △△教室の教室長、佐藤です😊
  友だち追加ありがとうございます。

  このLINEでは、お子さまの勉強に役立つ情報を
  週1回お届けします。営業のお電話は一切しません。
  ご質問は、平日14〜21時にこのトークでお返事します。

  まずは30秒の診断で、お子さまに合う学び方と
  コース・料金の資料をお受け取りください👇
  ［ 30秒診断をはじめる ］
  ```

### P17 構築③ 30秒ぴったり診断（旧P17）
- 帯：④リード獲得／⑤リード有効化
- データ：塾選びで一番困ったこと「うちの子に合う塾が分からない」63.5%
- すべきこと：申し込む前に「集団・個別・映像のどれが合うか」を見せて、納得してから体験へ進んでもらう
- LINE施策＋導線
  - 4問・すべて選択式（旧P17の設問のまま）：学年／悩み／性格／いつから
  - 回答はそのまま配信の出し分けに使う
  - 結果画面：共感 → 同じタイプの事例 → 費用の目安 → 「資料を受け取る」（CV①）→「無料体験を予約する」（CV②）
- 消すこと：「早期退塾を防ぐ」「リテンション施策」、DeltaXの退塾データ
- 注記：トライ（性格別学習法診断）など、競合の診断はP9の結果で差し替え

### P18 構築④ リッチメニュー（旧P18）
- 帯：全フェーズ
- データ：スマホは右手で持つ人が多く、親指が一番届きやすいのは画面の右下
- すべきこと：一番押してほしい行動を、右下に置く
- LINE施策：2タブ×6枠（塾生向けタブは外す）
  - タブ① はじめての方
    | 左 | 中 | 右 |
    |---|---|---|
    | 🎯 30秒ぴったり診断 | 💰 コース・料金 | 🏫 教室・講師紹介 |
    | 📄 資料を受け取る | 👫 友だちと一緒に体験 | **📅 無料体験・教室見学の予約（右下）** |
  - タブ② 体験予約済みの方
    | 左 | 中 | 右 |
    |---|---|---|
    | 📋 体験当日の流れ | 🗺️ アクセス・持ち物 | 👨‍🏫 担当講師の紹介 |
    | 💬 保護者の声 | ✉️ LINEで質問 | **🔁 日程の確認・変更（右下）** |
- 消すこと：タブ③（欠席・振替／面談予約／休会・退会のご相談ほか）、「左上に最重要CTA」

### P19 構築⑤ 配信の出し分け（旧P19を入会前だけに）
- 帯：⑤リード有効化／⑥再育成
- データ：同じ内容を全員に送ると、合わない人にはブロックされる
- すべきこと：保護者ごとに「うちの子の話」になる配信にする
- LINE施策
  - 診断タグ：学年／悩み／性格／いつから
  - 行動タグ：どのボタンを押したか／資料請求したか／体験予約したか・来たか
- 消すこと：在籍データ（出席・テスト・宿題）、塾管理システムとの連携

### P20 配信設計：14日間の配信（旧P20をシナリオ1本に）
- 帯：③育成／⑤リード有効化／⑥再育成
- データ：【データ待ち：前後検索】保護者が比べている間に何を調べているか
- すべきこと：比べている間、売り込みではなく役に立つ情報を届け、体験予約に進んでもらう
- LINE施策（未入会の保護者向けだけ）
  | 送る日 | 場面 | 内容 | 目的 |
  |---|---|---|---|
  | 登録した日 | 友だち追加の直後 | あいさつ＋30秒診断 | 悩みと学年を知る |
  | 3日後 | 比べ始めたころ | 家でできる勉強のコツ | 役立つ塾だと知ってもらう |
