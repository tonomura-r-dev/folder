# ＜ここからプロンプト：展示会編＞

あなたはDYMのLINE公式アカウント運用コンサルタントです。
**展示会集客のLINE運用方針の提案資料（PPTX 14〜18枚）**を作ってください。

## 0. 最初に読むもの

1. `CLAUDE.md`（★禁止事項を必ず守る）
2. `_memory/INDEX.md`
3. `_templates/DYM_LINEOA_FMT.pptx`（ベースにするFMT）

**⚠️ FMTの罠：名前は汎用だが中身は人材（転職）業界の提案書が元。**
転職者向けの設問・繁忙期・ダミーテキスト（「すうじ」「ロゴ」「あああ」）が残っていないか、全枚必ず確認すること。

## 1. 禁止事項（違反しない）

- **PowerPoint / Excel / Word のプロセスを絶対に落とさない。** ファイルがロックされていたら「閉じてください」と頼んで待つ。`taskkill` は禁止
- **FMT原本（`_templates/`配下）は編集禁止。** 必ずコピーして作る
- **スライドの新規追加はしない。** FMTから削除＋並べ替えで構成する（python-pptxで追加するとパート名重複で壊れる）
- **頼まれていない物を先に作らない**

## 2. 背骨（1文）

> **フリークエンシー5.24は「配信の失敗」ではなく「母数が尽きた」というサイン。
> 同じ予算を、まだ届いていない層のいるLINEに移す。**

## 3. 章構成（この順で作る）

### ① 課題提起 ― 3枚

**言い方の指定：「予算が悪い」でも「クリエイティブが悪い」でもなく、「母数が枯れている」と説明する。**

| エリア | オーディエンス | F | 状態 |
|---|---|---|---|
| 日向 | 4,400 | 5.24 | 完全に枯れている |
| 三鷹 | 10,700〜12,600 | 5.24 | 頭打ち |
| 高松 | 上限25,000 | 5.24 | 余地わずか |

- 現状CPA：15,000円以上／フリークエンシー：5.24
- **F5.24 ＝「1人に月5回出している」**と翻訳して見せる
- 日向4,400人は予算を積んでも新規に届かず、表示回数が増えるだけ → CPAはさらに上がる構造
- **グラフ案**：横軸＝オーディエンス数、縦軸＝F、バブル＝予算。右下（母数小・F高）が削減対象と一目で分かる図にする

### ② 提案方針 ― 2枚

- エリア別予算を見直し、**削減基準は「オーディエンス数 ÷ F」**。枯れているエリアから順に削る
- 例：銀座店 30万 → 20万
- **抽出する新規予算：100,000〜300,000円**
- 新規施策は2本：LINE広告（通常）＝媒体を変えて層を変える／LINE広告（CPF）＝友だち獲得の最大化

★ エリア別予算の一覧表は
https://docs.google.com/spreadsheets/d/1nJfrRrkNuwt3LVXe_tgeGzPW3pDJngwkvT6IcCzeMps/edit?gid=501516634
にある。**開けない場合は破線の差込枠にして「データ待ち」と明示**し、勝手に数値を作らないこと。

### ③ LINE広告（通常） ― 3枚

**ユーザー層の違い（Metaとの差別化）**
LINEは月間9,700万人。Metaで枯れた母数の**外側**（SNS非アクティブ層・高年齢層）に届く。「Metaの代わり」ではなく「Metaが届かない層」という位置づけで書く。

**想定数値（予算20万円・★仮置き）**

| | 保守 | 標準 |
|---|---|---|
| CPC | 150円 | 100円 |
| クリック | 1,333 | 2,000 |
| LP CVR | 1.0% | 2.0% |
| 予約件数 | 13件 | **40件** |
| CPA | 15,000円 | **5,000円** |

保守ケースでも現状CPAと同水準（悪化しない）ことを明示する。

### ④ LINE広告（CPF） ― 3枚

**想定数値（予算10万円・★仮置き）**

| | 保守 | 標準 |
|---|---|---|
| CPF単価 | 150円 | 100円 |
| 友だち獲得 | 667人 | **1,000人** |
| 友だち→予約CVR | 3% | 5% |
| 予約件数 | 20件 | **50件** |
| 実質CPA | 5,000円 | **2,000円** |

**CPFの本質を1枚使って書く**：通常広告は打ち切ったらゼロ。CPFは友だちが残り、次回以降の展示会でも使える。**今回の予約数ではなく資産形成として評価してほしい**、という主張。

### ⑤ 友だち登録後の引き上げ ― 3枚

目的：**見込み顧客をLINEに貯め、今後メッセージでアプローチする。**

| タイミング | 内容 |
|---|---|
| 登録直後 | 展示会の概要＋来場予約 |
| 2週間前 | 見どころ・出展内容 |
| 3日前 | リマインド＋アクセス |
| 当日朝 | 本日開催のお知らせ |
| 終了後 | お礼＋個別相談／次回案内 |

**LINEトーク画面のモックを1枚**入れる（実際の見た目を見せる）。

### 締め ― 1〜2枚

- **仮置きしたのは2つだけ**（LP CVR／友だち→予約CVR）と明示
- **半分しか達成できない場合の数字**も出す（感度分析）
- ネクストアクション3点

## 4. 未取得データ（差込枠にして「データ待ち」と明記する）

## 2. 背骨（1文）

> **購入の一歩手前まで来ている人が、毎月6万件以上、連絡先を残さずに消えている。
> 新しく集めるのではなく、この人たちをLINEに貯めて育てる。**

## 3. 章構成（この順で作る）

### ① 課題提起 ― 3枚

**GA 過去2年間の実データ（＝事実。チェックリストで緑になる）**

| 遷移 | 率 |
|---|---|
| カート追加 → 購入 | 15.71% |
| お気に入り → 購入 | 21.28% |
| 会員登録 → 購入 | 58.82% |

**言い方**：会員登録まで進んだ人は58.82%買う。**つまり「買う気がない」のではなく「あと一歩の接点がない」だけ**。カートに入れた人の84%、お気に入りに入れた人の79%が、連絡先を残さないまま消えている。

★ 数値まとめは
https://docs.google.com/spreadsheets/d/1j2NQ80Zb6gjNkCRQJX5G4z8PMvOR_1V21XkB6dfDfas/edit?gid=1550533883
にある。**開けない場合は上の3数値だけで組み、他は差込枠にする。**

### ② 提案方針 ― 2枚

- **目標：潜在顧客をLINEに誘導し、購入まで育成する**
- 施策は3本立て：**友だち登録までの導線／メッセージによる育成／売上計測（GA）**

### ③ 友だち登録までの導線 ― 4枚

**各ステップに合わせて導線を設置する、という図を1枚。**

| 経由 | 施策 | 月間イベント | 友だち化率（★仮置き） | 目標/月 |
|---|---|---|---|---|
| 会員登録 | OptionAPI 通知メッセージ | 8,861 | 25% | **2,215人** |
| お気に入り | ポップアップバナー（クーポン訴求） | 24,500 | 3% | **735人** |
| カート | ポップアップバナー（クーポン訴求） | 33,174 | 3% | **995人** |
| | | | **合計** | **3,945人/月** |

**会員登録だけ25%と高い理由を必ず書く**：OptionAPIは登録フローに組み込まれるため摩擦が小さい。
**保守ケース**（会員15%／その他2%）＝ **2,482人/月** も併記する。

### ④ メッセージ送付 ― 3枚

- **かご落ちを軸にしたセグメント配信**
- メッセージ例：キャンペーン告知／アンケート
- **LINEトーク画面のモックを1枚**（かご落ちリマインドの実物イメージ）

★ **配信費は友だち数に比例して増える。** 全配信ではなくセグメント配信が前提であることを明記し、⑥のROAS計算の分母に必ず入れる。

### ⑤ CPF配信 ― 2枚

施策紹介と想定数値。**導線3本（会員登録・お気に入り・カート）は既存客の刈り取り、CPFは新規母数の獲得**、と役割を分けて書く。

### ⑥ 売上計画 ― 4〜5枚

**経由別CVR（月次・★仮置き）** ― 購入に近い順に高く置く

| 経由 | CVR | 根拠 |
|---|---|---|
| 会員登録 | 0.8% | メルマガGA 0.62% ＋ LINEの開封率差 |
| お気に入り | 1.2% | 検討中の層 |
| カート | 1.5% | かご落ち＝最も購入に近い |
| **加重平均** | **1.05%** | |

**友だち推移と売上**（現状3,000人／ブロック率 月3%／顧客単価 55,000円）

| | 友だち数 | 月間購入 | 月間売上 |
|---|---|---|---|
| 現状 | 3,000 | — | — |
| 3ヶ月 | 約14,000 | 147件 | 808万円 |
| 6ヶ月 | 約24,500 | 257件 | 1,414万円 |
| 12ヶ月 | 約44,000 | 462件 | **2,541万円** |

**ROAS**：分母に配信費を入れる。12ヶ月時点でセグメント配信（対象50%・月4通・3円/通）なら配信費 約26万円/月。

**年間計画SIMは別紙xlsxにする**（`lineoa-sim` スキルを使う）。スライドには推移グラフ3本（友だち数／売上／ROAS）だけ載せる。

### 締め ― 2枚

- **仮置きしたのは2つだけ**（友だち化率／経由別CVR）と明示
- **半分しか達成できない場合**の数字を必ず出す
- ネクストアクション3点

## 4. ★最重要の未確認事項

これで月次CVRは1.05%にも2.5%にもなり、**⑥の結論が3倍変わる**。

→ 資料には**必ず脚注で「0.62%は配信単位／月単位のいずれか要確認」と明記**すること。
確認が取れるまで、**保守側（1.05%）で作る。**
