# 単品リピート通販 業界汎用資料｜要旨（刺す一点）

作成日：2026-08-27　※スキル §10 STEP② の型（事実＋損失の一文・数字入り／言わないことリスト3つ）

---

## 軸は「LTV」で正しい（EC版と違う理由）

総合EC版では「LTV一本にすると前半が浮く」と書いた。**単品通販では逆で、LTVが全部を束ねる。**

| | 総合EC | **単品通販** |
|---|---|---|
| 買う前の損失 | **カゴ落ち約70%**（＝CPO側） | **ほぼ無い**（LPで直接買う設計） |
| 買った後の損失 | F2で6〜7割 | **初回離脱50〜60%＋解約** |
| → 軸 | LTV ÷ CPO（2つ要る） | **LTV 一本で足りる** |

**この資料の施策は、全部LTVの変数を動かしている。**

| 施策 | 動かすLTV変数 |
|---|---|
| 使用フォロー・F2オファー | 平均購入**回数**の入口 |
| 解約の受け皿・スキップ提案 | 平均継続**期間** |
| 定期引上・まとめ買い | 平均購入**単価** |

```
LTV ＝ 平均購入単価 × 平均購入回数 × 利益率
```

## 刺す一点（この36枚が言うこと・1文）

> **初回を買った人の半分以上が、1回で消えている。
> そして「解約したい」と思った瞬間、その人に触れる手段が電話しかない。
> だから年7万件の「解約できない」という相談になり、
> 顧客の寿命が、月次解約率3%なら33ヶ月、7%なら14ヶ月に分かれている。**

**LTVを削っているのは新規獲得の失敗ではなく、買った後の接点の無さ。**

---

## ★この資料の一番の魅力＝「LTVが上がると、広告が楽になる」

ここまで言い切るのが本提案の締め。**LTVの話をLTVで終わらせない。**

```
限界CPO ＝ 年間LTV −（広告費を除く年間の総費用 ÷ 顧客総数）
```

**限界CPO＝1件の新規獲得にかけられる広告費の上限（損益分岐点）。**

> **LTVが上がる → 限界CPOが上がる → 同じ広告枠でも勝てる範囲が広がる。**
>
> つまりこの提案は「CRMの話」ではなく、**「新規獲得が苦しい会社への回答」**でもある。
> 広告単価は下げられない（検索CPCは10年で168%、ネット広告費は構成比50.2%）。
> **下げられないなら、上限を上げるしかない。**

**★経営層に効くのはこの一文。** CRM担当にはLTV、経営層には限界CPOで届く。

## 損失を裏づける数字（出典ラベル必須）

| 事実 | 数値 | ラベル・出典 |
|---|---|---|
| **初回で半分以上が消える** | 初回購入後の離脱率 **50〜60%超**（美容・健康食品） | 業界水準 |
| F2転換率 | **30〜40%**（化粧品25〜35%） | 業界水準 |
| 定期引上率 | 約**20%** | 業界水準 |
| **解約率が顧客の寿命を決める** | 月次解約率 **3%→約33ヶ月／7%→約14ヶ月** | 業界水準 |
| **しかも下げられる** | 解約アンケート＋リテンションオファーの自動化で**月次チャーン1〜2%削減** | 業界水準 |
| **解約が社会問題になっている** | 定期購入の相談 **2021年度 58,526件 → 2022年度 74,146件**（2023年2月末まで）。主な苦情は「電話がつながらず解約できない」 | 業界水準：国民生活センター |
| **塞ぐのは違法** | 特商法改正（**2022年6月1日施行**）で**契約解除の妨害行為に罰則** | 法令 |
| 広告単価は下げられない | 検索CPC 10年で**168%**／ネット広告費 4兆459億円・構成比**50.2%** | 業界水準：キーワードマーケティング／電通2025 |
| 市場は伸びている | 化粧品通販91社合計 **5,921億円**・実質成長率**4.1%** | 業界水準：日本流通産業新聞 2025年版 |
| 対して | LINEは**当日中に約8割が開封** | **LY公式** |

## 起承転結への落とし込み

| | 中身 | 該当スライド |
|---|---|---|
| **起** マクロの厳しさ | 市場は伸びている。**が、広告単価は下がらない**（CPC 168%）。しかも**法律がビジネスモデルそのものを規制した**（特商法・薬機法・景表法の三重） | S03・S04・S07・S09 |
| **承** 深層心理 | 効果を実感する前に不安になる／定期に縛られたくない／**解約を言い出しにくい**。だから「電話がつながらない」が年7万件の相談になる | S05・S11 |
| **転** LINEでのCX改善 | **解約を止めるのではなく、解約の手前で受け止める。** スキップ・周期変更・休止を"先に"出す。24時間受けられる場所は電話ではなくLINE | S06・S21〜S26 |
| **結** 売上成果 | 月次解約率が1〜2%下がる → **平均継続期間が伸びる → LTVが上がる → 限界CPOが上がる → 広告が楽になる** | S27・S29 |

## 言わないことリスト（3つ）

| # | 言わない | 理由 |
|---|---|---|
| 1 | **「解約を止めましょう」「引き止めましょう」** | **特商法で解約妨害に罰則**。提案に入れた瞬間、先方のコンプラ担当が止める。**「止めない」と明記することが信頼になる** |
| 2 | **「広告をもっと回しましょう」「CPOを下げましょう」** | 広告単価は相場。こちらでは触れない。**触るのはLTV側だけ**（結果として限界CPOが上がる、という順序で語る） |
| 3 | **「LINEの開封率は60〜80%でメルマガの3〜4倍」** | **LY公式値ではない**（スキル §4 の禁止事項）。公式は「**当日中に約8割**」のみ |

※ 競合批判もしない。競合分析は**実測データのみ**で、型の分類に留める（S12）。

## 主KPIとの整合（ここがズレると資料が壊れる）

軸はLTV一本だが、**測る指標は2つに分ける**。LTVは遅行指標で、6ヶ月では動ききらないため。

| 要旨の損失 | 対応する主KPI | 測れる時期 | 該当スライド |
|---|---|---|---|
| 初回で半分以上が消える | **F2転換率** | 1〜2ヶ月で動く | S22・S27 |
| 解約の受け皿が電話しかない | **月次解約率（チャーン）** | 3〜6ヶ月で動く | S24・S27 |
| 　→ 両方の結果 | **LTV**（→ 限界CPO） | **12ヶ月以上** | S29 |

> **6ヶ月の提案でLTVそのものを成果指標にしない。** 動ききらないので約束できない。
> **F2転換率と月次解約率を握り、「その先でLTVと限界CPOがこうなる」を構造で示す。**
> （賃貸Ver.Bで「CPOは3年累積の参考値に留める」としたのと同じ考え方）
