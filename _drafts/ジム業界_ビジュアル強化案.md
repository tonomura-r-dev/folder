## 画像生成プロンプト（ChatGPT想定）

### 共通ルール（毎回コピペで先頭に）

```
以下は全カット共通の条件です。
・16:9の横長、長辺2000px以上。写真としてリアルなもの（イラスト・CG・アニメ調は不可）。
・日本国内のジムに見えること。海外の大型ジムやアメリカンな内装は不可。
・画像の中に文字・ロゴ・看板・数字を一切入れない（文字は資料側で載せます）。
・実在ブランドを想起させる意匠を入れない。
・人物は顔が特定できない撮り方（後ろ姿・横顔・手元・目線を外す）。
・色調は寒色寄り・彩度控えめ。上に濃紺を重ねるので全体はやや暗め・コントラスト低め、
　中央〜右に被写体の少ない余白を残す。
・レンズフレア、過度なHDR、広告バナー風の加工は不可。
```

### 表紙・中扉（5枚）

**P-01｜p1 表紙**
```
早朝の24時間フィットネスジムの内観。人はいないか、いても遠くに1人だけの後ろ姿。
ランニングマシンとフリーウェイトのラックが奥行き方向に並ぶ。窓から自然光が入り、
床とマシンにやわらかい反射。左下から右上へ抜ける奥行きのある構図で、右上に余白。
```

**P-02｜p8 中扉「配信の考え方」**
```
スマートフォンを見ている人の手元だけのクローズアップ。ジムのベンチに腰掛け、
横にタオルとドリンクボトル。画面の中身は写さず白く飛ばす。背景のジムは大きくボケている。
```

**P-03｜p20 中扉「施策の詳細」**
```
ジムの受付カウンター越しの引きの構図。木目とグレーの落ち着いた内装。人は写さない。
```

**P-04｜p36 中扉「具体プラン提示」**
```
無人のスタジオ（レッスン用の広い部屋）を引きで撮った写真。床材、ミラーウォール、
天井のライン照明。
```

**P-05｜p38 中扉「ご提案にあたり」**
```
ジムのエントランス外観を夜に撮った写真。ガラス張りで内部の照明が漏れている。
看板や文字は入れない。歩道側からの引き。
```

### 混雑↔閑散の対（p13 シーズナリティ）

**P-06｜1月＝混雑**
```
1月の混雑したフィットネスジム。ランニングマシンがほぼ全台埋まり、順番待ちの人が
数人立っている。全員後ろ姿か遠景で顔は判別できない。やや広角、密度が伝わる俯瞰気味
の構図。20〜50代の男女が混在した日本人の一般客。
```

**P-07｜10〜12月＝閑散**（P-06 を作った直後に続けて投げる）
```
今の画像と同じ場所・同じ画角・同じ照明・同じ色調のまま、利用者が1〜2人しかいない
状態にしてください。マシンの列がほぼ空いている以外は変えないこと。
```

> ⚠️ この2枚は「同じ部屋で人だけ違う」ことが命。別々に生成すると意味が消える。

### 人物カット4枚（p21 インサイト）

**P-08｜①接触＝痩せたいがまだ漠然**
```
夜、自宅のソファでスマートフォンを見ている30代の日本人。部屋は暗く、画面の明かり
だけが顔の下半分を照らす。顔は伏せぎみで表情は読めない。手前に菓子か缶飲料が少し写る。
生活感のある部屋。
```

**P-09｜②離脱＝比較して迷っている**
```
ジムの入る建物の前の歩道に立ち、スマートフォンを見ている人の半身。入るか迷って
立ち止まっている雰囲気。後ろ姿または横顔。夕方の光。
```

**P-10｜③来店＝勧誘されないか不安**
```
ジムのカウンターで、スタッフが利用者にタブレットを見せながら説明している場面。
二人とも横顔または後ろ姿。押し売り感のない、落ち着いた距離感。
```

**P-11｜④継続・紹介＝見てもらえている感**
```
トレーニング後、ジムのベンチでタオルを首にかけて水を飲んでいる人。やり切った後の
穏やかな空気。顔は横顔か俯き。窓からの自然光。
```

### スマホ合成用プレート（p23 / p27）

**P-12**
```
片手で持ったスマートフォンのクローズアップ。画面は真緑（#00FF00）の単色で塗りつぶす
（後で差し替えるため）。スマホは正面向き、傾きは5度以内。背景はジムの内装が大きく
ボケている。手はマニキュアや指輪のない自然な手。指の本数に注意。
```

### リッチメニュー背景3枚（p25 差し替え用・トーンを揃える）

**P-13〜P-15**（3:2、同じシリーズに見えること）
```
① 見学・体験タブ用：ジムのエントランス〜受付。暗く落として半透明の黒を重ねた状態。
② 診断・シミュレーター用：マシンエリアの引き。①と同じ処理・同じトーン。
③ 会員の方へ用：ロッカールームまたはスタジオ。①と同じ処理・同じトーン。
いずれも中央にアイコンを載せるので、被写体を端に寄せて中央を空けること。
```
