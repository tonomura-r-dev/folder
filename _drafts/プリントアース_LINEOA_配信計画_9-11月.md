## 1. 共通ルール（3ヶ月通し）

| 項目 | 内容 |
|---|---|
| **プラン** | **ライトプラン＝月5,000通。超過したら送れない（追加購入は不可）** |
| 本数 | **月4本**（上限。超えない） |
| **配信形態** | **全配信は月1本まで。残り3本はセグメント配信** |
| **吹き出し** | **1配信＝1吹き出しに統一**（通数が倍になるため） |
| サイズ | **1040 × 1040 px** 固定 |
| 割引表記 | **「最大」を必ず付ける**。サイズにより対象部数・割引率が異なるため外せない |
| 締切訴求 | **「本日終了！」は使わない**（殿村さん指示）。当日だと動ける人が限られる。<br>**「まもなく終了！」で終了3日前に打つ** |
| 曜日 | **月曜が最も強い。火曜は避ける。** 次点は木・金 |
| 時間 | **売り込み系は夕方17:00／急いでほしい系は朝10:00** |
| 必須の一言 | 締切回には **「データのご入稿は後でも大丈夫です！」**（注文のハードルを下げる） |

## 1-2. 通数の設計（これが本数と対象を縛る）

**ライトプラン＝月5,000通。通数は「配信人数 × 吹き出し数」でカウントされる。**
ターゲットリーチは1,673（2026-09-04時点、減少傾向）。

| | 1吹き出し | 2吹き出し |
|---|---|---|
| 全配信1本 | 約1,700通 | 約3,400通 |
| セグメント3本（各600人） | 1,800通 | 3,600通 |
| **合計** | **約3,500通 ✅** | **約7,000通 ❌ 超過** |

→ **2吹き出しでは月4本が成立しない。** 1吹き出しに統一する。

現行のCRテキストは「主役文字＋補助＋CTA」の構成なので、
**リッチメッセージ1枚に収まる。** テキストを別吹き出しで足す必要がない。

### 運用ルール：月末の1本ぶん（約600通）は必ず残す
ライトプランは超過すると送れない。
**月末の「まもなく終了」を打とうとして枠切れ、が最悪のパターン。**
月初に予算を割り付け、月末分を先に確保しておく。

### 未確定
**過去配信が1吹き出しか2吹き出しかは未確認。**
8月は人数ベースで4,869人分を送って5,000枠に収まっているため、
**1吹き出しの可能性が高い**が、CSVに `1_imp` と `2_imp` が両方あるため断定できない。
→ **メッセージ配信画面の「詳細を確認」で8月の消費通数を見れば確定する。**
（約4,900通＝1吹き出し／約9,700通＝2吹き出し）

## 2. 狙い概要の使い分け（過去20本の実績から）

**シートの「狙い概要」列は5種類。** 過去の配信20本での実際の振り方は以下のとおり。
勝手に増やさず、この5つから選ぶ。

| 狙い概要 | 使う場面 | 過去の該当 |
|---|---|---|
| **キャンペーン訴求** | そのキャンペーンの告知・リマインド・終了告知。<br>**「残り日数わずか」「まもなく終了」「本日終了」も全てこれ** | 8本（年度末応援／新春／新緑／サマー） |
| **新商品紹介** | 新しい商材・仕様の紹介 | 5本（うちわ、トレカ台紙、トレカ封筒・ケース） |
| **CPF流入ユーザーの新規会員登録** | 会員登録の訴求 | 3本 |
| **CV獲得** | 単発の商材訴求・値引き告知・**休業告知** | 3本（夏コミ同人誌、ポリうちわ10%OFF、**お盆休業**） |
| **購入への動線の明確化／CPの告知** | リッチメニュー関連 | 1本 |

**注意した2点：**
- **締切リマインドは「CV獲得」ではなく「キャンペーン訴求」。**
- **休業告知は「CV獲得」。**（お盆の実績がそうなっている）

## 3. CRの構成（全カット共通の型）

```
〔主役文字：1行。トーク画面で読めるのはここだけ〕

〔補助：対象・条件〕

〔キャンペーン名〕
～◯月◯日まで

ご注文はこちらから！（CTA）
```

### 版面（1040×1040）
| 領域 | y座標 | 役割 |
|---|---|---|
| 上 | 0–120px | 見出し・期限リボン |
| **主役** | **120–480px** | **主役文字。画面幅いっぱいまで大きく** |
| 中 | 480–800px | 商材ビジュアル |
| 下 | 800–1040px | 補助文字・CTA |

- **外周40pxには文字を置かない**（トーク画面で見切れる）
- 横長バナーをトリミングせず、**正方形用に組み直す**
- **1本1商材に絞る。** 複数商材を並べるのはキャンペーンの開幕・締切回のみ

## 6. OAM実績（2026-09-04に取得済み）

詳細は `_drafts/プリントアース_OAM分析_2026-09.md`。要点だけ：

| 項目 | 実績 |
|---|---|
| 友だち／ターゲットリーチ／ブロック | 2,660 ／ **1,673** ／ 978（**ブロック率36.8%**） |
| リーチの推移 | 6/30の1,910 → 9/4の1,673（**月80人ペースで減少**） |
| 全配信のブロック増 | 1回あたり **+19〜37人** |
| セグメント配信のブロック増 | 1回あたり **+3〜7人** |
| 全配信の開封率 | 30.1% → 20.8% → 19.7% → **16.6%**（単調低下） |
| セグメント配信の開封率 | **21.2〜70.9%** |
| 流入 | **97%が友だち追加広告**。ブロック率 29.9%（4-5月）→ **58.5%**（6-8月） |
| リッチメニュー | UUクリック率 7.2%。**面積あたりでは「商品一覧」が最強** |

**→ これが「全配信は月1本まで」の根拠。** 絞るほど開封が上がりブロックが減る。

### まだ取れていないもの
1. **クリック実績（clickUU）が全13配信で空。** クリックが1件も計測できていない。
   **効果測定が開封率までしか見えず、クリックリターゲティングも使えない。最優先の宿題。**
2. **8月の消費通数**（吹き出し数の確定に必要。§1-2参照）
3. 友だち追加経路の詳細（経路ごとのURL/QRを発行していないと「その他」に入る）
