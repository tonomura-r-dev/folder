## 1. 共通ルール（3ヶ月通し）

| 項目 | 内容 |
|---|---|
| **プラン** | **ライトプラン＝月5,000通。超過したら送れない（追加購入は不可）** |
| 本数 | **月4本**（上限。超えない） |
| **配信形態** | **全配信は月1本まで。残り3本はセグメント配信** |
| **吹き出し** | **1配信＝1吹き出しに統一**（通数が倍になるため） |
| サイズ | **1040 × 1040 px** 固定 |
| 割引表記 | **「最大」を必ず付ける**。サイズにより対象部数・割引率が異なるため外せない |
| 締切訴求 | **「本日終了！」は使わない**（殿村さん指示）。当日だと動ける人が限られる。<br>**「まもなく終了！」で終了3日前に打つ** |
| 曜日 | **月曜が最も強い。火曜は避ける。** 次点は木・金 |
| 時間 | **売り込み系は夕方17:00／急いでほしい系は朝10:00** |
| 必須の一言 | 締切回には **「データのご入稿は後でも大丈夫です！」**（注文のハードルを下げる） |

## 1-2. 通数の設計（これが本数と対象を縛る）

**ライトプラン＝月5,000通。通数は「配信人数 × 吹き出し数」でカウントされる。**
ターゲットリーチは1,673（2026-09-04時点、減少傾向）。

| | 1吹き出し | 2吹き出し |
|---|---|---|
| 全配信1本 | 約1,700通 | 約3,400通 |
| セグメント3本（各600人） | 1,800通 | 3,600通 |
| **合計** | **約3,500通 ✅** | **約7,000通 ❌ 超過** |

→ **2吹き出しでは月4本が成立しない。** 1吹き出しに統一する。

現行のCRテキストは「主役文字＋補助＋CTA」の構成なので、
**リッチメッセージ1枚に収まる。** テキストを別吹き出しで足す必要がない。

### 運用ルール：月末の1本ぶん（約600通）は必ず残す
ライトプランは超過すると送れない。
**月末の「まもなく終了」を打とうとして枠切れ、が最悪のパターン。**
月初に予算を割り付け、月末分を先に確保しておく。

### 未確定
**過去配信が1吹き出しか2吹き出しかは未確認。**
8月は人数ベースで4,869人分を送って5,000枠に収まっているため、
**1吹き出しの可能性が高い**が、CSVに `1_imp` と `2_imp` が両方あるため断定できない。
→ **メッセージ配信画面の「詳細を確認」で8月の消費通数を見れば確定する。**
（約4,900通＝1吹き出し／約9,700通＝2吹き出し）

## 2. CRの構成（全カット共通の型）

```
〔主役文字：1行。トーク画面で読めるのはここだけ〕

〔補助：対象・条件〕

〔キャンペーン名〕
～◯月◯日まで

ご注文はこちらから！（CTA）
```

### 版面（1040×1040）
| 領域 | y座標 | 役割 |
|---|---|---|
| 上 | 0–120px | 見出し・期限リボン |
| **主役** | **120–480px** | **主役文字。画面幅いっぱいまで大きく** |
| 中 | 480–800px | 商材ビジュアル |
| 下 | 800–1040px | 補助文字・CTA |

- **外周40pxには文字を置かない**（トーク画面で見切れる）
- 横長バナーをトリミングせず、**正方形用に組み直す**
- **1本1商材に絞る。** 複数商材を並べるのはキャンペーンの開幕・締切回のみ

カレンダー（10月）→ 年賀状（10〜11月）→ 名刺・挨拶状（10月末〜11月）と重ねている。

| 月 | 検証テーマ | 見るもの |

## 5. OAMから取りたいデータ

**LINEの実績が無いまま設計しているのが現状の最大の弱点。** 以下が入れば全部作り直せる。

| 優先 | 場所 | 分かること |
|---|---|---|
| **1** | 分析 → **メッセージ配信**（CSV／期間は最大） | **訴求別の勝敗。** 過去CR20本と突き合わせれば「何が効いたか」が実測で出る |
| 2 | 分析 → **友だち** | 友だち数・ターゲットリーチ・**ブロック推移**。月4本が適正かの判定 |
| 3 | 分析 → **リッチメニュー** | タブ別クリック。使われていない枠が分かる |
| 4 | 設定 → **友だち追加経路** | 友だちが購入済みか未購入か。**訴求が真逆になる** |

**1つ目だけでも効果が大きい。**
