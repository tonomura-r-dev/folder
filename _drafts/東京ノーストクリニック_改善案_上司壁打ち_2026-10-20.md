# 東京ノーストクリニック｜LINE配信の改善案（2026-10-20・殿村さんが上司に壁打ちする用のテキスト）

前提＝10月3本目（10/26）から「Lステップに流す」形で配信する。阿久津執行役員部長の3件のうち、セグメント・エリア／時間帯／GAでのCV改善の2件目・3件目をまとめた。
（1件目＝離脱ポップアップ経由の訴求は、ポップアップから入った人の流入経路が取れてから）

```
■ 東京ノーストクリニック LINE配信の改善案（10/26以降）

【現状】
・配信はOAM（LINE公式の管理画面）から男性全員 約6,800人に一斉送信。
　開封 19〜24%、予約フォームまで来る人は1本40〜50人（開いた人の約3%）。
・Lステップは連携済みだが、認識している有効友だちは94人。
　既存の友だちは「何か動いた人」しか入らない。
・予約の実数はGA（配信ごとに印を付けたURL）で見る。10/26から配信ごとに揃える。

【10/26からの基本形：配信でLステップに入れる】
・配信の画像をタップ → 本人から「予約フォームを送ってください」の一言が送られる
　→ この時点でLステップに入る → 自動応答で予約フォームのバナーを返し、タグ「予約希望」を付ける。
・毎回40〜50人（＝予約に一番近い人）がLステップにたまる。
・Lステップ側の設定は自動応答1つ。OAM側は画像のタップ動作を1か所変えるだけ。

【1. セグメント（誰に送るか）】
OAM側（約6,800人・今すぐできる）
・月3本のうち1本は全員、2本は「開いた人」に絞る。
　同じ人に続けて送るほどブロックが増えるため（9/16 +273 → 10/9 約+90）。
Lステップ側（たまった人・11月から）
・予約希望（自動）：翌日に一押しを1通。月末に「ご予約はお済みですか」を1通。
・予約済／来院済（手で付ける）：配信から外す。
　→ テキスト冒頭の「※すでにご来院・ご相談いただいた方は…」が不要になり、
　　通知に出る1行目を訴求の一文に使える（今は3本とも同じ注意書きが通知に出ている）。
・アドアフィの新規（流入経路）：追加直後のシナリオは既存の計測の仕組みに合わせる。

【2. エリア（どこの人に送るか）】
・OAMの属性フィルター（居住地・都道府県）で、院のあるエリアごとに「近くの院名」を出す配信を1本試す。
　全国36院（東京5・関東6・甲信越2・東海北陸6・近畿6・北海道東北2・中国四国九州6）。
・まず関東（1都6県）と近畿（大阪・京都・奈良・兵庫・三重）の2本。中身は同じで院名だけ変える。
　それ以外の地域には全国版。各エリアの人数は属性フィルターの画面で確認（50人以上が条件）。
・Lステップでエリア分けをするには回答フォームで都道府県を聞く必要があるので、後回し。

【3. 時間帯】
・これまでは3本とも21時台（開封 23.8→19.4→18.8%、押す率 2.9→2.9→3.5%）。時間の差はまだ測れていない。
・11月から月3本で時間を変えて比べる：21時（基準）／昼12時（昼休み）／23時台（競合が21〜22時に集中するので、その後にトーク一覧の上に来る）。
・配信先と画像の型を揃え、「開いた率」「押した率」「予約数」で比べる。2か月（6本）で決める。
・11月の3連休の回は、金曜夜ではなく土曜朝も候補。

【4. GAで見る数字と、CVの改善】
・配信ごとに「届いた → 開いた → 押した → 予約」の4段を表にする（GAの画面：トラフィック獲得 → セッションのキャンペーン → 配信の印で検索）。
　予約完了のイベント名は最初に確定させる（別案件で名前と実態がずれていた）。
・効率の指標：予約1件あたりの配信通数／ブロック1人あたりの予約数。
・今の逆算：6,800 × 開封19% ≒ 1,300 → 押す3.3% ≒ 43人 → 予約率2%で約1件/本 → 月3本で約3件。
・改善の順番：
　① 開いてもらう所（通知に出る1行目）。Lステップで予約済を外せれば、注意書きをやめて訴求に変えられる。
　② フォームの先（9/24は29人がフォームまで来て予約0）。フォームの項目数・表示を確認する。
　③ 押す率は3%前後で安定しているので、画像の型は固定し、訴求の言葉だけ変える。

【必要なもの】
・Lステップの自動応答の設定（10/26まで）とスマホでのテスト。
・OAMの属性フィルターでの都道府県別の人数。
・GAの予約完了イベント名の確定。
```
