# AI調査プロンプト（画一FMT）

Gemini・ChatGPT・Perplexityのどれに投げても、**同じ形（表）・出典URLつき**で返ってくるようにするプロンプト。
【 】の部分だけ案件ごとに書き換えて貼る。

## 出力の決まり（全プロンプト共通）
- 出力は**表のみ**（前置き・まとめ・感想なし）。列は固定。
- すべての数字に**開いて確認した出典URL**を付ける。確認できないものは書かせない（「確認できず」）。
- 出典の優先順：公的統計・官公庁 → 業界団体・調査会社 → 企業の公式サイト → その他。ブログ・まとめ記事・孫引きは出典にしない。
- 数字は原文どおり（丸めない）。調査の時期・対象・人数も書かせる。
- 食い違うときは両方並べ、公的統計に★。

## A. 市場調査プロンプト

```
あなたは市場調査の担当です。以下の案件について、指定の形式だけで回答してください。

【案件】
・クライアント：【会社名】（【サービス名・URL】）
・業界・職種：【例：自動車整備士の求人】
・提案の目的：【例：LINEで会員登録・応募を増やす】

【調べる項目】（この順番で、項目を増やさない）
A. 需給・市場規模（求人倍率、人手不足の割合、担い手の推移）
B. 求職者・ユーザーの行動（利用する経路、探す時期、決め手）
C. 企業側（クライアント側）の課題
D. 競合サービスの数と規模
E. 【追加で調べたい項目があれば書く。なければこの行を削除】

【回答ルール】（必ず守る）
1. すべての数字に、開いて確認した出典URLを付ける。URLを開いて確認できなかったものは書かない。
2. 出典は「公的統計・官公庁 → 業界団体・調査会社 → 企業の公式サイト → その他」の順で優先する。ブログ・まとめ記事・孫引きは出典にしない。
3. 数字は原文どおりに書く（丸めない・言い換えない）。調査の時期・対象・人数も書く。
4. 推測・一般論・「〜と言われている」は書かない。
5. 数字が出典ごとに食い違うときは、両方を並べる（公的統計に「★」を付ける）。
6. 確認できなかった項目は、表に「確認できず」とだけ書く。

【出力形式】（表のみ。前置き・まとめ・感想は書かない）
| 区分(A〜E) | 項目 | 内容（数字は原文どおり） | 調査の時期・対象 | 出典URL | 出典の種類 |

【最後に】
「確認できなかった項目」を、箇条書きで1つにまとめる。
```

## B. 競合サービス調査プロンプト

```
あなたは競合調査の担当です。以下について、指定の形式だけで回答してください。

【調べる対象】
・業界・職種：【例：自動車整備士の求人サービス】
・調べる競合：【社名を列挙。指定がなければ「知名度の高い順に大手3社と、特化型3社」】

【調べる項目】（この順番で、項目を増やさない）
1. 公式サイトのURL
2. 種別（総合／特化）
3. 掲載件数・登録者数など、公式サイトに載っている規模の数字
4. LINE公式アカウントの案内が公式サイトにあるか（あれば案内ページのURL。無ければ「案内なし」）
5. 特徴（公式サイトに書かれている言葉で1行）

【回答ルール】（必ず守る）
1. すべての情報に、開いて確認したURLを付ける。開いて確認できなかった項目は「確認できず」と書く。
2. 数字は原文どおり。確認日を書く。
3. 推測・口コミ・まとめ記事の情報は書かない。公式サイトと公的な情報だけを使う。

【出力形式】（表のみ。前置き・まとめ・感想は書かない）
| 競合名 | 種別 | 公式サイトURL | 規模の数字（原文どおり） | LINEの案内（有無とURL） | 特徴 | 確認日 |

【最後に】
「確認できなかった項目」を、箇条書きで1つにまとめる。
```

## 戻ってきた出力のチェック（Claudeがやる）
1. 出典URLが無い行 → 資料に使わない（削除）
2. 出典の種類がブログ・まとめ・孫引き → 使わない
3. 数字が食い違う → 公的統計（★）を採用。両方を出すのは社内メモまで
4. 「確認できず」の項目 → 追加プロンプトで、その項目だけ狭く聞き直す
5. 通過した行だけを `_drafts/<案件名>_商材・市場調査（日付）.md` の表に転記（出典URL・確認日つき）
