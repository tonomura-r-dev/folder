# FMTの正しい使い方（2026-09-16・殿村さん指摘を受けて全面改訂）

> **⚠️ `DYM_LINEOA_FMT.pptx` を単体で使ってはいけない。**

## 正しい2本立て

| ファイル | 役割 | 使い方 |
|---|---|---|
| **`DYM_LINEOA_BUFFF_ver3.pptx`**（62枚） | **LINEOAの前提＝共通パーツの在庫** | 業界に関係なく使い回すページはここから取る。**中身を書き換えない** |
| **`ジム・フィットネス業界_LINEOA施策提案_ver3.pptx`**（46枚） | **業界資料の流れ・構成の完成見本** | **並べ方（章立て・順番・枚数）はこれに合わせる** |
| `DYM_LINEOA_FMT.pptx`（36枚） | ⚠️ **旧**。中身は人材（転職）業界の提案書 | **単体では使わない。** 参照するなら業界分析パートだけ |
| `DYM_LINEOA_33p_base.pptx` | 旧ベース | 同上 |

**考え方：BUFFF＝部品箱／ジム＝組み立て説明書。**
業界資料は「BUFFFの共通パーツ」＋「その業界の実測データ」を、ジムの順番で並べたもの。

## ⚠️ BUFFFの数値の扱い（ジム ver3 は既に直している）

| BUFFFの表記 | 問題 | ジム ver3 での直し方 |
|---|---|---|
| p15「**業態平均で最大3%**のユーザーは有効化/マネタイズ可能 **とされている**」 | 出典なし。受け身の「とされている」で逃げている | → 「LINE誘導から**1.5〜3%程度**が有効化/マネタイズ可能（**社内想定の目安**）」と**ラベルを付けて言い直している** |
| p7「開封率60%／**メルマガの6倍**」 | **LINEヤフー公式値ではない**。公式は「受信直後 約2割・3〜6時間で約5割・**当日中に約8割が開封**」 | ジム ver3 では**この比較ページ自体を落としている** |
| p8「今すぐ客1-2%／…／お悩み客80%」 | 一般に流通するモデルで出典なし | 同上（ジム ver3 には無い） |

**→ 注文住宅の公表判断チェックリストで赤になった「業態平均で最大3%」は、BUFFF p15 が出元。**
**BUFFFをそのまま貼ると赤が生える。ジム ver3 の言い換え（社内想定の目安）を採用すること。**

## 今後のルール

1. **新しい業界資料は、ジム ver3 をコピーして作る。** FMTからは作らない
2. BUFFFのページを持ち出すときは、**上の表の3つだけラベルを直す**
3. **【業界】ページ15枚が実作業。** 残り31枚はBUFFFからの持ち出しと章扉
4. **章扉を必ず入れる**（5章）。これが無いと商談で「いま何の話か」が迷子になる
5. **奥付を必ず入れる**
6. 原本（BUFFF・ジム ver3）は**絶対に編集しない**。必ずコピーして作業
