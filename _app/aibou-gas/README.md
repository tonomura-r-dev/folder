# 殿村の相棒（ログイン不要版）— 私用PCでの立ち上げ手順

claude.ai を開かず、URL だけで使えるチャット。記憶は持たない。
頭脳は Gemini API の無料枠（Google AI Studio で発行。カード不要）。
置き場は Google Apps Script（GAS）。サーバー不要。

## 手順（私用の Google アカウントで・10分）

1. **APIキーを取る**
   https://aistudio.google.com/apikey → 「APIキーを作成」→ 出てきたキーをコピー。
2. **GASプロジェクトを作る**
   https://script.google.com → 「新しいプロジェクト」。
   - 既定の `コード.gs` の中身を消して、`Code.gs` の中身を貼る。
   - 左の「＋」→「HTML」→ 名前を `index` にして、`index.html` の中身を貼る。
3. **キーを入れる**（コードには書かない）
   左の歯車「プロジェクトの設定」→ 下の「スクリプト プロパティ」→「プロパティを追加」
   - `GEMINI_API_KEY` ＝ 1で取ったキー
   - `PASSCODE` ＝ 好きな合言葉（任意。URLが漏れたときの保険。入れておくのを推奨）
4. **公開する**
   右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   → 「デプロイ」。初回は許可画面が出るので許可する。出てきた `…/exec` のURLが相棒。
5. **スマホに置く**
   そのURLをスマホで開き、「ホーム画面に追加」。以後ログインなしで開ける。

疎通確認だけしたいときは、エディタで関数 `test_` を選んで「実行」。実行ログに返事が出る。

## メモ帳シート（2026-09-04 追加・立ち上げ済み後にやったこと）

1. `Code.gs` をシート対応版に差し替え（Ctrl+A → 貼り付け → Ctrl+S）。
2. エディタ上部の関数選択で `setup` を選び「実行」。初回は許可画面（Advanced → Go to → Allow）。
   → Drive に「殿村の相棒メモ」というスプレッドシートができ、実行ログにURLが出る。
3. 「デプロイ」→「デプロイを管理」→ 鉛筆 → 「新バージョン」→「デプロイ」（URLは変わらない）。

以後は**シートを直せば次の返事から効く**（デプロイし直し不要）：
- 「設定」シート：B1=殿村さんについて／B2=返答ルール／B3=案件地図
- 「メモ」シート：B列に1行1件。チャットで「覚えて ○○」と送っても自動で追記される。

## 直し方

- 人格・案件地図：上記「設定」シートのB列を直す。コードは触らない。
- コードを変えたとき：「デプロイ」→「デプロイを管理」→ 鉛筆 → 「新バージョン」→「デプロイ」。
- モデルを変えたいときはスクリプト プロパティに `MODEL` を足す（既定 `gemini-3.6-flash`）。

## 注意

- 「アクセスできるユーザー：全員」なので、URLを知っていれば誰でも話せる。
  案件名が入っているので、**PASSCODE を入れる**か、URLを人に渡さない。
- 会話ログは残らない（タブを閉じると消える）。残したいことは「メモ」シートか「覚えて ○○」。
  Claude Code 側の記憶（CLAUDE.md／INDEX）とは自動同期しないので、大事な決定は両方に書く。
- 無料枠には1日の回数上限がある。超えると「使いすぎです」と出る。翌日に戻る。
- このコードはクラウド環境から Gemini API に接続できなかったため、**実機で未検証**。
  動かなかったらエラー文をそのまま Claude Code に貼れば直せる。
