# 殿村の相棒（オレ専用AI・Webチャット）

- **URL**：https://claude.ai/code/artifact/d3cfa346-20e4-48f8-b445-be22dcd441b1
  - スマホもPCも同じURL。claude.ai にログインして開く（非公開・本人のみ）。
  - 初回は「このページがClaudeを使うのを許可しますか」と出るので **許可** を押す。
- **中身**：`index.html` 1枚。サーバー・APIキー不要（claude.ai の Artifact 機能で動く）。
  - AIの呼び出し＝ `sample` 機能（殿村さんのClaude利用枠を使う）
  - 記憶＝ `db` 機能（会話ログ・記憶メモ・設定を端末間で共有）

## 入っているもの

| 場所 | 中身 | 変え方 |
|---|---|---|
| 設定 → プロフィール・ルール | 殿村さんについて／返答ルール（CLAUDE.md の要約） | 画面で編集して保存 |
| 設定 → 案件地図 | `_memory/INDEX.md` の要約 | 案件が動いたら画面で直す |
| 設定 → 記憶 | チャットで「覚えて」と言うと相棒が追記。手動追加・削除も可 | 画面で |
| 頭の使い方 | 速く／普通／じっくり（モデルの段階） | 画面下のトグル |

## できること・できないこと

- できる：案件の状況を踏まえた相談、文面作成、Gemini/ChatGPT向けプロンプト作成、Claude Code向け指示文の作成、記憶。
- できない：ファイル生成（PPTX/Excel）、Web閲覧、リポジトリの読み書き。→ 指示文を作らせて Claude Code に貼る。

## 更新のしかた

1. `index.html` を直す（既定の人格は `DEFAULT_PROFILE` / `DEFAULT_RULES` / `DEFAULT_CASES`）。
2. Claude Code で「`_app/aibou/index.html` を同じURLに再公開して」と頼む
   （Artifact の `url` に上のURLを渡すと同じリンクのまま更新される）。
3. 画面で保存した設定・記憶は db 側にあるので、再公開しても消えない。

## 制限

- 1回に送れる文脈は 64KiB。履歴は直近 約14,000文字ぶんだけ送る（古い分は自動で落とす）。
- 会話ログはチャットごとに1ドキュメント（最大200発言で古い方から削る）。
