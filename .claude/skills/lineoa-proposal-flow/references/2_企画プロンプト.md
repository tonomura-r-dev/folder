# AI企画プロンプト（セグメント・企画）（画一FMT・業界を問わず使える版）

友だち追加の動線・調査の結果・前後検索・期間を入れると、**施策ビジュアル①〜④のFMTに載せる形**で企画案が返ってくるプロンプト。
【 】の部分だけ案件ごとに書き換えて貼る。人数・件数・費用は AI に書かせない（SIM から Claude が入れる）。
業界を問わず使える（2026-10-09 汎用版。3つの観点のチェックを反映済み）。

```
あなたはLINE公式アカウントの運用設計の担当です。以下の案件について、指定の形式だけで回答してください。
【例：…】のまま残っている行は、書かれていないものとして扱ってください（例の中身は使わない）。

【案件】
・クライアント：【会社名】（【サービス名・URL】）
・業界・商材：【例：賃貸仲介／自動車整備士の求人サイト／歯科のインプラント治療／化粧品の通販】
・お客様（LINEで友だちになってほしい方）：【例：都内で部屋を探している女性の会社員】
・提案の目的：【例：LINEで問い合わせ・予約・応募・購入を増やす】
・LINE上でのゴール（CV）：【例：CV①＝友だち追加の直後にLINEで問い合わせ／CV②＝配信から申し込み】

【友だち追加の動線】（この動線ごとに考える。使わない動線の行は削除し、残した動線は00から番号を振り直す）
・動線00：【例：離脱防止ポップアップ（サイトから離れようとした方）】

【ここに貼る】

【前後検索の分析結果】（検索の前・当日・後の関心の順番。無ければ「なし」）
【ここに貼る】

【期間とピーク】
・期間：【例：11月開始・翌4月まで（6か月）】
・ピーク：【例：需要のピークは◯月、最も少ないのは◯月。分からなければ「不明」】

【条件】
・企画配信は月【4本】。表3は期間の【6か月分】を書く。

・LINE公式アカウントの標準機能（あいさつ・ステップ配信・企画配信・リッチメニュー・クリックの履歴で分けるオーディエンス・自動応答・チャット・クーポン・ショップカード・リサーチ）で実現できるものだけを書く。外部ツールやAPI連携が要るものは、項目の末尾に「（別ツール）」と付ける。
・あいさつメッセージは全員共通。流入元別の出し分けはできない前提で書く。
・リッチメニューは全員共通の1つ（同時に出せるのは1つだけ）。
・【使わないもの：例：通知メッセージ】は書かない。
・人数・件数・金額・開封率などの数字は書かない。数字の欄は「SIMで入力」とだけ書く。
・根拠のない一般論や、他社の数字は書かない。
・今の友だち数・CV数・広告の実績など、先方の内部の数字は「先方に確認が要る点」に入れない（数字はSIMで仮置きする）。

（前後検索が「なし」のときは、最後の列は「―」と書き、関心を想像で作らない）

| 動線 | QA自動化 | 個別チャット | その他 |

【最後に】
「決められなかった点・先方に確認が要る点」を、箇条書きで1つにまとめる。
```

## 埋め方のコツ（Claudeが【 】を埋めるとき）
- 動線は与件で決まったものだけ残し、00から番号を振り直す（例：あらうち＝00 友だち追加広告／01 サイト内のLINE問い合わせ）。番号はSIMのプロンプトと同じにする
- LINE上でのゴール（CV）は、SIM・資料と同じ定義を書く
- 調査の結果は、①の検品で通した行だけを貼る（出典URLつき）
- 前後検索・ピークが無い案件は「なし」「不明」と書く（空欄のまま貼らない）。同じ業界の分析がリポジトリにあれば使ってよい（例：賃貸＝`_drafts/賃貸業界_調査結果.md` §8）

## 戻ってきた出力のチェック（Claudeがやる）
1. 数字（人数・件数・金額・率）が書かれていたら削除して「SIMで入力」に戻す
2. 「（別ツール）」の項目は、先方が使う前提かを確認してから資料に載せる
3. 完了画面から入った方に、済ませた申し込みをもう一度勧める案内が入っていたら削除
4. 景品表示法・業界のルール（医療広告ガイドライン・薬機法など）に触れる企画が無いか確かめる
5. 表1〜6を、施策ビジュアルFMT（①〜④の4枚）に転記する（表1→①、表2〜4→②、表5→③、表6→④）。②の人数・件数はSIMから入れる。**FMTに残っている求人の言葉（求人ページ・応募率・応募の完了画面・面談など）は、この案件のCVの言葉（問い合わせ率・予約・購入など）に置き換える**
