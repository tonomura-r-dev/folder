# AI投稿案プロンプト（あいさつ・ステップ・企画投稿・リッチメニュー）（画一FMT・業界を問わず使える版）

「セグメント・企画」のプロンプトの結果（動線・企画）を入れると、**配信する文面**が固定の表で返ってくるプロンプト。
【 】の部分だけ案件ごとに書き換えて貼る。
業界を問わず使える（2026-10-09 汎用版。3つの観点のチェックを反映済み）。
量が多いので、1回で書ききれないときは「続き」と送ると、止めた表の続きから出てくる。

```
あなたはLINE公式アカウントの配信文面（CR）の担当です。以下の案件について、指定の形式だけで回答してください。
【例：…】のまま残っている行は、書かれていないものとして扱ってください（例の中身は使わない）。

【案件】
・クライアント：【会社名】（【サービス名・URL】）
・業界・商材：【例：賃貸仲介／自動車整備士の求人サイト／歯科のインプラント治療／化粧品の通販】
・読み手（お客様）：【例：都内で部屋を探している女性の会社員／転職を考えている整備士の方】
・LINE上でのゴール（CV）：【例：CV①＝友だち追加の直後にLINEで問い合わせ／CV②＝配信から申し込み（企画・SIMと同じ定義を書く）】

【先方の中身の情報】（文面に書いてよい事実は、ここにあるものだけ）

【企画案】（前のプロンプトの表1・表2・表3・表4を貼る）

【ブランドの色・トーン・過去の配信】
【例：色は紺とオレンジ／丁寧で押し売りしない／過去の配信文があれば貼る】

【条件】
```

## 埋め方のコツ（Claudeが【 】を埋めるとき）
- 先方の中身の情報は、サイトや与件にある事実だけを貼る（料金・条件・申し込みの流れ）。ここに無いことはAIに書かせない
- 業界のルールの行は消さない（景品表示法はどの業界にもかかる）。業界のルールが無ければ【 】を「なし」にする。規制が強い業界＝医療・美容・健康食品・化粧品・不動産・金融・求人・通販

## 戻ってきた出力のチェック（Claudeがやる）
1. 【要確認】以外で、先方の中身の情報に無い数字・条件・実績があれば削除
2. 「最大」「No.1」「業界初」などは根拠を確認。無ければ外す。医療・化粧品は根拠があっても外す
3. 完了画面から入った方に、済ませた申し込みをもう一度勧める文面が入っていたら削除
4. 景品表示法・業界のルール（医療広告ガイドライン・薬機法など）に触れる表現が無いか確かめる
5. 吹き出しの文字数・通知の冒頭15字を数える
6. **表5は、画像生成用プロンプト（背景・構図・商品だけ。日本語の文字は画像生成AIに描かせない）と、後から載せる文字（一字一句）に分けて殿村さんに渡す。** 文字はCanva等で後から載せる。画像はClaudeが作らない
7. 通過した文面を `_drafts/<案件名>_配信文面（日付）.md` に転記
