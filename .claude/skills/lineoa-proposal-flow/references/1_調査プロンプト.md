# AI調査プロンプト（画一FMT・業界を問わず使える版）

Gemini・ChatGPT・Perplexityのどれに投げても、**同じ形（1つの表）・出典URLつき**で返ってくるプロンプト。
市場調査と競合調査は**1本にまとめてある**。【 】の部分だけ案件ごとに書き換えて貼る。
求人・不動産・医療・EC・スクールなど、**業界を問わず同じ形で使える**（2026-10-09 汎用版。3つの観点のチェックを反映済み）。
**ウェブ検索が使えるAIに貼る**（検索が切れていると、出典を作り話で埋めることがある）。

## 出力の決まり
- 出力は**表1つと、最後の箇条書きだけ**（前置き・感想なし）。列は固定。
- すべての数字に**開いて確認した出典URL**を付ける。確認できないものは書かせない（「確認できず」）。
- 出典の優先順：公的統計・官公庁 → 業界団体・調査会社 → 企業の公式サイト → その他。ブログ・まとめ記事・孫引きは出典にしない。
- 数字は原文どおり（丸めない）。調査の時期・対象・人数も書かせる。
- 食い違うときは両方並べ、公的統計に★。

## プロンプト

```
あなたは市場・競合調査の担当です。以下の案件について、指定の形式だけで回答してください。
【例：…】のまま残っている行は、書かれていないものとして扱ってください（例の中身は使わない）。

【案件】
・クライアント：【会社名】（【サービス名・URL】）
・業界・商材：【例：賃貸仲介／自動車整備士の求人サイト／歯科のインプラント治療／化粧品の通販】
・お客様（LINEで友だちになってほしい方。Bで調べる対象）：【例：都内で部屋を探している女性の会社員／転職を考えている整備士の方（求人を出す企業ではなく、求職者の方）】
・地域：【例：東京都内／大阪市／全国】
・提案の目的：【例：LINEで問い合わせ・予約・応募・購入を増やす】
・調べる競合：【社名を列挙。指定がなければ「知名度の高い大手3社と、特化型3社」。店舗・医院のように地域で選ばれる商売は「（地域）の同業3社と、全国の大手3社」】

【調べる項目】（この順番で、項目を増やさない）
A. 市場の大きさと動き（市場規模、利用者数・件数の推移、需要と供給のバランス。この業界でよく使われる指標で書く。地域の数字があれば地域も）
B. お客様の行動（探し始めるきっかけと時期、使う経路（検索・SNS・比較サイト・紹介など）、比べるときの決め手、申し込みをためらう理由）
C. この業界の企業側の課題（集客、申し込みから成約・来店までの離脱、継続・リピート、人手など）
D. 競合（競合ごとに1行：規模の数字、公式サイトにLINE公式アカウントの案内があるか（あれば案内ページのURL。見つからなければ「見つからず」と書き、「なし」とは書かない）、特徴）
E. 同じ業界・近い業界のLINE公式アカウントの活用事例（LINEヤフー公式の導入事例など、数字が出ているもの）
F. 広告・表示のルール：景品表示法（「最大」「No.1」・割引・特典の書き方）と、この業界のルール【例：医療広告ガイドライン、薬機法、宅建業法・不動産の表示に関する公正競争規約、職業安定法（求人の表示）、特定商取引法（通販・定期購入の表示）。無ければ「なし」】
G. この案件だけで追加で調べたい項目：【例：整備士の年収の相場。無ければ「なし」】

【回答ルール】（必ず守る）
1. すべての数字・情報に、開いて確認した出典URLを付ける。URLを開いて確認できなかったものは書かない。ウェブ検索が使えないときは、記憶で表を作らず「ウェブ検索が使えません」とだけ答える。
2. 出典は「公的統計・官公庁 → 業界団体・調査会社 → 企業の公式サイト → その他」の順で優先する。ブログ・まとめ記事・孫引きは出典にしない。
3. 数字は原文どおりに書く（丸めない・言い換えない）。調査の時期・対象・人数も書く。
4. 推測・一般論・「〜と言われている」・口コミは書かない。
5. 数字が出典ごとに食い違うときは、両方を並べる（公的統計に「★」を付ける）。
6. 確認できなかった項目は、表に「確認できず」とだけ書く。

【出力形式】（表1つと、最後の箇条書きだけ。前置き・感想は書かない。表は省略しない）
| 区分(A〜G) | 項目（Dは競合名、Eは事例の会社名） | 内容（数字は原文どおり） | 調査の時期・対象 | 出典URL | 出典の種類（公的統計／業界団体・調査会社／企業の公式サイト／その他） |

【最後に】
「確認できなかった項目」を、箇条書きで1つにまとめる。
```

## 埋め方のコツ（Claudeが【 】を埋めるとき）
- 業界・商材は「何を売っているか」まで書く（「不動産」だけでなく「賃貸仲介」）。**求人は職種まで書く**（「求人サイト」だけでなく「自動車整備士の求人サイト」）。Aで使う指標が変わる（求人＝その職種の求人倍率、賃貸＝転居者数・空室率、医療＝患者数 など）
- **お客様の行は消さない。** 求人サイト・ライバー事務所のように、お金を払う側（求人を出す企業）とLINEで友だちになる方（求職者・ライバー志望の方）が違う業界では、友だちになる方を書く
- 地域で選ばれる商売（店舗・医院・賃貸仲介など）は、地域の同業も競合に入れる
- Fは消さない（景品表示法はどの業界にもかかる）。業界のルールが無ければ【 】を「なし」にする。規制が強い業界＝医療・美容・健康食品・化粧品・不動産・金融・求人・通販

## 戻ってきた出力のチェック（Claudeがやる）
1. 出典URLが無い行 → 資料に使わない（削除）
2. 出典の種類がブログ・まとめ・孫引き → 使わない
3. **URLを自分で開いて、数字が原文どおり載っているか確かめる**（AIが言い換えていることがある。GPTの `utm_source=chatgpt.com` は外してから開く）
4. 競合のLINEが「見つからず」→ 公式サイトを自分で開いて確かめる（「やっていない＝先に始められる」の根拠に使うので、間違いが許されない）
5. 数字が食い違う → 公的統計（★）を採用。両方を出すのは社内メモまで
6. 「確認できず」の項目 → 追加プロンプトで、その項目だけ狭く聞き直す
7. 通過した行だけを `_drafts/<案件名>_商材・市場調査（日付）.md` の表に転記（出典URL・確認日つき）
