# AI調査プロンプト（画一FMT・業界を問わず使える版）

Gemini・ChatGPT・Perplexityのどれに投げても、**同じ形（1つの表）・出典URLつき**で返ってくるプロンプト。
市場調査と競合調査は**1本にまとめてある**。【 】の部分だけ案件ごとに書き換えて貼る。
求人・不動産・医療・EC・スクールなど、**業界を問わず同じ形で使える**（2026-10-09 汎用版に直した。旧版は求人向けの言葉だった）。

## 出力の決まり
- 出力は**表1つだけ**（前置き・まとめ・感想なし）。列は固定。
- すべての数字に**開いて確認した出典URL**を付ける。確認できないものは書かせない（「確認できず」）。
- 出典の優先順：公的統計・官公庁 → 業界団体・調査会社 → 企業の公式サイト → その他。ブログ・まとめ記事・孫引きは出典にしない。
- 数字は原文どおり（丸めない）。調査の時期・対象・人数も書かせる。
- 食い違うときは両方並べ、公的統計に★。

## プロンプト

```
あなたは市場・競合調査の担当です。以下の案件について、指定の形式だけで回答してください。

【案件】
・クライアント：【会社名】（【サービス名・URL】）
・業界・商材：【例：賃貸仲介／求人サイト／歯科のインプラント治療／化粧品の通販】
・お客様（調べる対象）：【例：都内で部屋を探している方／転職を考えている整備士の方。特に無ければこの行を削除】
・提案の目的：【例：LINEで問い合わせ・予約・応募・購入を増やす】
・調べる競合：【社名を列挙。指定がなければ「知名度の高い大手3社と、特化型3社」】

【調べる項目】（この順番で、項目を増やさない）
A. 市場の大きさと動き（市場規模、利用者数・件数の推移、需要と供給のバランス。数字は、この業界でよく使われる指標で書く）
B. お客様の行動（探し始めるきっかけと時期、使う経路（検索・SNS・比較サイト・紹介など）、比べるときの決め手、申し込みをためらう理由）
C. この業界の企業側の課題（集客、申し込みから成約・来店までの離脱、継続・リピート、人手など）
D. 競合（競合ごとに1行：規模の数字、公式サイトにLINE公式アカウントの案内があるか（あれば案内ページのURL）、特徴）
E. 同じ業界・近い業界のLINE公式アカウントの活用事例（LINEヤフー公式の導入事例など、数字が出ているもの）
F. 【この業界の広告・表示のルール（例：医療広告ガイドライン、薬機法、景品表示法、宅建業法の広告の規制）。関係なければこの行を削除】

【回答ルール】（必ず守る）
1. すべての数字・情報に、開いて確認した出典URLを付ける。URLを開いて確認できなかったものは書かない。
2. 出典は「公的統計・官公庁 → 業界団体・調査会社 → 企業の公式サイト → その他」の順で優先する。ブログ・まとめ記事・孫引きは出典にしない。
3. 数字は原文どおりに書く（丸めない・言い換えない）。調査の時期・対象・人数も書く。
4. 推測・一般論・「〜と言われている」・口コミは書かない。
5. 数字が出典ごとに食い違うときは、両方を並べる（公的統計に「★」を付ける）。
6. 確認できなかった項目は、表に「確認できず」とだけ書く。

【出力形式】（表1つだけ。前置き・まとめ・感想は書かない）
| 区分(A〜F) | 項目（Dは競合名） | 内容（数字は原文どおり） | 調査の時期・対象 | 出典URL | 出典の種類 |

【最後に】
「確認できなかった項目」を、箇条書きで1つにまとめる。
```

## 埋め方のコツ（Claudeが【 】を埋めるとき）
- 業界・商材は「何を売っているか」まで書く（「不動産」だけでなく「賃貸仲介」）。Aで使う指標が変わる（求人＝求人倍率、賃貸＝転居者数・空室率、医療＝患者数 など）
- お客様は与件のターゲットをそのまま書く（地域・性別・年代・職業）。Bの調査がその人たちに寄る
- 競合は与件の指定どおり。指定がなければ既定の文のまま
- Fは規制がかかる業界（医療・美容・健康食品・化粧品・不動産・金融など）だけ残す

## 戻ってきた出力のチェック（Claudeがやる）
1. 出典URLが無い行 → 資料に使わない（削除）
2. 出典の種類がブログ・まとめ・孫引き → 使わない
3. **URLを自分で開いて、数字が原文どおり載っているか確かめる**（AIが言い換えていることがある）
4. 数字が食い違う → 公的統計（★）を採用。両方を出すのは社内メモまで
5. 「確認できず」の項目 → 追加プロンプトで、その項目だけ狭く聞き直す
6. 通過した行だけを `_drafts/<案件名>_商材・市場調査（日付）.md` の表に転記（出典URL・確認日つき）
