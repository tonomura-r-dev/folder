## STEP1 事例を探す

1. Google検索：`site:lycbiz.com/jp/case-study （業界関連KWを5〜8個 OR でつなぐ）`
   ブラウザで開き、JSで `a[href]` から `host==='www.lycbiz.com' && /case-study/` のURLとh3を抽出
2. 候補ページを requests で取得 → タグ除去 → **本文は `ホーム 事例` 以降**を読む
   （冒頭に「目的／施策／効果」が箇条書きで揃っている＝数値の宝庫）
3. 選定は自分で決めてよい（確認不要）
   - **数値が明記されている事例を最優先**（友だち追加率・開封率・CVR・増加倍率など）
   - 大手1〜2 ＋ 中堅・自治体・スタートアップ1〜2 で**規模を散らす**
   - 活用サービスを散らす（LINE公式アカウント／LINEミニアプリ／LINE通知メッセージ／LINE API）
   - 数値のない事例は原則不採用（採るなら「機能面の参考」と位置づけを明記）
4. **該当業界が2本未満なら、隣接業界（購買構造が近い業界）で補い、その旨を明記**
   ※ ブライダル（式場）のように**公式事例がほぼ存在しない業界がある**。無理に埋めず正直に書く

## STEP2 実画面キャプチャを取得（★品質の分かれ目）

1. 各事例ページのHTMLから `<img ... src="...">` を全部拾い、**`/case-study/` を含むものだけ**残す
   （`https://www.lycbiz.com` + 相対パス。`.webp` が多いので PIL で PNG 変換）
2. requests は稀に `SSLEOFError` → **Sessionで3〜4回リトライ**
3. 落とした画像を**コンタクトシートにして必ず目視**し仕分ける
   - 採用：スマホ画面（リッチメニュー／トーク／通知メッセージ／配信クリエイティブ）、成果グラフ
   - 不採用：**インタビュイーの人物写真**、企業ロゴ、共通アイコン
4. **複数画面が1枚に連結された画像は分割する**
   - 横並び：パネル境界でクロップ（等分割で端が混ざるときは内側に2〜10px寄せる）
   - 縦：トーク部分とリッチメニュー部分を上下で切る
5. **どれがリッチメニューでどれが投稿かは必ず画像を見て判断**（左右・順序の思い込みは外れる）
6. 公式ページに画面キャプチャが無い事例のみモックアップを描画
   （ベゼル `#2B2B2B`／画面 `#EFF2F7`／ヘッダー `#06C755`／吹き出し in・out・chips・btn・img、文字6.5pt）
   → **「※公開情報をもとに作成した配信イメージ（実画面ではありません）」と明記**

## STEP3 構成（見本＝旅行観光版）

1. **表紙**：「{業界名} LINE活用 導入事例集」／サブ「LINEヤフー公式 導入事例より　○○の4事例」
2. **サマリー**：事例カードを2×2（企業名＋領域／活用サービス／施策3行／成果KPIをオレンジ大文字）
3. **事例ごとに1枚**
   - 左（x=1.0〜13.4）：「課題と施策」カード（■課題／■施策）＋「効果」帯＋KPIタイル3つ（大数字＋説明2行）
   - 右（x=14.0〜26.6）：小見出し「実際のLINE画面」＋**ネイビーのラベルバー**で区切って画像を配置
     - 「リッチメニュー」／「配信・投稿」の2ブロックが基本
     - 画面が3種あるときは3ブロック（例：配信（投稿）／リッチメニュー／ミニアプリ画面）
     - 画像はアスペクト比維持でフィット（`ratio = min(max_w/iw, max_h/ih)`）、各ブロック中央寄せ
     - 画像の下に、その事例のリッチメニュー構成や配信内容を1〜3行で補足
   - 下：出典（事例タイトル・企業名・公開日）＋「※画面は公式導入事例ページ掲載のキャプチャ」
4. **まとめ**：「{業界名}でのLINE活用の型」を4ブロックで言語化。各ブロックに事例の数値を根拠として引用
5. **裏表紙**（DYM固定）

## STEP4 制作手順

1. 最新のDYM様式デッキをコピー → python-pptxで `表紙／コンテンツ骨格1枚／裏表紙` だけ残す
   （`prs.part.drop_rel(sldId.rId)` ＋ `sldIdLst.remove()`。zip内の実partnameは `zipfile.namelist()` で確認）
2. `add_slide.py <deck> slideN.xml --after slideN.xml -o <deck>` で骨格を必要枚数ぶん複製
3. python-pptxで描画（clear_body → 見出し → 左カラム → 右カラムに画像）
4. 画像を後から差し替える場合は、**右カラム領域の図形を座標で一括削除**してから貼り直す
   （`sh.left >= Cm(13.75) and sh.top < Cm(17.0)` の図形を削除）

## 鉄則（このモード固有）

- 数値・固有名詞は**公式事例の記載どおり**。盛らない、丸めない、推測を混ぜない
- **全ページに出典**（媒体名・事例タイトル・企業名・公開日）
- 実画面キャプチャは**公式ページ掲載分のみ**。**人物写真は使わない**
- LINEグリーンはUI部分のみ（SKILL.md §7）
