# AI調査プロンプト（画一FMT）

型の原本：`_templates/AI調査プロンプト_画一FMT.md`（A＝市場調査／B＝競合サービス調査）。
**出力は表のみ・出典URLつき・URLを確認できないものは「確認できず」**で固定。どのAI（Gemini・ChatGPT・Perplexity）に投げても同じ形で返る。

## いつ使うか（タイミング）
案件の情報を受けた直後、**スライド構成を作る前**（multi-ai-relay の流れの②）。
「分析」とだけ言われたときの切り分け：
- **データが付いていない**（案件名や業界だけ）→ このスキルでプロンプトを出す
- **前後検索の画像・Googleトレンド・競合のLINE IDが付いている** → プロンプトは出さず、Claudeが直接分析する

## 手順
1. 与件（チャット、または `_drafts/<案件名>_与件整理*.md`）から、【 】に入る情報を埋める。**聞き返さない**（足りない項目だけ、一言で聞く）
2. 市場を調べるなら A、競合サービスを調べるなら B（両方なら2本）を、**完成形のコードブロック**で出す
3. 「このままGemini（またはChatGPT・Perplexity）に貼って、**表を全文コピペで戻してください**」と一言添える
4. 戻ってきた出力は、テンプレ末尾の**チェック**を通す
   - 出典URLが無い行 → 使わない／ブログ・まとめ・孫引き → 使わない
   - 食い違い → 公的統計（★）を採用
   - 「確認できず」の項目 → その項目だけ狭く聞き直すプロンプトを出す
5. 通過した行だけを `_drafts/<案件名>_商材・市場調査（日付）.md` の表に、出典URL・確認日つきで転記して commit & push

## 守ること
- CLAUDE.md：**根拠（出典URL）のない数字は資料に載せない**。2つのAIで数字が食い違うときは公的統計側
- 資料に載せる文言は先方に出せる言い方にする（調査メモは社内向けでよい）
- 【 】の項目や順番を勝手に増減しない（画一の形を崩さない）
