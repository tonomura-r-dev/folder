#### 各業界の設計判断（引き継ぎで効く要点）

- **賃貸**：効いた発見＝**検索は年中フラット（ピーク7月）なのに契約は1-3月に集中**＝業界は1-3月しか刈っていない、という論に組み替えた。広告の話は Ver.A の S06 だけ。
- **EC**：**賃貸のルール（広告を削る）を持ち込まない。** CPC推移＋広告審査は章2に必須。理由＝「獲得単価が上がるから回収側に回す」が資料の背骨。薬機法がLINE配信文面の制約になる。主KPI＝CPO＋F2転換率。
- **単品通販**：与件が**法律**。特商法改正（2022/6/1施行）で**解約妨害に罰則**。だから「解約を止める」ではなく**「解約の手前で受け止める」**が軸。主KPI＝F2転換率＋月次解約率、締めはLTV÷CPO。
- **注文住宅**：請負会社のLINE公式アカウント**公式事例は存在しない**（＝先行者になれる）。近い事例＝auka／オープンハウスG／ミサワホーム北越／LIFULL HOME'S。
- **教育（塾）**：**確定要旨＝「保護者の検討は塾を探す26日前に始まっている。塾が現れるのは最後の数日だけ」**（LINEヤフー前後検索・起点KW「塾 費用」の実測。−26日「小学生 塾 月謝 相場」→0日「塾 いつから通わせる」→+1.6日「料金相場」→+2〜10日「◯◯塾 口コミ」）。
  - **最初の問いは「いくら」ではなく「いつから」**：関連度1位「塾 いつから通わせる」**4.98**、2位「塾 成績上がらない」4.67。料金確認は**+1.6日＝決断の後**→入口訴求は"安さ"でなく"いつ始めるべきか"。
  - **検索者は母親**（実測）：「塾」女性**67.4%**・40代**52.8%**／個別クエリは80〜88%。※ChatGPT①が「一般論」とした点を実データで昇格。
  - **トレンド実測**：「塾」ピーク**2/8**、「夏期講習」ピーク**7/12**（冬期・春期の3〜5倍）。26日前と掛けて**仕込み開始＝1/13・6/16**が結論。
  - ⚠️**「勧誘・断り方」は前後検索ヒット0件**。初版の要旨はこれで棄却。第2版「合う塾が分からない63.5%」（塾ナラ2025）も検索行動に出ないためS5の心理根拠へ降格。**要旨を2回変えている**。
  - 🔴**競合調査の最大の発見（2026-09-15実機・証跡は `_data/lineoa_competitors/`）：栄光ゼミナール/ビザビは友だち3,713,373人を持ちながら、あいさつメッセージが「本アカウントは4月で配信を停止いたしました」＝371万人のリストが完全に凍結。** 移行先の栄光本体は30,000人＝**移行率1%未満**。→「友だちは広告で買えるが、運用設計がなければ資産にならない」がS8の結論であり提案の存在意義。
  - 友だち数実測：KUMON **25,256,318**／ビザビ **3,713,373**（凍結）／東進 136,000／武田塾 32,871／栄光 30,000／早稲アカ 30,000／明光・トライ・森塾は**教室別分散で合算不能**。→ **大手もLINEでは規模を持てていない＝資本力の勝負ではない。**
  - KUMONのリッチメニューはタブ切替＋左上「学年別」（提案の3タブ×学年起点の裏付け）。**ただし診断も体験予約も無く、Webへ送客するだけ**＝2,525万人を持っていて活用していない。
  - 補強データ：退会検討理由の**コミュニケーション不足が合計50.6%**（POPER2022）→月次学習レポート配信。**1年未満退塾者の43%が事前調査不足**（DeltaX2024）＝**診断は集客でなくリテンション施策**。**口コミ47%＞Web**（POPER2022）＋**紹介経由の入会率70〜80%超 vs Web経由40〜50%**＝紹介導線が最強。入塾学年は中受小4・他小5-6（オリコン2025）。費用は**91.2%が負担を感じつつ57.7%が「妥当」**（塾シル2026）＝**払う気はある、合うか分からないから決められない**。→ 打ち手は匿名30秒の適合診断。決定関与は**保護者80.5%・子ども本人57.8%**（明光2020）で親子両方を納得させる必要あり。**退会理由は1位「成績が上がらない」44.6%、2位3位のコミュニケーション不足が合計50.6%**（POPER2022）→ 月次学習レポート配信が効く。**1年未満退塾者の43%が「入塾前に十分調べなかった」**（DeltaX2024）＝**診断は集客ツールではなくリテンション施策**。集客は**口コミ47%＞Web**（POPER2022）で紹介導線が最安。入塾学年の山は中受小4・それ以外小5-6（オリコン2025）→**1学年前に友だち化**。
  - **⚠️ 塾はCPC/CPA・体験→入会率・退会率の公的統計が一切ない**（Gemini①③で確認）。業界推計値は CPC300〜800円／体験CPA25,000〜50,000円／入会率Web経由40〜50%・紹介経由70〜80%／退会率10〜20% だが**Gemini③も出典元を特定できていない**。社内実績の入手が最優先。
  - **⚠️ 学習塾の市場規模は定義で2倍変わる**：経産省「特定サービス産業動態統計」4,965億円（2024年）は**受講生500人以上の主要事業者のみ・市場の4〜5割**。矢野経済研究所の全体推計は**9,870億円**（2023年度）。**併記しないと「その数字おかしい」と言われる。**
  - 学習費の公表値：**令和5年度 子供の学習費調査**（2024-12-20公表・2年周期）＝公立中の通塾者平均 **318,500円/年**（月謝・入会金・講習費・教材費・模試代・施設費すべて込み）。
  - **⚠️ 当初仮説「大手はLINEを連絡網にしか使っていない」は外れ**（Gemini②）。大手8社全てが新規集客に使用。空白は「LINEの有無」ではなく**「診断で適合を見せているか」**（実装はトライ・早稲アカ程度）。
  - **⚠️「勧誘が不安で問い合わせない」は比率を示す公開調査が無い**（ChatGPT①が明示）＝一般論扱い。前後検索で「体験 断り方」系が出れば一次根拠に昇格。
- **学校法人（大学・専門学校）**：**塾と決定的に違う4点**が資料の設計を変えている。①**決めるのは高校生本人・払うのは保護者**（＝二重の説得。リッチメニュー3面目を保護者専用にした）②**接触期間が約18ヶ月**（塾の26日とは桁が違う）③**チャンスは年1回＝失注＝実質永久失注**（1人の入学＝4年間で約400万円）④**勝負は年内に終わる**（総合型は9/1出願・11/1発表、学校推薦型は11/1出願・12/1発表＝文科省 大学入学者選抜実施要項）。
  - **要旨＝「進路検討は18ヶ月。なのに学校の接点はオープンキャンパス当日の数時間だけ」**＋「渡した連絡先はメール＝高校生が最も見ない経路」。
  - **逆算の結論：夏のOCが実質の決戦 → だからOC集客は6月では遅い。友だち化は春（4-5月）に終わらせる。** 専門学校はAOエントリー**6/1解禁**なのでさらに前倒し。
  - **第2の提案軸＝入学後活用（中退防止）。** 年間中退率 約2%・4年で約8%（文科省・⚠️要照合）／2年次中退＝残存学費200〜300万円。**「募集で1人増やす＝中退を1人止める」で理事会の稟議に乗せる。**
  - **SIMのCPAは"悪化して見える"のが正しい**（資料請求CPA 4,000→4,408円）。見せるのは**入学1名あたりの獲得コスト 83,333→74,725円**。あわせて**「Web経由だけを切り出した試算＝他経路と重複するので純増は小さくなる」「定員という上限がある」**の限界注記を必ず添える。
  - **Googleトレンド実測（2026-09-15取得・`_data/trends/学校法人/`）**：「オープンキャンパス」は**5年連続で7月ピーク**（7月値 100/94/80/85/90）、谷は12-1月でピークの約1/20。週次は**ピーク7/27週・6/29週で既に半分（51）・動き出し5/25週**＝**仕込みの窓は5週間**。「総合型選抜」は**5年で3.3倍**（9月値30→100）で**2023年9月に指定校推薦を逆転**、週次ピークは**8/31週＝9/1出願解禁を含む週**。「専門学校」は**年中フラット22〜40**＝大学と季節性が違うので別設計。「共通テスト」は1月中旬の2週だけ（大学受験の約17倍スケールなので必ず別グラフ）。
  - **前後検索の読み（`_data/journey/学校法人/`）**：0日前後の密集帯は**ほぼ全部「大学名＋偏差値」**。−7日＝MARCH・成成明学 → 0日＝大東亜帝国・地方中小私大＝**志望校は下方修正の過程で決まる**。**OC検索が立つのは+1〜+7日＝OCは入口ではなく絞り込み後の確認行動**。「定員割れの大学一覧」が−2日。部活KW（野球部・駅伝部）が多く**スポーツ推薦の導線**が実在。地域は埼玉西部〜北部＝通学圏が主軸。
  - ⚠️**未取得**：競合8校の友だち数（**page.line.me をPCで実査**）／前後検索の**起点KWが未確認**／総合型選抜・専門学校の前後検索。
