# 提案資料のビルド手順（PC／スマホ共通）

ビイサイドプランニング様（求人vivical『しが就職・転職フェア』）向け LINE公式アカウント提案資料を、
スクリプトから再生成するための一式です。**スマホから claude.ai/code でこのリポジトリを開けば、同じ作業ができます。**

## ファイル構成

| パス | 中身 |
|---|---|
| `_templates/DYM_LINEOA_33p_base.pptx` | 33枚版のベース（DYMマスター入り・44枚） |
| `_templates/DYM_LINEOA_FMT.pptx` | 9枚版のベース（DYM汎用FMT・36枚） |
| `_build/build_vivical_33.py` | 33枚版フル提案のビルド |
| `_build/build_vivical_9p.py` | 9枚版コンパクト提案のビルド |
| `_build/qa_render.py` | 全ページPNG化（QA用・Windows/Linux両対応） |

## 使い方

```bash
pip install python-pptx
python _build/build_vivical_33.py
python _build/qa_render.py "20260804_株式会社ビイサイドプランニング御中_公式LINEのご提案.pptx"
```

出力はリポジトリ直下、QA画像は `_qa/` に出ます。

## 修正するときはここを触る

- **文言・数値**：`build_vivical_33.py` の各 `# ===== Slide NN =====` ブロック
- **スライドの並び／採否**：先頭の `ORDER`（ベース44枚の何番をどの順で使うかの指定）
- **配色**：先頭の定数（`TNAVY` タイトル紺 / `NAVY` 打ち手紺 / `RED` 課題赤 / `INK` 本文）

## 落とし穴（踏んだので書き残す）

1. **`put_text()` は必ず `reset_tf()` を通す。** 既存スライドのシェイプにそのまま書くと、
   元のテキストへの「追記」になって文字が混ざる（例：「ヒアリングの上Meta広告のみ確定」）。
2. **スライドの追加はしない。** ベースから削除＋並べ替えだけで構成する。
   python-pptx でスライドを新規追加すると、パート名の重複で壊れることがある。
   新しい内容が要るときは、使わないスライドの中身を `clear_slide()` して作り直す。
3. **流用スライドの業種残骸に注意。** ベースは別業種（EC・人材）の提案書なので、
   「定期購入・クロスセル」等の文言が残っていないか毎回確認する。
4. **QAのフォント。** クラウド（Linux）にメイリオが無い場合、代替フォントで描画されるため
   文字あふれの判定がズレる。**最終確認はPCの PowerPoint COM で行うこと。**
