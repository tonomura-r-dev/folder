# 07. 用語集（逆引き辞典）

> 会議中に「?」となったときに開く用途。**式があるものは式で覚える**のがコツです。

---

## 指標

| 用語 | 読み・正式名 | 意味・式 |
|---|---|---|
| **Imp** | インプレッション | 広告の表示回数 |
| **CTR** | Click Through Rate | クリック率 = クリック ÷ 表示 |
| **CPC** | Cost Per Click | クリック単価 = 広告費 ÷ クリック |
| **CPM** | Cost Per Mille | 1,000回表示あたり費用 = 広告費 ÷ 表示 × 1,000 |
| **CV** | コンバージョン | 成果地点（問い合わせ・予約・購入など）。**定義を決めるのが仕事** |
| **CVR** | Conversion Rate | CV率 = CV ÷ クリック |
| **CPA** | Cost Per Acquisition | 獲得単価 = 広告費 ÷ CV = **CPC ÷ CVR** |
| **ROAS** | Return On Ad Spend | 広告費用対効果 = 売上 ÷ 広告費 × 100% |
| **ROI** | Return On Investment | 投資収益率 = 利益 ÷ 投資額。ROASと違い**利益**ベース |
| **LTV** | Life Time Value | 顧客生涯価値 ≒ 単価 × 粗利率 × 購入回数 |
| **CAC** | Customer Acquisition Cost | 顧客獲得コスト。広告費以外も含む考え方 |
| **限界CPA／許容CPA** | ― | これ以上払うと赤字になるCPAの上限 |
| **フリークエンシー** | Frequency | 1人あたり平均接触回数。3〜4超で疲弊の目安 |
| **リーチ** | Reach | 広告に接触したユニークユーザー数 |
| **IS（インプレッションシェア）** | Impression Share | 表示機会のうち実際に表示された割合 |
| **CPF** | Cost Per Friend | **LINE友だち追加1件の単価**。相場150〜300円程度 |
| **ARPF** | ― | 友だち1人あたり売上 = 売上 ÷ 友だち数 |

## Google広告

| 用語 | 意味 |
|---|---|
| **P-MAX** | Performance Max。1キャンペーンでGoogleのほぼ全在庫に横断配信し、CV目標をAIが最大化する目標ベースのキャンペーン |
| **デマンドジェネレーション（Demand Gen）** | YouTube／Shorts・Discover・Gmailに画像・動画で配信し、潜在層に需要を作るキャンペーン |
| **RSA** | レスポンシブ検索広告。見出し最大15本・説明文最大4本をAIが組み合わせる |
| **マッチタイプ** | 完全一致 `[]` ／フレーズ一致 `""` ／インテントマッチ（旧・部分一致） |
| **検索語句レポート** | 実際に検索された語句の一覧。**除外の元ネタ。週次で見る** |
| **除外キーワード** | 配信させたくない語句。運用の中心作業 |
| **品質スコア** | 推定CTR・広告の関連性・LPの利便性から算出。低いとCPCが上がる |
| **広告ランク** | 掲載順位を決める指標 ≒ 入札 × 品質 ＋ 表示オプションの影響 |
| **アセット（広告表示オプション）** | サイトリンク、コールアウト、電話、住所など |
| **アセットグループ** | P-MAXにおける、テキスト・画像・動画のまとまり（広告グループ相当） |
| **オーディエンスシグナル** | P-MAXに渡す「こういう人に出したい」というヒント。**限定ではない** |
| **ブランド除外** | P-MAXが指名検索を食わないようにする設定。**必須** |
| **tCPA / tROAS** | 目標CPA／目標ROASの自動入札 |
| **拡張コンバージョン** | ハッシュ化した自社データで計測精度を補うGoogleの仕組み |

## Meta広告

| 用語 | 意味 |
|---|---|
| **Advantage+** | Metaの自動化機能群の総称。近年は「自動化が前提」の設計に移行 |
| **ASC** | Advantage+ ショッピングキャンペーン。現在は通常のキャンペーン作成フローに統合 |
| **Advantage+ オーディエンス** | 指定条件を"提案"として扱い、AIが外側まで配信する仕組み |
| **Advantage+ 配置** | 全配置に自動配信。縦型・スクエア素材の用意が前提 |
| **Andromeda** | Metaが刷新した広告レコメンデーションの基盤モデル |
| **CBO / キャンペーン予算最適化** | 広告セット間で予算を自動配分する仕組み |
| **Pixel** | サイトに設置するブラウザ側の計測タグ |
| **CAPI（コンバージョンAPI）** | サーバー側からCVを送る仕組み。**Pixelと併用が標準**。`event_id` で重複排除 |
| **AEM** | Aggregated Event Measurement。イベントの優先順位設定 |
| **カスタムオーディエンス** | 自社データ（顧客リスト・サイト訪問・動画視聴等）から作るターゲット |
| **類似オーディエンス（Lookalike）** | ソースに似たユーザーへ拡張したターゲット |
| **インスタントフォーム** | Meta内で完結するリード獲得フォーム。CVRは高いが質は落ちやすい |
| **学習期間** | 配信最適化のための初期期間。目安は広告セットあたり週50CV |
| **アトリビューション設定** | 例：クリック7日＋ビュー1日。**媒体間で異なるため単純合算不可** |
| **Ad Fatigue（疲弊）** | 同じ人に出しすぎてCTRが落ち、CPM・CPAが上がる状態 |

## LINE公式アカウント

| 用語 | 意味 |
|---|---|
| **LINE公式アカウント（LINE OA）** | 企業がLINE上で顧客とやり取りするためのアカウント |
| **コミュニケーションプラン** | 月額0円／無料200通／追加メッセージ**不可**（税別） |
| **ライトプラン** | 月額5,000円／無料5,000通／追加メッセージ**不可**（税別） |
| **スタンダードプラン** | 月額15,000円／無料30,000通／**追加メッセージ可（従量課金）**（税別） |
| **追加メッセージ** | 無料通数を超えた分の従量課金。**2026年10月以降：20万通まで3.0円／超過2.5円（税別・予定）** |
| **通数カウント** | **配信回数 × 到達友だち数**。1回の配信で吹き出し3つまでが1通 |
| **あいさつメッセージ** | 友だち追加時の自動配信。**通数カウント対象外**。開封率70〜80% |
| **応答メッセージ** | ユーザー発話への自動返信。**通数カウント対象外** |
| **LINEチャット** | 1:1トーク。**通数カウント対象外** |
| **ステップ配信** | 追加等をトリガーに順序・間隔を決めて自動配信。**通数カウント対象** |
| **絞り込み配信（セグメント配信）** | 属性・オーディエンスで対象を絞る配信。**通数カウント対象**だが**通数もブロック率も下げられる** |
| **リッチメニュー** | トーク画面下部に常時表示するメニュー。表示自体は課金対象外 |
| **みなし属性** | LINEが推定する年齢・性別・地域等。一定の友だち数がないと使用不可 |
| **オーディエンス** | クリック・インプレッション・チャットタグ等から作る配信対象 |
| **認証済アカウント** | LINEの審査を通ったアカウント。**友だち追加広告の出稿に必須**。審査に約10営業日 |
| **友だち追加広告（CPF）** | 友だち追加の成果課金型広告。日予算1,000円から |
| **ブロック率** | ブロック数 ÷ 追加数。**週3回以上の配信で急上昇**する傾向 |
| **Messaging API** | 外部システム（CRM・予約）と連携するAPI。配信は課金対象 |
| **LINE VOOM** | 投稿型のフィード。配信通数を消費しない接触手段 |

## 計測・分析

| 用語 | 意味 |
|---|---|
| **GA4** | Google Analytics 4。イベントベースの計測 |
| **キーイベント** | GA4における重要イベント（旧「コンバージョン」） |
| **UTMパラメータ** | 流入元を識別するURLパラメータ（`utm_source` 等）。**命名規則を最初に決める** |
| **アトリビューション** | CVをどの接点の成果とみなすかの考え方 |
| **ラストクリック** | 最後のクリックに全成果を帰属させるモデル |
| **データドリブンアトリビューション** | 実データから貢献度を配分するモデル |
| **ITP** | Appleのトラッキング防止機能。Cookie計測に影響 |
| **サーバーサイド計測** | ブラウザを介さずサーバーからCVを送る手法（CAPI・拡張CV） |
| **同意管理（CMP）** | Cookie利用の同意取得。**未同意だと計測が止まる**ので設定に注意 |
| **A/Bテスト** | 2案の比較検証。**各パターン最低30〜50CV**ないと勝敗はノイズ |

## LP・クリエイティブ

| 用語 | 意味 |
|---|---|
| **LP** | ランディングページ。広告の遷移先 |
| **FV（ファーストビュー）** | スクロールなしで見える領域。**CVRへの影響が最大** |
| **メッセージマッチ** | 広告の訴求とLPの訴求が一致していること |
| **CRO** | Conversion Rate Optimization。CVR改善 |
| **EFO** | 入力フォーム最適化。**項目を1つ減らすごとにCVRが上がる**のが経験則 |
| **UGC** | ユーザー生成コンテンツ。広告では「一般ユーザー風」クリエイティブとして活用 |
| **ヒートマップ** | クリック・スクロール・熟読箇所の可視化ツール |
