# 04. LINE公式アカウント（LINE OA）運用

> 記載時点：**2026年8月**。料金・仕様は変わります（→ [`08_出典と更新メモ.md`](08_出典と更新メモ.md)）。
> **提案書に載せる数値は、必ず [LINEヤフー for Business の公式ページ](https://www.lycbiz.com/jp/service/line-official-account/plan/) で当日確認してから使うこと。**

## 1. なぜLINE OAなのか（提案の一行目）

- LINEの国内MAUは**1億超**（LINEヤフー発表、2025年12月末時点）。年齢層・地域を問わず届く数少ないチャネル
- **プッシュで届く**。メールと違い、ほぼ確実に通知が出る
- **CV後の顧客に、追加コストほぼゼロで何度でも接触できる**

### 提案上の一番の勘所

> **広告は「CVまで」しか作れない。CV後の引き上げ（予約→来場、資料請求→商談）を担えるのがLINE OA。**

```
広告費80万円 / 予約80件 → 予約CPA 10,000円
予約 → 来場 65%   → 実質来場単価 15,385円
予約 → 来場 80%   → 実質来場単価 12,500円  ← 広告費は1円も増えていない
```

**「広告の外側で単価が改善する」** ── この構図を数字で見せるのが、LINE OA提案のコアロジックです。
（`20260804_..._LINE公式アカウント活用のご提案.pptx` と `_build/README.md` の数値の組み立ても、この形になっています）

## 2. 料金プラン（2026年8月時点・すべて税別）

| プラン | 月額固定費 | 無料メッセージ通数／月 | 追加メッセージ |
|---|---|---|---|
| **コミュニケーション** | 0円 | 200通 | **不可** |
| **ライト** | 5,000円 | 5,000通 | **不可** |
| **スタンダード** | 15,000円 | 30,000通 | **可（従量課金）** |

**重要：追加メッセージを送れるのはスタンダードプランだけ。** ライトプランは5,000通を使い切ったらその月は配信できません。

### 従量課金（追加メッセージ）と 2026年10月の改定

| | 現行 | **2026年10月1日以降（予定）** |
|---|---|---|
| 体系 | 配信量に応じて単価が下がる**15段階の逓減構造** | **20万通を境にした2段階** |
| 単価 | 最初の5万通までは1通3.0円、量が増えるほど段階的に下がり最大1.1円まで | **20万通まで一律3.0円／20万通超過分 2.5円** |

**影響：月5万通までのアカウントは実質影響なし。大量配信しているアカウントほど値上がりする。**

> 提案時の注意：**大量配信前提のシミュレーションを作るときは、必ず改定後の単価で試算する。**
> 「今の単価で計算した提案が、施策開始時には成立しない」は最悪のパターンです。

## 3. 通数のカウント方法 ― ここを間違えると見積もりが崩壊する

### 基本式

```
消費通数 = 配信回数 × 配信が届いた友だちの数
```

**1回の配信で最大3吹き出しまで送れて、3吹き出しまでは「1通」としてカウントされます。**
（吹き出しを3つ使っても消費は1通。ただし配信人数分は必ず消費する）

> 例：友だち5,000人に、月4回配信 → `4 × 5,000 = 20,000通`
> スタンダードプラン（30,000通込み）の範囲内で収まる。
>
> 友だちが15,000人に増えると → `4 × 15,000 = 60,000通`
> 超過30,000通 × 3.0円 = **追加90,000円/月**。固定費15,000円と合わせて月105,000円。

**「友だちが増えると配信コストが線形に増える」** ── これがLINE OA運用の最大の経済的制約です。
だからこそ **セグメント配信（絞り込み配信）** が効いてきます（後述）。

### カウントされる／されない

| カウント**される**（課金対象） | カウント**されない**（無料・無制限） |
|---|---|
| メッセージ配信（一斉配信） | **あいさつメッセージ**（友だち追加時の自動配信） |
| **絞り込み配信（セグメント配信）** | **応答メッセージ**（ユーザー発話への自動返信） |
| **ステップ配信** | **LINEチャット（1:1トーク）** |
| Messaging API の各種配信API | リッチメニュー（表示自体は課金対象外） |

### この仕様から導かれる実務戦略（超重要）

1. **あいさつメッセージは全力で作り込む。** 無料・無制限・かつ**開封率が平均70〜80%と最も高い**接点
2. **1:1チャットは無料。** 個別対応が効く商材では、一斉配信より1:1に寄せるほうが安く効く
3. **応答メッセージ（キーワード応答）で自動化する。** よくある質問はここで無料処理
4. **一斉配信は「全員に送らない」。** セグメントで絞れば通数が減り、かつブロック率も下がる ── コストと成果が同時に改善する

## 4. 友だちを集める（獲得）

| チャネル | コスト感 | 特徴 |
|---|---|---|
| **友だち追加広告（CPF）** | **CPF 150〜300円程度**（100〜400円が目安、業種差大） | 成果課金。**認証済アカウントが必須**。量を作れる |
| LINE広告（通常）からLPへ | CPC課金 | LPを挟むぶん動機づけできるが歩留まりが落ちる |
| Meta広告 → LINE誘導 | CPC/CPM課金 | クリエイティブ検証がしやすい。`03_Meta広告` 参照 |
| 自社サイト・LPへの導線設置 | ほぼ無料 | **やっていない企業が多い＝提案の即効ネタ** |
| 既存顧客への案内（メール・SMS・同梱物） | 低 | 質が最も高い |
| 店頭・チラシのQRコード | 低 | オフライン商材で強い |
| 友だち追加の**インセンティブ**（クーポン等） | 変動 | 量は出るが**質が落ちやすい**。ブロック率とセットで見る |

### 友だち追加広告（CPF）の実務

- **前提条件：認証済アカウントであること。** 審査に**10営業日程度**かかるので、**逆算してスケジュールを引く**（最低2週間の余裕）
- 初期費用・最低出稿金額なし。**日予算1,000円から**開始できる
- **立ち上げの型：日予算3,000〜5,000円で2週間テスト配信し、CPF単価とブロック率のデータを取る**
- 見るべきは CPF だけではない。**「CPF × (1 − ブロック率)」＝ 残る友だち1人あたりの実質単価**

```
CPF 200円 / ブロック率 30% → 実質単価 200 ÷ 0.7 ≒ 286円
CPF 300円 / ブロック率 10% → 実質単価 300 ÷ 0.9 ≒ 333円
```

**安く集めてブロックされるより、少し高くても残る友だちのほうが良い**ことがある ── これを数字で言えると強い。

## 5. 配信の設計

### 5-1. あいさつメッセージ（最優先）

**無料・無制限・開封率70〜80%。ここが全体の成否を決めます。**

構成の型：

```
① 追加のお礼 ＋ このアカウントで何が届くか（1〜2行）
② すぐ使える価値（クーポン／限定情報／診断／資料）← 追加の"見返り"を即渡す
③ 次のアクション1つ（予約する／診断する／メニューを見る）
④ 配信頻度の予告（「週1回程度お送りします」）← ブロック率を下げる効果
```

**やりがちな失敗：** 会社紹介から始める／情報量が多すぎる／CTAが3つ以上ある。

### 5-2. ステップ配信

友だち追加をトリガーに、あらかじめ決めた順序・間隔で自動配信する機能。**課金対象**です。

- 用途：**予約 → 来場**、**資料請求 → 商談**、**追加 → 初回購入** の引き上げ
- 設計：**「離脱が起きる場所」に合わせて置く**。等間隔に並べるものではない

> イベント集客のステップ設計例（予約完了をトリガー）
> ```
> 即時   ：予約完了の確認＋当日の持ち物・アクセス（不安の解消）
> 3日後  ：出展企業の紹介（期待の醸成）
> 前日   ：リマインド＋会場地図（最重要。ここが来場率に一番効く）
> 当日朝  ：「本日開催です」＋開始時刻
> 翌日   ：お礼＋次回案内／不参加者へのフォロー
> ```

**通数計算を忘れない：** 5通のステップ配信を1,000人が通過すると `5 × 1,000 = 5,000通` 消費します。

### 5-3. 絞り込み配信（セグメント配信）

**通数コストとブロック率を同時に下げる、最も費用対効果の高い機能。**

絞り込みの軸：

- **オーディエンス**：メッセージクリック、インプレッション、チャットタグ、友だち追加経路、購買データ連携（Messaging API）
- **属性（みなし属性）**：年齢・性別・地域・OS・利用年数 ※一定の友だち数がないと使用不可

> 全1万人に月4回配信 = 40,000通
> → 関心セグメント3,000人に絞って月4回 = 12,000通（**28,000通＝約84,000円/月の削減**）
> かつ、**関心のない人に送らないのでブロック率も下がる**

### 5-4. リッチメニュー

トーク画面下部に常時表示されるメニュー。**表示は課金対象外。**

- 「予約する」「メニューを見る」「よくある質問」「クーポン」など、**主要導線を常設**できる
- **タブ切り替え／期間で出し分け**が可能
- **CVの受け皿として最強**。配信で興味を持った人がいつでも辿り着ける
- 設計原則：**最上段の左に、最も取りたいアクション**を置く

### 5-5. その他の主要機能

| 機能 | 使いどころ |
|---|---|
| **クーポン／ショップカード** | 来店促進、再来店。使用状況が計測できる |
| **リサーチ（アンケート）** | セグメント用の属性収集。回答インセンティブとセットで |
| **応答メッセージ（キーワード応答）** | FAQの自動化。**無料** |
| **LINEチャット** | 1:1対応。**無料**。高単価商材ほど効く |
| **Messaging API** | 外部システム連携。予約システム・CRMと繋いで個別最適化 |
| LINE VOOM | 投稿型。配信通数を消費せずに接触できる |

## 6. KPI設計

| 指標 | 見方 | 目安・注意 |
|---|---|---|
| **友だち数（純増）** | 追加数 − ブロック数 | 総数ではなく**純増**で見る |
| **ブロック率** | ブロック数 ÷ 追加数 | 獲得経路別に必ず分解する。インセンティブ経由は高くなる |
| **配信到達数** | ブロックを除いた実配信数 | **課金はここに乗る** |
| **開封率** | インプレッション ÷ 到達 | 配信内容・時間帯で動く |
| **クリック率（CTR）** | クリック ÷ 到達 | メッセージ内リンクの反応 |
| **CV／引き上げ率** | 予約→来場、追加→購入 | **最終的にここが提案の約束** |
| **1通あたり売上** | 売上 ÷ 消費通数 | **配信の費用対効果**。従量課金の判断材料 |
| 友だち1人あたり売上（ARPF） | 売上 ÷ 友だち数 | LTV的な見方 |

### ブロック率のコントロール

**最大の要因は配信頻度です。週3回以上の配信でブロック率が急上昇する**という傾向が知られています。

抑えるための手：

1. **頻度は週1〜2回を基本線に。** あいさつメッセージで頻度を予告する
2. **セグメント配信で、関心のない人に送らない**
3. **配信内容に「受け取る価値」を必ず入れる**（お知らせだけの配信を続けない）
4. **配信時間帯を最適化**（BtoCは夜、BtoBは平日昼など。実データで検証）
5. **獲得経路の質を上げる**（インセンティブ目当ての大量獲得は、後で通数コストとして跳ね返る）

## 7. 提案の組み立て（実務テンプレ）

```
1. 現状：広告費・CV数・CPA・引き上げ率をヒアリング実績で置く
2. 課題：どこで漏れているか（例：予約→来場が65%）を数字で特定
3. 打ち手：LINE OAのどの機能で、どこの漏れを止めるか
     予約直後の不安 → あいさつ／ステップ配信
     前日の失念     → リマインド配信
     再来場         → セグメント配信＋クーポン
4. 効果試算：引き上げ率を◯%に改善 → 実質単価が◯円→◯円
5. コスト：プラン月額＋想定通数×単価（改定後単価で）＋広告費（CPF）＋運用工数
6. 差引：改善効果 − コスト = 純便益
7. スケジュール：認証審査10営業日を含めた逆算
```

### 数値の出典を分けて書く（信頼を落とさないため）

`_build/README.md` の書き方が良い手本です。提案書には必ず区別して書く：

- **貴社ヒアリング実績**（一番強い）
- **他社事例／社内配信実績**
- **上記からの試算**
- **一般公開されている相場**

**この4つを混ぜて「◯◯円になります」と書かない。** どれが約束でどれが仮定かが分かるようにする。

## 8. つまずきポイント集

| 症状 | 疑うところ |
|---|---|
| 見積もりが実際と大きくズレた | 通数カウントの誤解（配信回数 × **到達友だち数**）、ステップ配信の通数を数え忘れ |
| 友だちは増えるがCVしない | 獲得経路の質（インセンティブ目当て）、あいさつメッセージが弱い、リッチメニューに導線がない |
| ブロック率が高い | 配信頻度、セグメントなしの全体配信、内容に価値がない、獲得時の期待とのズレ |
| 配信コストが急増した | 友だち数の増加に配信回数を掛け続けている。**セグメント配信への切り替えを提案** |
| 友だち追加広告が出せない | **未認証アカウント**。認証審査に10営業日 |
| 効果が測れない | 計測設計なし。**リンクにUTM付与＋CV地点の定義**を最初に決める |
| ライトプランで月中に配信できなくなった | ライトは追加メッセージ不可。**スタンダードへの移行**が必要 |
