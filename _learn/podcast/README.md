# Podcast台本（音声学習用）

`_learn/` の教材を、**通勤中に聴いて消化できる対話形式の台本**にしたものです。
2週間集中プランの Day 1〜10 と1対1で対応しています。

- 形式：2人の対話（**ハル**＝解説役／**ソラ**＝聞き手・新人）
- 尺：1本あたり **約6〜8分**（約2,000〜2,500字）
- 全10本、合計およそ70分

## 音声にする手順

### いますぐ聴く：同梱のプレイヤー（`player.html`）

`player.html` をブラウザで開けば、**全10話をそのまま再生できます**。
音声ファイルは持たず、**端末の読み上げ機能（Web Speech API）** で喋らせています。

- 2話者に別々の日本語音声を自動割当（声が1つしかない端末では話速と高さで区別）
- 行をタップするとそこから再生／再生速度 0.9〜1.6倍
- 聴いた位置を端末に保存し、次に開いたとき続きから
- **音質は端末の読み上げエンジン依存**。iOSは画面ロックで停止します

自然な音声で聴きたい場合は、下のNotebookLMの手順のほうが上です。

**台本を直したら、必ず再ビルドしてください**（`player.html` は生成物です）：

```bash
python3 _learn/podcast/build_player.py
```

`build_player.py` は `ep*.md` をパースしてHTMLを生成します。台本の単一情報源は
あくまで `ep*.md` 側です。読み上げの崩れを直す置換（`P-MAX`→`ピーマックス`、
桁区切りカンマの除去など）はスクリプト冒頭の `SPEECH_FIXES` にまとまっているので、
気になる読み間違いが出たらここに足します。**表示される台本は元の表記のまま**で、
読み上げ用テキストだけを変換しています。

発話数が想定と違うとスクリプトが警告を出します（台本を増減したときは
`EXPECTED` も更新してください）。

### NotebookLM の音声概要を使う場合（音質はこちらが上）

1. NotebookLM で新しいノートブックを作る
2. **ソースに `ep01.md` 〜 `ep10.md` を追加**（テキストを貼り付けでも可）
3. 「音声概要」を生成。カスタマイズ欄に指示を入れると台本に寄ります：
   > 「アップロードした台本の内容と順序に忠実に、ハルとソラの対話として進めてください。数値は台本のとおり正確に読み上げてください。新しい情報は足さないでください。」
4. **1本ずつソースを分けたほうが、エピソード構成が崩れません**

> 注意：NotebookLM の音声概要は台本を一字一句読むツールではなく、**内容を再構成して喋ります**。
> 数値の正確さが必要な回（EP08 の料金・通数）は、生成後に必ず聴いて確認してください。

### ElevenLabs / VOICEVOX など、台本どおり読ませる場合

- **話者ラベル（`ハル：` `ソラ：`）を削って、話者ごとにテキストを分割**してから投入します
- 2話者に別々の声を割り当てると対話らしくなります
- VOICEVOX（無料・ローカル）なら、日本語の話者切り替えが簡単です

### スマホの読み上げ機能で済ませる場合

- iOS：設定 → アクセシビリティ → 読み上げコンテンツ → 画面の読み上げ
- GitHub 上でこのファイルを開いて、2本指で画面上端から下にスワイプ

> **なぜ mp3 を同梱していないか**：この作業環境ではネットワークポリシーにより
> 音声合成サービス（Edge TTS・Google TTS）に到達できず、サーバー側で音声ファイルを
> 生成できません。ローカルTTSも入っていないため、再生は端末側に任せる方式にしています。

## 台本を書くときのルール（追記・修正するとき用）

読み上げを前提にしているので、教材本体とは書き方を変えています。

1. **記号を本文に使わない。** 太字・箇条書き・表・矢印は読み上げると崩れる
2. **数式は音読できる日本語で書く。** 「CPA ＝ CPC ÷ CVR」ではなく「CPAは、CPCをCVRで割ったもの」
3. **数字は聴いて分かる単位で。** 「16,667円」より「およそ1万6,700円」
4. **1文を短く。** 息継ぎのない長文は聴き取れない
5. **各エピソードの最後に「今日の宿題」を入れる。** 2週間プランの完了条件と揃える
6. **専門用語は初出で必ず一度、日本語で言い換える**
