# 03. Meta広告（Facebook / Instagram）

> 記載時点：**2026年8月**。Metaは仕様変更が特に速い媒体です（→ [`08_出典と更新メモ.md`](08_出典と更新メモ.md)）。
> 大原則：**Meta広告の成果はクリエイティブで決まる。** ターゲティングの妙技で勝つ時代は終わりました。

---

## 1. 構造

```
キャンペーン（目的・予算配分方式）
 └ 広告セット（ターゲット・配置・予算・最適化イベント）
    └ 広告（クリエイティブ・テキスト・遷移先）
```

### キャンペーン目的

| 目的 | 使う場面 |
|---|---|
| 認知 | リーチ・ブランド想起（CPMが安い。指標はCV以外で見る） |
| トラフィック | サイト流入。**CV目的が使えるならCV目的を選ぶ**（安いクリックだけ集まりがち） |
| エンゲージメント | 動画再生、投稿反応、**メッセージ（LINE/Messenger誘導と相性）** |
| リード | Meta内のフォームで完結（インスタントフォーム）。CVRは高いが質は落ちやすい |
| アプリ | アプリインストール |
| **売上（コンバージョン）** | サイト内CVを取る主戦場。**基本はこれ** |

## 2. Advantage+ と自動化の潮流（ここが近年の最大の変化）

Metaは **「自動化を選ぶ」から「自動化が前提」へ** プロダクト思想を転換しました。

### 押さえるべき変化

- 従来独立していた **Advantage+ ショッピングキャンペーン（ASC）** の仕組みが**通常のキャンペーン作成フローに統合**された
- 条件を満たすと**自動的に Advantage+ が有効化される「合理化されたセットアップ」**が展開されている
- かつて「1キャンペーン＝1広告セット」固定だった制約が緩み、**複数の広告セットを内包できる**ようになった（商材カテゴリ別・国別の管理がしやすい）
- レコメンデーションの基盤モデル刷新（Andromeda）により、**パーソナライズ精度が向上**
- 広告ポリシーの大規模改訂、AI生成物の開示、審査のマルチモーダル化などが進行

### 主なAdvantage+機能

| 機能 | 中身 | 実務判断 |
|---|---|---|
| **Advantage+ オーディエンス** | 指定条件を"提案"として扱い、AIが外側まで配信 | 基本ON。ただし**厳格な条件（年齢制限・地域限定商材）がある場合は要注意** |
| **Advantage+ 配置** | 全配置に自動配信 | 基本ON。**ただし縦型・スクエア素材を用意すること**が前提 |
| Advantage+ クリエイティブ | 明るさ調整、テキスト自動生成、音楽追加など | 検証してから。ブランド管理が厳しい案件はOFF |
| Advantage+ カタログ広告 | フィード連動のダイナミック広告 | EC必須 |
| Advantage+ キャンペーン予算（旧CBO） | 広告セット間で予算を自動配分 | 基本ON。手動配分したい理由があるときだけOFF |

### 自動化時代の"罠"

1. **オーディエンス拡張で、既存顧客・低品質層に配信が寄る** → 既存顧客の除外、質のフィルタを入れる
2. **配置自動化で、素材が崩れた面に出る** → 各配置のプレビューを必ず確認
3. **学習が回らないほど広告セットを分割する** → 統合する
4. **見かけのCPAが良いが、実受注が伴わない** → **必ずCRM実数と突合**（リード獲得系で頻出）
5. **自動化に任せた結果、なぜ勝ったかが分からない** → クリエイティブ単位のレポートで仮説を残す
6. **CV計測が壊れたまま自動化が最適化を続ける** → 定期的にテストCVを通す
7. **ポリシー改訂で既存クリエイティブが落ちる** → 審査落ちの通知は放置しない

## 3. ターゲティング

### 現在の優先順位

```
1. 自社データ（カスタムオーディエンス）  ← 最強。顧客リスト、サイト訪問、動画視聴、LINE友だち
2. 類似オーディエンス（Lookalike）      ← 良質なソースがあるとき
3. Advantage+ オーディエンス（AI任せ）  ← 標準。シグナルとして興味関心を渡す
4. 詳細ターゲット（興味関心・行動）      ← 補助的。単体で細かく刻むのは非推奨
```

### カスタムオーディエンスの作り方（実務でよく使う）

- **顧客リストのアップロード**（メール・電話番号のハッシュ化。**同意取得の範囲内で**）
- **ウェブサイト訪問者**（Pixel）：全訪問／特定ページ／滞在時間上位25%
- **動画視聴者**：3秒／25%／75%視聴。**低コストでリタゲ母数を作れる**
- **Instagram/Facebookのプロフィール接触者**：フォロー、投稿保存、DM
- **リードフォーム開封者・送信者**

### 除外の設計（忘れがち）

- **既存顧客・購入済みユーザーを除外**（新規獲得キャンペーンでは必須）
- 応募済み・来場済みを除外（人材・イベント系）
- リタゲとプロスペクティングの**重複除外**

## 4. クリエイティブ ― ここが本丸

### 検証すべき順序（効果が大きい順）

```
1. 訴求（誰の・どの悩みに・何を言うか）   ← 最大の変数
2. フォーマット（静止画／動画／UGC風／カルーセル）
3. ファーストビュー（冒頭1〜2秒、1枚目）
4. コピー（見出し・本文）
5. 細部（色、CTAボタン文言）
```

**訴求を変えずに色だけ変えても、成果はほぼ動きません。**

### 訴求の作り方（`ペルソナ・マンダラート課題ワーク.xlsx` と接続）

ペルソナから訴求を出すときは、この5軸で機械的に展開すると漏れが減ります。

| 軸 | 問い | 例（イベント集客の場合） |
|---|---|---|
| **課題・悩み** | 何に困っているか | 「転職したいが、何から始めればいいか分からない」 |
| **ベネフィット** | 手に入る良い状態 | 「1日で複数社と直接話せる」 |
| **不安の解消** | 何が怖くて動けないか | 「参加無料・履歴書不要・私服OK」 |
| **証拠** | なぜ信じられるか | 「昨年◯◯名が参加」「地元企業◯社出展」 |
| **今すぐの理由** | なぜ今か | 「9/26 東近江開催・受付は8/28から」 |

### 制作の実務ルール

- **縦型（9:16）・スクエア（1:1）・横型（1.91:1）を必ず用意。** 自動配置の前提条件
- 動画は**冒頭2秒で結論**。音声なしでも伝わるよう**字幕を焼き込む**
- **テキスト量の目安**：情報を詰めすぎない。1クリエイティブ1メッセージ
- 静止画・動画・UGC風を**同時に走らせて勝ちを探す**（1本ずつ試すのは遅い）
- **勝ちクリエイティブは"型"として横展開する**（同じ構成で訴求だけ替える）

### クリエイティブ疲弊（Ad Fatigue）

- 症状：**CTRが落ち、CPMとCPAが上がる**（フリークエンシー上昇を伴う）
- 目安：フリークエンシーが週あたり3〜4を超えると要注意（母数が小さいほど早く来る）
- 対策：**定期的な差し替えを運用に組み込む**（例：2週間ごとに新規3本投入）
- 注意：**勝っているクリエイティブを止めない**。追加投入で入れ替える

## 5. 計測（Pixel / コンバージョンAPI）

- **Pixel（ブラウザ側）だけでは取りこぼす。** ITP・アドブロック・同意管理の影響
- **コンバージョンAPI（CAPI／サーバー側）を併用するのが標準**。重複排除のため `event_id` を揃える
- **イベントの優先順位（Aggregated Event Measurement）** を設定する
- **アトリビューション設定**（例：クリック7日＋ビュー1日）を必ず確認し、**レポートに明記**する
  - Google側とアトリビューションが違うため、**媒体CVの単純合算は実CVを超える**
- 週次で「**媒体CV数 ÷ CRM実数**」の比率を見ると、計測劣化に早く気づける

---

## 6. 予算と学習

- 広告セットあたり **週50CV程度** が学習の目安。届かないなら
  - 広告セットを**統合する**
  - **最適化イベントを上流に変える**（購入 → カート投入 → LP到達）
  - 予算を集約する
- **キャンペーン予算最適化（Advantage+ キャンペーン予算）** を使い、広告セット単位の細かい予算調整はしない
- 予算変更は**一度に±20%程度**まで。大きく動かすと学習がリセットされる
- **学習期間中（通常1週間程度）は触らない**

## 7. LINE公式アカウントへの誘導（自社実務で最重要）

Meta広告 → LINE友だち追加、は非常に相性の良い導線です。

```
Meta広告（認知・興味） → LP or 直接LINE追加 → あいさつメッセージ → ステップ配信 → CV
```

### 設計のポイント

- **目的は「トラフィック」ではなく「コンバージョン」or「エンゲージメント（メッセージ）」**を検討
- 友だち追加を**CVとして計測する**（LINEの友だち追加完了ページ or Messaging APIのWebhookをトリガーに）
- **オファーが命**：「友だち追加で◯◯プレゼント」「LINE限定で先行予約」など、追加する理由を明示
- **追加直後のあいさつメッセージの開封率は平均70〜80%と非常に高い**。ここでの体験がブロック率を決める
- 広告のCPFと、LINE広告の友だち追加広告（CPF、相場150〜300円程度）を**並べて比較**する

> **提案での見せ方：**
> 「広告でCVを増やす」だけでなく、
> 「**広告で獲得した見込み客をLINEに溜め、二度目・三度目の接触で引き上げる**」
> という設計にすると、同じ広告費で実質単価が下がる ── これが数字で示せると提案が通ります。

## 8. つまずきポイント集

| 症状 | 疑うところ |
|---|---|
| CPMが高い | 競合期（年末・セール期）、ターゲットが狭すぎ、オークション競争、品質ランキングが低い |
| CTRが低い | クリエイティブの訴求ズレ、冒頭で止められていない、疲弊 |
| CVRが低い | LPとのメッセージマッチ、遷移速度、フォーム、そもそも興味段階の層に出ている |
| CVが計測されない | Pixel/CAPI設定、ドメイン認証、イベント優先順位、同意管理ツールとの干渉 |
| リードの質が悪い | インスタントフォームの項目が少なすぎる、オファーが目的とズレている（例：プレゼント目当て） |
| 配信が偏る | 学習不足で1広告に集中。**それが正常な挙動**なので、勝ち素材が明確なら問題なし |
| 審査落ちが増えた | ポリシー改訂。文言（誇大表現・個人属性の断定）、LPの記載、AI生成物の開示 |
