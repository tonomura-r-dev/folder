## 2. 許容CPA 逆算シート

```
① 客単価                      =            円
② 粗利率                      =            %
③ 1件あたり粗利  ①×②         =            円
④ CV → 受注率                 =            %
⑤ CV1件あたり期待粗利 ③×④    =            円
⑥ 目標とする利益配分（例50%） =            %
⑦ 【許容CPA】 ⑤×(1−⑥)        =            円

⑧ 現在のCVR                   =            %
⑨ 【許容CPC】 ⑦×⑧            =            円
⑩ 媒体の想定CPC               =            円
判定：⑨ ≧ ⑩ なら成立の見込み／⑨ < ⑩ ならCVR改善かオファー見直しが先
```

## 3. LINE OA 通数・コストシミュレーション

```
■ 前提
友だち数（想定到達）        =        人
一斉配信の回数             =        回/月
ステップ配信の通過人数      =        人/月
ステップ配信の通数         =        通（=1人あたりの配信回数）
                                    ※吹き出し3つまでは1通

■ 消費通数
一斉配信      : 配信回数 ×  到達友だち数     =        通
ステップ配信  : 通過人数 ×  ステップ通数     =        通
合計                                        =        通

■ 費用（すべて税別）
プラン月額（スタンダード）                   = 15,000 円
無料通数                                     = 30,000 通
超過通数 = 合計 − 30,000                     =        通
超過料金（2026年10月以降）
   20万通まで        : 超過分 × 3.0円        =        円
   20万通超過分      : 超過分 × 2.5円        =        円
月額合計                                     =        円

■ 参考：1通あたり売上
想定売上 ÷ 消費通数 =        円/通  ← 1通3円を上回っているか
```

> **注意：** 料金は 2026年8月時点の情報。提出前に [公式ページ](https://www.lycbiz.com/jp/service/line-official-account/plan/) で必ず確認。

## 4. 引き上げ改善の効果試算（LINE OA提案の中核）

```
■ 現状
広告費                =            円/月
CV（予約・問合せ）数   =            件/月
CPA = 広告費 ÷ CV     =            円

引き上げ率（CV→来場/受注） =        %
実質獲得単価 = CPA ÷ 引き上げ率  =            円   ← ここが本当のコスト

■ 改善後（LINE OA施策あり）
引き上げ率（目標）        =        %
実質獲得単価（改善後）    =            円
改善幅（1件あたり）       =            円
月間の改善額 = 改善幅 × 来場/受注件数 =        円

■ 施策コスト
LINE OA プラン月額 ＋ 従量課金        =        円
友だち獲得広告費（CPF × 目標人数）     =        円
運用工数（内製 or 委託）              =        円
合計                                 =        円

■ 純便益 = 月間の改善額 − 施策コスト =        円/月
```

**書き方の注意：** 各数値の右に必ず出典を書く。
`（貴社ヒアリング実績）` `（他社事例／社内配信実績）` `（上記からの試算）` `（公開相場）`

## 7. LINE OA 提案の骨子（スライド構成）

```
1. 表紙
2. 本日のご提案（結論を1枚で）
3. 現状の整理 ── ヒアリング実績の数字を並べる
4. 課題の特定 ── 「どこで漏れているか」を1点に絞る
5. なぜLINEか ── MAU、プッシュ到達、CV後の接触コスト
6. 施策① あいさつメッセージ ── 無料・開封率70〜80%
7. 施策② ステップ配信 ── 離脱ポイントに合わせた設計図
8. 施策③ セグメント配信 ── コストとブロック率を同時に下げる
9. 施策④ リッチメニュー ── 常設の受け皿
10. 友だちの集め方 ── CPF／自社導線／既存顧客
11. 効果試算 ── 引き上げ率の改善 → 実質単価の変化
12. 費用 ── プラン＋従量課金＋広告費＋運用（改定後単価で試算）
13. 純便益
14. スケジュール ── 認証審査10営業日を含めた逆算
15. 体制・ご依頼事項
16. Appendix ── 前提条件と数値の出典一覧
```

**最後の「前提条件と数値の出典一覧」を必ず入れる。** ここがある提案は信頼されます。
