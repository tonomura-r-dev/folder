**自分用の教科書＋実務チェックリスト**です。読んで終わりではなく、明日の提案・運用にそのまま貼れる形を優先しています。

- 対象領域：**広告運用（Google／Meta／LINE広告）** と **LINE公式アカウント運用**
- 前提レベル：用語はぼんやり知っている／自分で数字を組み立てるところが不安、という段階
- 記載時点：**2026年8月**（数値・仕様は変わります。→ [`08_出典と更新メモ.md`](08_出典と更新メモ.md)）

## 2週間集中プラン（平日10日／1日45〜60分）

**これがメインの進め方です。** 1日 = 読む15〜20分 ＋ 手を動かす25〜40分。
**インプット：アウトプット＝1：2。** 読むだけの日を作らないのが、短期で身につける唯一のコツです。

### Week 1 ── 広告運用（数字の言語 ＋ Google／Meta）

| Day | 読む（15〜20分） | 手を動かす（25〜40分）＝ その日の完了条件 |
|---|---|---|
| **1** | `00_基礎` 1〜2節（ファネル・CPA分解・LTV/CAC・許容CPA） | **自社の既存案件1件をファネルの数式に分解**して書き出す（広告費 → CV → CPA → 引き上げ率 → 実質単価） |
| **2** | `00_基礎` 3〜6節（単位揃え・ジャーニー）＋ `01_共通原則` 1〜2節（計測設計） | `06_テンプレート集` の**許容CPA逆算シートを1案件ぶん埋める** |
| **3** | `01_共通原則` 3〜6節（構造・入札・予算配分・LP） | 既存アカウント1つの**構造図を書き、「なぜこう分けているか」を各キャンペーンに一言ずつ**添える |
| **4** | `02_Google広告` 1〜2節（キャンペーンタイプ・検索広告） | 実案件の**検索語句レポートを開き、除外キーワードを20個**出す |
| **5** | `02_Google広告` 3〜7節（P-MAX・DemandGen・入札） | **ブランド除外の有無を実アカウントで確認**＋入札戦略が今の段階に合っているか判定を書く |
| **6** | `03_Meta広告` 1〜4節（構造・Advantage+・ターゲ・クリエイティブ） | `06_テンプレート集` の**クリエイティブ企画シートを3案**書く（訴求軸を3つ変える） |
| **7** | `03_Meta広告` 5〜8節（計測・予算・LINE誘導・つまずき） | 1案件で**統合できる広告セットを指摘**＋CAPIの設定有無を確認する |

> Day 1〜7 が終わった時点で、**「CPAが高い」と言われたときに分解して答えられる**状態になります。ここまでが最低ライン。

| Day | 読む（15〜20分） | 手を動かす（25〜40分）＝ その日の完了条件 |
|---|---|---|

**仕上げ（週末・2〜3時間）**
`06_テンプレート集` の提案骨子に沿って、**「広告 → LP → LINE OA → 来場/購入」を貫く提案を1本、ゼロから作る。**
これが実質的な卒業試験です。ここまでやって初めて「身についた」と言えます。

## 学習の進め方（大事なところ）

1. **数字は必ず「分解」してから覚える。** CPAが高い／低いは結論ではなく、`CPA = 広告費 ÷ CV = CPC ÷ CVR` まで割ってから初めて打ち手が決まります。
2. **媒体の管理画面を「読む」練習をする。** 記事を10本読むより、実案件のレポートを1本、数式に分解して読むほうが速い。**短期で身につけるなら、教材より実データの時間を増やす。**
3. **1日の完了条件は「書けたか」で判定する。** 「理解した気がする」で先に進むと、2週間後に何も残りません。
4. **仕様と相場は必ず一次情報で確認する。** このノートの数値も 2026年8月時点のスナップショットです。人に出す数字は [`08_出典と更新メモ.md`](08_出典と更新メモ.md) のリンクを踏んでから使ってください。
5. **「自社の実績値」を最強の教材にする。** 一般論の相場より、社内の配信実績のほうが提案では強い。ヒアリング実績と他社事例は必ず区別して書く（`_build/README.md` の「数値の出どころ」の書き方が良い手本です）。

> **もっと時間が取れない場合：** 2週間プランを、1日1トピック → **週2〜3日ペースで4週間**に薄めても構いません。
> ただし**順番は変えないこと**（`00_基礎` → 広告 → LINE OA → 提案）。数字の言語がないままLINE OAを読んでも、通数計算が腹落ちしません。
