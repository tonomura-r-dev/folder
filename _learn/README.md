**自分用の教科書＋実務チェックリスト**です。読んで終わりではなく、明日の提案・運用にそのまま貼れる形を優先しています。

- 対象領域：**広告運用（Google／Meta／LINE広告）** と **LINE公式アカウント運用**
- 前提レベル：用語はぼんやり知っている／自分で数字を組み立てるところが不安、という段階
- 記載時点：**2026年8月**（数値・仕様は変わります。→ [`08_出典と更新メモ.md`](08_出典と更新メモ.md)）

## 12週間ロードマップ

「毎日30〜60分＋週末に手を動かす」ペース想定。**インプット：アウトプット＝1：2** を守るのがコツです。

### フェーズ1：共通言語をつくる（1〜2週目）

| 週 | やること | アウトプット（これが完了条件） |
|---|---|---|
| 1週目 | `00_基礎` を読む。CPA・ROAS・LTV・CACを自分の言葉で説明できるようにする | **自社の既存案件1件を、ファネルの数式に分解して書き出す**（例：広告費80万円 → CV80件 → CPA1万円 → 来場率65% → 実質来場単価16,667円） |
| 2週目 | `01_広告運用_共通原則` を読む。GA4のCV設定を実物で見る | **既存アカウント1つの「計測設計図」を書く**（何をCVとしているか、重複計上はないか） |

### フェーズ2：広告運用の型を入れる（3〜7週目）

| 週 | やること | アウトプット |
|---|---|---|
| 3週目 | `02_Google広告` 前半（検索広告・マッチタイプ・品質） | 実案件の検索クエリレポートを見て、**除外キーワード案を20個**出す |
| 4週目 | `02_Google広告` 後半（P-MAX・デマンドジェネレーション・入札戦略） | 既存アカウントの入札戦略が**なぜそれなのか**を説明する文章を書く |
| 5週目 | `03_Meta広告` 前半（構造・Advantage+・オーディエンス） | 1案件のキャンペーン構造図を書き、**統合できる広告セット**を指摘する |
| 6週目 | `03_Meta広告` 後半（クリエイティブ・疲弊・CAPI） | **クリエイティブ企画シートを3案**書く（`06_テンプレート集`） |
| 7週目 | 総合演習 | 架空案件で **月額50万円の媒体配分案＋KPI設計** を1枚にまとめる |

### フェーズ3：LINE公式アカウントを武器にする（8〜11週目）

| 週 | やること | アウトプット |
|---|---|---|
| 8週目 | `04_LINE OA` 料金・通数計算 | **通数シミュレーションを自分で作る**（友だち数×配信頻度×吹き出し数 → 月額） |
| 9週目 | `04_LINE OA` 友だち獲得（CPF・LP・店頭） | 既存案件の**友だち獲得チャネル別コスト**を並べて比較する |

| 11週目 | `04_LINE OA` KPI・ブロック率・改善 | 既存の提案書（`20260804_...pptx`）を**このノートの観点でセルフレビュー**する |

| 週 | やること | アウトプット |

## 学習の進め方（大事なところ）

1. **数字は必ず「分解」してから覚える。** CPAが高い／低いは結論ではなく、`CPA = 広告費 ÷ CV = CPC ÷ CVR` まで割ってから初めて打ち手が決まります。
2. **媒体の管理画面を「読む」練習をする。** 記事を10本読むより、実案件のレポートを1本、数式に分解して読むほうが速い。
3. **仕様と相場は必ず一次情報で確認する。** このノートの数値も 2026年8月時点のスナップショットです。人に出す数字は [`08_出典と更新メモ.md`](08_出典と更新メモ.md) のリンクを踏んでから使ってください。
4. **「自社の実績値」を最強の教材にする。** 一般論の相場より、社内の配信実績のほうが提案では強い。ヒアリング実績と他社事例は必ず区別して書く（`_build/README.md` の「数値の出どころ」の書き方が良い手本です）。
