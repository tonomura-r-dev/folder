# 02. Google広告

> 記載時点：**2026年8月**。機能名・仕様は変わります（→ [`08_出典と更新メモ.md`](08_出典と更新メモ.md)）。
> 近年の潮流は一貫して **「運用者が細かく制御する」から「AIに良い材料と正しい目標を与える」へ**。
> 何を渡し、何を渡さないかを設計するのが今の運用者の仕事です。

---

## 1. キャンペーンタイプの地図

| タイプ | 配信面 | 役割 | 向く場面 |
|---|---|---|---|
| **検索** | Google検索結果 | **顕在層の刈り取り** | ニーズが検索されている商材。まずここ |
| **P-MAX（Performance Max）** | 検索・ディスプレイ・YouTube・Discover・Gmail・マップ等ほぼ全面 | **取りこぼしの回収**、横断最適化 | アセットが揃っていて、CVデータが溜まっている |
| **デマンドジェネレーション（Demand Gen）** | YouTube／Shorts・Discover・Gmail | **需要の創出**（潜在層） | 検索されない商材、ビジュアルで伝わる商材 |
| ショッピング | 検索・ショッピングタブ | EC商品の刈り取り | 物販（商品フィード必須） |
| ディスプレイ | GDN | 認知・リタゲ | 安価なリーチ、リマーケティング |
| 動画 | YouTube | 認知・比較 | 動画アセットがある |
| アプリ | 各面 | アプリインストール | アプリ商材 |

### 使い分けの原則

**検索広告が「指名検索」と「重要な刈り取りキーワード」を確実に押さえ、その外側（検索の裾野・ディスプレイ・YouTube・Discover）をP-MAXが拾う。** 潜在層への需要創出はデマンドジェネレーションが担う ── この役割分担で考えると迷いません。

> **順番の原則：まず検索。** 検索で成立しない商材が、P-MAXで急に成立することはあまりありません。
> 逆に、検索でCPAが合っている状態でP-MAXを足すと、伸びしろが取れることが多い。

## 2. 検索広告 ― まずここを固める

### 2-1. アカウント構造

```
アカウント
 └ キャンペーン（予算・入札戦略・地域・スケジュールの単位）
    └ 広告グループ（キーワードと広告文の対応の単位）
       ├ キーワード
       └ レスポンシブ検索広告（RSA）
```

**構造の作り方の目安**

- キャンペーンは **予算を分けたい単位**（指名／一般／エリア別／商材別）
- 広告グループは **同じ検索意図のキーワードのまとまり**。1グループ5〜20KW程度
- **指名検索は必ず別キャンペーンに**（CPAが桁違いに安いので、混ぜると一般KWの実力が見えなくなる）

### 2-2. マッチタイプ

| マッチタイプ | 記法 | 挙動 | 使いどころ |
|---|---|---|---|
| **完全一致** | `[キーワード]` | 同じ意味の検索に反応 | 主力KW。制御が効く |
| **フレーズ一致** | `"キーワード"` | 意味を含む検索に反応 | 拡張と制御のバランス |
| **インテントマッチ**（旧・部分一致） | `キーワード` | 関連する意図まで広く反応 | 発見用。**除外とセットで運用** |

> 現在の実務では「完全一致だから安全」とは言い切れません（同義語まで拾う）。
> **どのマッチタイプを使っても、検索クエリレポートの確認と除外は必須**です。

### 2-3. 除外キーワード ― 運用の中心作業

**週次でやること：検索語句レポートを開き、CVしていない無関係なクエリを除外に入れる。**

除外の定番カテゴリ：

- **無料系**：「無料」「フリー」「タダ」
- **求人系**：「求人」「バイト」「採用」「年収」（サービス訴求に求人系が流入するのは頻出）
- **情報収集系**：「とは」「意味」「やり方」「自分で」「diy」
- **競合名**（自社が勝てないなら除外／勝てるなら意図的に狙う）
- **他業種の同名語**（商材名が一般語と被る場合）
- **地域外**（エリア商圏の場合）

**除外にも一致タイプがある**ので、広く消したいときはフレーズ除外を使う。完全一致除外だけだと漏れます。

### 2-4. レスポンシブ検索広告（RSA）

- 見出し（最大15本）・説明文（最大4本）を入れて、Googleが組み合わせを最適化
- **アセットの「多様性」が効く**：同じ言い回しを15本入れても意味がない
  - 訴求軸を分ける例：`実績・数字` / `価格・費用` / `スピード` / `安心・保証` / `対象者の呼びかけ` / `行動喚起`
- **固定（ピン留め）は最小限に**。法務上必須の文言だけピン留めする
- **広告の有効性**は参考程度。「良」以上を目指しつつ、無理に埋めない
- **アセットグループ単位のレポート**で、どの見出しが効いているか確認する

### 2-5. 品質と広告ランク

```
広告ランク ≒ 入札単価 × 品質（推定CTR・広告の関連性・LPの利便性）＋ 広告表示オプションの影響
```

**品質スコアが低いとCPCが上がる。** 改善順は、

1. **キーワードと広告文の一致**（広告グループを分けて、見出しにKWを入れる）
2. **LPの関連性**（KWに対応した見出し・内容が、そのLPにあるか）
3. LPの表示速度・モバイル対応

### 2-6. 広告表示オプション（アセット）

**入れるだけでCTRが上がるので、基本は全部入れる。**

- サイトリンク（4本以上）／コールアウト／構造化スニペット
- **電話番号**（電話CVが取れる商材では最優先）
- 住所（店舗ビジネス／Googleビジネスプロフィール連携）
- リードフォーム、価格、プロモーション

## 3. P-MAX（Performance Max）

**1キャンペーンでGoogleのほぼ全在庫に横断配信し、設定したCV目標の達成をAIが最大化する目標ベースのキャンペーン**です。

### 運用者がコントロールできること／できないこと

| コントロールできる | できない（AI任せ） |
|---|---|
| CV目標と入札戦略（CV数最大化／CV値最大化、tCPA／tROAS） | 配信面ごとの予算配分 |
| 予算、地域、言語、配信スケジュール | どのクエリにいくら入札するか |
| **アセット（テキスト・画像・動画）の質と量** | 面ごとの細かい入札調整 |
| **検索テーマ／オーディエンスシグナル** | 個別プレースメントの完全制御 |
| **除外キーワード、ブランド除外** | ― |

> **要点：P-MAXの成果は「アセットの質」と「シグナルの正しさ」でほぼ決まる。**
> 管理画面でいじれるレバーが少ない分、**入れる材料の準備が仕事**になります。

### P-MAXの実務ポイント

1. **CVデータが溜まってから入れる。** ゼロから立ち上げると学習が回らず、予算だけ溶ける
2. **ブランド除外を必ず設定。** しないと指名検索を食い、見かけのCPAだけが良くなる（＝検索キャンペーンから奪っているだけ）
3. **動画アセットは自分で用意する。** 入れないとGoogleが自動生成し、品質が読めない
4. **アセットグループは「訴求・商材」で分ける。** 分けすぎると学習が薄まる
5. **オーディエンスシグナルは"ヒント"であって限定ではない。** 既存顧客リスト・購買意向を渡すと立ち上がりが速い
6. **検索テーマ**で拾ってほしい領域を明示する
7. **レポートの見にくさが最大の弱点。** アセットグループ別・検索カテゴリ別のレポートと、除外の当て方で可視性を稼ぐ

### 検索キャンペーンとP-MAXの共存

- 完全一致キーワードで拾えるクエリは、原則**検索キャンペーンが優先**される
- 混在時は **検索＝守り／P-MAX＝攻め** と役割を決め、**指名は必ず検索側で確保**する

## 4. デマンドジェネレーション（Demand Gen）

**YouTube・YouTube Shorts・Discover・Gmail といったビジュアル面に、画像・動画で配信して「まだ検索していない層」に需要を作るキャンペーン**です。

### 押さえどころ

- 位置づけは **旧ファインド広告の後継＋動画面の統合**。SNS広告に近い発想で運用する
- **クリエイティブが主役**。ターゲティングよりまず素材の質と本数
- 縦型（Shorts）・スクエア・横型を**すべて用意する**
- 効果測定は**CVだけで見ない**。指名検索数、サイト直接流入、ブランドリフトを併せて見る
- **類似セグメント／自社データ（顧客リスト）** との相性が良い

### Meta広告との比較（提案でよく聞かれる）

| | デマンドジェネレーション | Meta広告 |
|---|---|---|
| 強み | YouTubeの動画到達力、Googleの検索・視聴履歴シグナル | 精緻な行動ターゲティング、クリエイティブ検証の速さ |
| 主な面 | YouTube / Shorts / Discover / Gmail | Facebook / Instagram / Reels / Threads 等 |
| 向く商材 | 動画で見せると伝わるもの、認知が薄いもの | ビジュアル訴求、衝動性のある商材、リード獲得 |

## 5. 入札戦略

| 戦略 | 使う場面 | 注意 |
|---|---|---|
| クリック数の最大化 | データゼロの立ち上げ期 | 上限CPCを必ず設定（青天井を防ぐ） |
| **コンバージョン数の最大化** | CVが出始めたら標準 | 予算を使い切る方向に動く |
| **目標CPA（tCPA）** | CPAを一定に保ちたい | 厳しすぎると配信量が激減 |
| コンバージョン値の最大化 | CV値を送れている | 値の設定が誤っていると全部歪む |
| **目標ROAS（tROAS）** | EC・売上金額連動 | 十分なCV値データが前提 |
| 目標インプレッションシェア | 指名検索の防衛、認知 | CPAは悪化しやすい |

**移行の型：** `クリック数の最大化 → CV数の最大化 → 目標CPA → 目標ROAS`
CVデータが溜まるにつれて、右へ進む。**飛ばすと学習が回らない。**

## 6. 立ち上げの実務手順（新規アカウント）

```
1. ビジネス理解     商材・粗利・成約率・繁閑・エリア・競合をヒアリング（→ 06_テンプレート集）
2. 許容CPA算出     粗利 × 目標配分 から逆算（→ 00_基礎）
3. 計測設計        CV定義 → GA4/タグ設置 → テストCVを1件通す
4. キーワード設計   キーワードプランナー＋実際の検索結果を目視。検索意図でグルーピング
5. 構造設計        指名／一般／エリアでキャンペーン分割
6. 広告文作成      グループごとにRSA。見出しにKWを入れる
7. LP確認          メッセージマッチ、フォーム項目、表示速度
8. 入札            立ち上げはクリック数の最大化（上限CPC付き）or CV数の最大化
9. 配信開始        初週は毎日消化とクエリだけ確認、施策は打たない
10. 2週目以降      検索語句レポート → 除外 → 広告文改善 → 入札戦略移行
```

## 7. つまずきポイント集

| 症状 | 疑うところ |
|---|---|
| インプレッションが出ない | 予算不足、入札が低すぎ、tCPAが厳しすぎ、KWの検索ボリュームがない、広告審査落ち |
| CTRが低い | 検索意図と広告文のズレ、広告表示オプション未設定、掲載順位が低い |
| クリックは来るがCVしない | LPのメッセージマッチ、フォーム、そもそも意図がズレている（クエリを見る） |
| CPAが急に悪化した | 競合参入（CPC上昇）、KW追加による意図拡散、計測不具合、季節性、LP変更 |
| P-MAXのCPAだけ異様に良い | **ブランド（指名）を食っている**。ブランド除外を確認 |
| CVが急にゼロ | タグ・タグマネの事故、LPのURL変更、フォームの不具合。**まず自分でCVしてみる** |
