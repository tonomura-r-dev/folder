# 00. 基礎 ― マーケの共通言語

> ここが曖昧なまま媒体の勉強に進むと、「CPAが高いですね」で会話が終わってしまいます。
> **すべての指標は、掛け算・割り算に分解できる**。分解できれば打ち手が決まる。これがこの章の全部です。

---

## 1. ファネル ― 数字は必ず階段になっている

広告からの購買は、必ず段階を降りていきます。各段階の「人数」と「移行率」がすべての土台です。

```
表示（Imp）
  ↓ CTR（クリック率）
クリック（Click）＝ LP流入
  ↓ CVR（コンバージョン率）
コンバージョン（CV）＝ 問い合わせ・予約・購入
  ↓ 引き上げ率（来場率・受注率など）
売上・来場・契約
```

### 各段階の基本式

| 指標 | 式 | 意味 |
|---|---|---|
| CTR | クリック ÷ 表示 | 広告が「自分ごと」に見えているか |
| CPC | 広告費 ÷ クリック | 1クリックの仕入れ値 |
| CVR | CV ÷ クリック | LP・オファーが噛み合っているか |
| **CPA** | 広告費 ÷ CV | 1件獲得の原価 |
| **CPM** | 広告費 ÷ 表示 × 1,000 | 1,000回表示あたりのコスト |
| ROAS | 売上 ÷ 広告費 × 100% | 広告費が何倍の売上になったか |
| CPO / CPI など | 用途別のCPAの言い換え | 何を1件と数えるかを必ず定義する |

### いちばん大事な分解

```
CPA = CPC ÷ CVR
    = （広告費 ÷ クリック） ÷ （CV ÷ クリック）
```

つまり **CPAを下げる方法は原理的に2つしかない**：

1. **CPCを下げる**（＝ 仕入れを安くする）… 入札、品質、マッチタイプ、配信面、ターゲット
2. **CVRを上げる**（＝ 歩留まりを良くする）… LP、オファー、フォーム、訴求と検索意図の一致

「CPAが高い」と言われたとき、**どちらの問題かを切り分けてから喋る**。これができるだけで会議での立ち位置が変わります。

さらにCPMベースの媒体（Meta・LINE広告など）では：

```
CPC = CPM ÷ 1,000 ÷ CTR
→ CPA = CPM ÷ 1,000 ÷ CTR ÷ CVR
```

Meta広告で「CPAが悪化した」ときは、**CPM（オークション競争・ターゲット幅）／CTR（クリエイティブ）／CVR（LP・計測）** のどこが崩れたかを分けて見ます。

## 2. 損益の言葉 ― LTV・CAC・限界CPA

広告の良し悪しは「CPAが安い／高い」では決まりません。**いくらまで払っていいか**が先です。

| 用語 | 式・意味 |
|---|---|
| **LTV**（顧客生涯価値） | 1顧客が生涯で生む粗利。ざっくり `平均購入単価 × 粗利率 × 購入回数` |
| **CAC**（顧客獲得コスト） | 1顧客の獲得にかかった総コスト（広告費だけでなく人件費・ツール費も含む考え方） |
| **限界CPA（許容CPA）** | `1件あたり粗利 × 目標とする利益配分` 。ここを超えたら赤字 |
| **LTV : CAC** | 3:1 が健全とよく言われる目安（業種で大きく変わる） |
| **回収期間（Payback）** | CACを何ヶ月で回収できるか。キャッシュフロー上はCPAより重要なことも多い |

### 実務での組み立て順（提案でそのまま使える）

```
1. 客単価と粗利率を聞く            → 1件あたり粗利
2. 成約率（CV → 受注）を聞く       → CV1件あたりの期待粗利
3. 目標利益率を決める              → 許容CPA
4. 現在のCVRから逆算               → 許容CPC
5. 媒体の相場CPCと比べる           → 「その媒体で成立するか」の判断
```

> **例（このリポジトリの実案件の考え方）**
> 月額広告費80万円／予約単価10,000円／月間予約80名。
> ここまでは「予約」のCPAが10,000円。しかし予約→来場が65%なら、
> **実質来場単価 = 10,000 ÷ 0.65 ≒ 15,385円**。
> 来場率を80%に引き上げれば **12,500円**。広告を1円も増やさずに単価が改善する。
> → **「広告の外側（引き上げ）で単価が改善する」ことを数字で示すのが、LINE OA提案の核心です。**

## 3. 指標の「単位」を揃える ― 事故の9割はここ

提案・レポートで揉める原因のほとんどが、単位のズレです。

### 揃えるべき4点セット

| 揃えるもの | よくある事故 |
|---|---|
| **期間** | 「今月」が暦月／直近30日／課金締め日でズレる |
| **税** | 媒体費は税別、請求は税込。LINE OAの料金は基本**税別**表記 |
| **CVの定義** | フォーム送信／サンクスページ到達／電話タップ／予約完了。**電話とフォームの二重計上**は頻出 |
| **アトリビューション** | Google（クリック基準・CV発生日 or クリック日）と Meta（7日クリック＋1日ビュー等）で**同じCVを両方が自社成果として数える**。媒体合計 ≠ 実CV数 |

**鉄則：媒体管理画面の合計と、CRM／予約システムの実数は必ず突き合わせる。** 提案の数字は原則「実数側」を正とし、媒体側は参考値として併記します。

## 4. STP と 4P（提案の骨格を作るとき）

広告の細かい話に入る前に、そもそもの立ち位置を1枚で言えるか。

- **S**egmentation：市場を分ける（属性・地域・行動・ニーズ）
- **T**argeting：どこを狙うか決める（規模 × 到達可能性 × 競合の弱さ）
- **P**ositioning：**誰にとって、何がいちばんの理由で選ばれるか**を一文で

> ポジショニングの一文テンプレ：
> **「〈ターゲット〉が〈状況〉のとき、〈競合〉ではなく当社を選ぶ理由は〈独自の便益〉である」**

4P（Product / Price / Place / Promotion）のうち、**広告運用は Promotion の一部でしかない**。
CPAが下がらないときの真因が Price（高い）や Product（オファーが弱い）にあることは珍しくありません。
「広告では解けない」と切り分けて言えるのも実力のうちです。

## 5. カスタマージャーニーと媒体の役割

| フェーズ | 顧客の状態 | 主戦場 | 見るべき指標 |
|---|---|---|---|
| 認知（need未自覚） | 課題に気づいていない | Meta広告、デマンドジェネレーション、動画 | リーチ、CPM、視聴完了率 |
| 興味・比較（need顕在） | 調べている | Google検索広告、SEO記事、比較サイト | CTR、CVR、指名検索数 |
| 意思決定 | 決めかけている | 指名検索、リマーケティング、LP | CVR、CPA |
| **再訪・引き上げ** | CV後〜来店/購入まで | **LINE公式アカウント**、メール、SMS | **引き上げ率、開封率、ブロック率** |
| リピート・LTV | 既存顧客 | LINE OA、CRM | 再購入率、LTV |

**このノートで広告とLINE OAを並べて学ぶ理由がここにあります。**
広告は「CVまで」しか作れない。CV後の引き上げとリピートを担うのがLINE OA。
**「広告で入口を広げ、LINE OAで漏れを止める」** ── これが提案の一貫したストーリーになります。

## 6. よく使う概算値（暗算用）

| 場面 | ざっくり感覚 |
|---|---|
| 検索広告のCTR | 指名 20〜50%／一般KW 2〜5%（業種差大） |
| ディスプレイ・SNSのCTR | 0.5〜1.5% 程度 |
| LPのCVR | BtoCのフォーム 1〜5%／BtoBの資料DL 3〜10%（同上） |
| 有意差判定に必要なCV数 | A/Bテストは **各パターン最低30〜50CV**。それ未満の勝敗はほぼノイズ |
| 自動入札の学習に必要な量 | **週50CV程度**が目安（Google・Meta共通の考え方） |

> これらは「桁を間違えないための感覚値」です。**提案書に載せる数字は必ず自社実績か一次情報**から取ること。
