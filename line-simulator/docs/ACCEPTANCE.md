## 残課題

1. 書き出しの対象ブラウザは Chrome／Edge のみ確認（Safari・スマホ実機は未確認）。
2. スクショの解析は Claude Code に頼む運用（編集ツールにAIは内蔵していない＝方針どおり）。
   提案の質はスクショの枚数・写り方で変わる。隠れた項目は推定になる。
3. 伏せ字（〔店名〕）はそのままデモに出る。営業は書き出す前に架空の店名へ書き換える。
4. 「来店日から30日後」のように LINE の外の日付を起点にする配信は、答えた日／予約した日を起点に近似している。
5. 1案件の画像が多いと HTML が重くなる（5MBで警告・15MBで書き出し不可）。
